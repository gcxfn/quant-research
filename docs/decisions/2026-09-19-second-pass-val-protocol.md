# 决策：val 窗二次消费协议（预承诺，先于任何新候选存在）

- 日期：2026-09-19；裁定：用户指示"大规模的攒一起再拿之前的val集验证"（探索在 dev 攒批、二次过手 val 验证）；主对话起草协议并预承诺。
- 背景：val 窗 2021–2024 已于 TL-30 一次性消费（R3-05/R3-06 过三门、ROT-05 淘汰）。本决策开启**至多一轮**的二次消费，规则先于任何新候选冻结。

## 1. 认识论声明（不可删）

1. 二次消费产生的证据**永远不得称为"样本外"**；一切报告、台账、README 措辞为"**二次过手 holdout（证据折扣）**"。
2. 折扣来源（如实随结果披露）：① 该窗首轮结果已知（含 B1m(val) −0.15%/−23.4%）；② 家族设计者的认知污染（已知 2022 亏损、QDII 动量有效等窗特征）；③ 同窗多次检验的适应性数据分析损耗。
3. 唯一真·新鲜样本外数据仍是 **2025+ 冻结区**——解锁与否独立于本协议，另由用户决定。

## 2. 预承诺协议（Phase A/B）

**Phase A（dev-only 大规模探索，即日启动）**
- 全部探索限于 2015–2020；预登记纪律不变（每轮 ≤12 配置、先冻结后运行、锚回归、试验照常计账）。
- 探索线：ETF 宇宙扩展轮（先数据筛查后预登记）、混合结构变体轮、T1 完成后事件驱动线；子代理并行实施，主对话逐轮验收。

**入册资格（roster，冻结定义）**
- dev 八门全过 **且** dev 净年化 ≥10%（目标列）；已消费过 val 的配置（R3-05/R3-06）不入册。

**Phase B（二次过手批量验证，一次性）**
1. 触发：某探索线宣告完成且册内 ≥1 配置；名册在专用预登记中冻结（含全部配置逐字参数）——冻结后不得增删。
2. 单批执行：全部名册成员于 2021–2024 一次运行（引擎 v1.3、事件表沿 TL-30 口径、锚回归先行）；判据=R16 冻结 val 三门逐字 + 目标列披露。
3. **全部结果报告**：任何成员的失败都是有效结果；禁止看结果后修改/增补/重跑（违者全族降为 exploration-grade）。
4. 多重性披露：名册规模 N 随结果一并报告（N 次同窗检验的家族性误差膨胀如实陈述）。
5. 本协议允许的二次消费**至多此一批**；此后 val 窗对判定用途永久关闭。

## 3. 边界

- 2025+ 冻结不变；data/raw 只追加；试验计数与台账纪律不变；本协议不构成任何盈利或实盘声称。
- 若 Phase A 全线无入册配置 → Phase B 不触发，val 窗保持已消费状态。
