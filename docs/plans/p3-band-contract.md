## 1. 执行契约（v0 冻结语义，全部为保守方向）

### 1.1 决策与订单生命周期
- 决策时点：T−1 收盘后生成 T 日区间表；v1 追加 T 日 11:30 午盘刷新点（halfday 表）。
- 订单类型：**限价日单**。当日未成交收盘作废，次日由信号层重挂——与真实 A 股订单语义一致；不实现跨天订单状态机。
- 挂单价规则（信号→区间的映射，**零搜索、单一规则集**；买卖不对称是设计而非疏漏——踏空买入的代价是少一个仓位，持死仓位的代价是风险敞口）：
  - 买入：限价 = 信号日收盘价，**固定不重锚**——只在回踩到信号价以下时成交；信号失效（沿宿主规则，如缓冲带跌出、换期新信号）即停止重挂。同名义新信号日重挂覆盖旧单。
  - 卖出：限价 = **每日重锚至最新收盘价**（跟随市价保证常规日可成交）；连续 3 个交易日未成交，则第 4 个交易日以开盘价**无条件市价退出**（K=3 冻结，防下跌途中限价单永不成交）；市价退出日若开盘即跌停（open ≤ limit_down×(1+1e-4)）或停牌，顺延至下一可交易日。
- 推论：旧口径"无条件次日成交"的成交集是本契约成交集的超集；本契约同时压低换手与成交率，两者都必须如实披露。

### 1.2 触发与成交（保守语义）
- 买入成交：当日 `low < 限价 p`（**严格穿透**）→ 按价 p 成交；触价（==）不成交（排队保守）。
- 卖出成交：当日 `high > 限价 q` → 按价 q 成交。
- 成交价不取更优价（不假设日内路径有利）。
- 停牌日：无行情 → 当日单作废；信号未失效则复牌后继续按规则重挂。
- 限价合法性：限价须落在当日 [limit_down, limit_up] 内（stk_limit 实测价），越界单作废并记录。

### 1.3 账户规则
- T+1：当日买入不可当日卖出。日线同 bar 买卖冲突时卖出顺延次日（保守）。
- 整手：**买入**为 100 股整数倍；目标单笔名义 2–4 万（按各预登记）；不足一手放弃并记录（gate-8 内生性教训：成交失败与权益死亡的相互作用须可追溯）。公司行动产生的**零股允许一次性卖出**（A 股规则：零股只能整笔委托卖出）。
- 现金竞争：同日多单按预登记优先级顺序占用现金，优先级 = 宿主信号当期排序（R16 = 流动性排序，沿其冻结配置）；低优先级订单只见高优先级成交后的余额。日粒度无法分辨日内先后，此排序为登记的保守假设，不得事后调整。
- 现金时序：**当日卖出回笼资金不计入当日买入可用现金**（次日可用）——日粒度下不假设"上午卖下午买"的有利路径；月度换仓因此天然承受一日换仓时滞，属契约成本如实入账。
- 公司行动（2026-09-18 双签 REJECT 后修正，F1/F2）：份额调整**仅用 split_factor.h5 的真实送转比例**变更股数（half-up 取整）；现金分红用 dividends.h5，金额 = dividend_cash_before_tax ÷ round_lot × 除息日前持股数（**每手口径**，税前，ex_dividend_date 当日入现金）；**ex_cum_factor 是含分红的价格复权因子，禁止作为账户输入**（只可作对照审计）。loader 必须保留 (0, 1.0) 锚点语义——首个变更点比值不得等于全累计因子（F2）。

### 1.4 费用（与既有轮次口径可比）
- 佣金 = max(万 1 × 成交名义, 5 元)。20 万资金、单笔 ≤5 万名义下恒为 5 元；实现时保留通式并加断言（名义 >5 万即报警），防止未来改资金口径时静默失真。
- 印花税：仅卖出方，按卖出日分段——2023-08-28 前 0.1%、之后 0.05%。实现为出场现金流折价（数学等价），契约测试验证等价性。
- 过户费不计（沿 R6–R16 既有口径；约 0.1bp/边、仅沪市，作为披露项保留）。

## 4. 引擎验收（先于任何策略判定）

1. 费用守恒：全期费用总额与逐笔独立重算逐分对账。
2. T+1 零违例：全期扫描不存在同日买入又卖出的成交对（同 bar 冲突顺延的计数单列）。
3. 整手不变量：所有**买入**成交股数为 100 的倍数；公司行动产生的零股仅在一次性卖出中出现（单列计数）。
4. 现金非负：任意时点现金 ≥0；竞争日的占用顺序与预登记优先级一致。
5. 触价 vs 穿透：构造 low == p 的手算样例，确认不成交。
6. 公司行动（F1 修正后口径）：用真实个股/日期验证——送转日份额按 split_factor 变更、分红按每手口径入现金；纯派息股（如 600000）在派息日**份额不变**；并验证首个变更点比值 ≠ 全累计因子（F2 回归样例）。
7. 停牌与涨跌停：构造样例验证作废/限价合法性。
8. 卖出重锚与市价兜底：构造连续下跌样例，验证每日重锚、第 4 日开盘市价、开盘跌停顺延、同名义新信号覆盖旧单。
9. 现金时序：同日卖出回笼资金不得当日用于买入的样例验证。
10. 双签：执行者 → 独立审阅代理（10 项清单，CRITICAL/MAJOR 分级）→ 我方复算，沿既有流程。

## 7. 契约 v1（2026-09-18 用户对齐后冻结）

对齐记录（用户 2026-09-18）：ETF 不限 T+0 品种、全池纳入；总仓位上限 100%；决策点为**上下午收盘各一次、对称**，区间更新与新标的**不互斥**；分批加仓为信号驱动（"觉得还能涨"即加，不限回踩）；分批减仓=止盈分档+风险减仓；分批语义按**实时动态调整、不设固定网格**；股票卖出印花税**保留单独分段计提**（用户确认）。v1 = v0 §1 全部语义 + 下列修正与扩展；冲突处以本节为准。

### 7.1 时间结构与决策点

- 每交易日两个 session：S_am（09:30–11:30）、S_pm（13:00–15:00）；两个决策点：11:30 收盘后、15:00 收盘后。决策输入 = 该时点的真实账户状态 + 此前全部完整 session 行情。
- 订单为**半日限价单**：15:00 决策挂出的单 live 于次日 S_am；11:30 决策挂出的单 live 于当日 S_pm。session 末未成交即失效（日单语义不变，粒度半日）。
- 每个决策点可自由：撤销并重挂全部在途单（改锚/改量/改批次）、新增标的、加仓、减仓、或不动作。**同一 session 内订单不可变更**——这是分钟以下路径不可验证的保守边界，也是策略层"实时调整不设限"的唯一物理约束。

### 7.2 成交判定与资金（对 v0 的修正）

- 穿透语义按半日 bar：买单 session low < p 成交于 p；卖单 session high > q 成交于 q；跳空按限价成交（保守）；无 bar（停牌）该 session 作废、下个决策点重挂。
- T+1（股票与境内股票 ETF）：当日任何 session 买入的份额当日不可卖，逐批次（clip）记录取得日；**T+0 ETF（跨境/债券/黄金/货币）当日可卖**。
- 卖出资金：**前一 session 成交的卖出资金自下一 session 起可用于买入**（真实 A 股规则为当日可用；同一 session 内先卖后买的路径不可观测，保守禁用。比 v0"次日可用"更接近真实，属保真修正并披露）。
- K=3 兜底 session 化：**风减/离场类**卖单（信号层标记 intent=risk）连续 3 个 session 未成交 → 下一 session 开盘市价兜底，开盘跌停顺延；**止盈类**卖单（intent=profit）到期静默失效，无兜底。

### 7.3 持仓、分批与限制

- 持仓由多 clip 组成：加仓=新 clip（独立锚、数量、有效期），信号驱动不限回踩；减仓=止盈分档单+风险减仓单（减至目标仓位，吃兜底）。
- 整手：买入 clip 为 100 股/份整数倍；公司行动零股一次性卖出（零股当日可卖）。可卖数量=取得日早于今日的 clip 之和（T+0 品种为全部）。
- 上限：总仓位 ≤100%（含费用预留）；单票 ≤25% 权益（20 万初始即 5 万）。

### 7.7 接缝裁定（2026-09-18 引擎实现前；顾问预读 3M+7m 触发，主对话裁定）

以下闭合实现接缝，不改变 §7.1–7.5 已冻结语义与用户对齐的五项核心规则；引用编号沿顾问发现（M=MAJOR，m=MINOR）：

- **K=3 计数主体（M1）**：计数键 = (标的, intent=risk, 来源信号)。机械重锚（撤旧挂新）**不重置**计数——否则订单对象活不过一个 session，兜底被结构性删除；同名义新信号（换期重发）重置；意图到期撤销即终止计数。
- **仓位上限语义（M2）**：总仓位 ≤100% ≡ 现金非负不变量 + 费用预留：买单占用 = 限价×数量 + max(限价×数量×万1, 5 元)，总占用 ≤ 可用现金（含上一 session 回笼）。单票 ≤25%：作用于**订单构建时**（买入/加仓不得使该票目标权重 >25%，按决策点权益快照），越限**整单作废**并计数披露；既有持仓因价格**漂移**越限不强制减持（减持由信号层 rescale 负责），仅记录披露。引擎不做上限裁剪式部分成交（维持不缩量原则）。
- **未成交意图重挂（M3）**：信号存续期内，session 末失效的未成交意图在**每个后续决策点重挂并机械重锚**（v0 语义延续，保证 P3R2 与 P3R1/v0 成交率口径可比）；仅 expiry（下月末信号日）撤销、新信号同名义覆盖。（2026-09-19 裁定：重挂与重锚的执行主体=**引擎意图层**——宿主单帧提交意图，引擎内完成生命周期；宿主侧展开存在成交自指、无稳定不动点，证据见 P3R2 预登记 §9 修订 2。）
- **K 计数边角（m1）**：沿 v0 裁定类推到 session 粒度——停牌 session 计数冻结；兜底武装后的开盘跌停顺延 session 计入；缺涨跌停数据日计入。
- **clip 消耗与双卖意图（m2）**：部分卖出按取得日 FIFO 消耗；同标的止盈+风减并存时，任一成交后按剩余持仓重估风减"减至目标"，目标已满足则撤余单，不叠加击穿（2026-09-18 双签补充：重估主体=宿主下一决策点，引擎不代做；P3R2 静态映射不含 profit 意图卖单，该场景本轮不出现）。
- **半日市（m3）**：无 S_pm bar 的交易日，该 session 按停牌作废处理，当日无 15:00 决策点，在途意图次日首个决策点重挂。
- **送转份额（m4）**：整手送转新增份额取得日记为当日、次日可卖——保守偏离真实规则（真实为上市日整体可卖），登记为已知偏差。
- **涨跌停价（m5）**：同日两 session 共用该日涨跌停价；K=3 兜底的"开盘跌停"按 session 开盘价对该日跌停价判定。
- **门 8 映射口径（m6）**：P3R2 计划成交率 = 成交单数 /（成交 + 未成交终止单数）；终止原因单列（到期/上限作废/同名义覆盖/停牌放弃），重锚中性不计入。
- **同决策点多 clip 平局（m7）**：现金竞争按 clip 创建序（早者优先）；同标的多 clip 各自独立判穿透，互不阻塞。**（S-v13-5 裁定澄清，2026-09-19）**现行为自 v1.1 起未变：同决策点买入现金竞争 = (priority, symbol) 稳定排序叠加意图帧生成序，跨标的同优先级平局由 symbol 名仲裁；"创建序早者优先"的可观测绑定在 **clip 消耗 FIFO**（部分减持按取得序消耗）。测试 c2a/c2b/c2c 钉住（引擎 v1.3 测试文件）。

### 9.2 语义设计（实施前冻结）

1. **通用规则（修订 1）**：份额乘数 = **公告整数比例**（513100=5、513500=2），整数份额 × 整数比例恒为整数；方向无关（拆分 >1、合并 <1 同式）。因子比仅作事件检测与交叉核验：事件表可携带因子比（可选字段），引擎断言 |因子比 ÷ 公告比例 − 1| ≤ 2%（实测 5.0019/5=+0.04%、1.9848/2=−0.76%，均过护栏）。
2. **执行时点**：除权日 pm 会话开市前（先于当日任何成交判定与估值）逐 clip 变换全部持仓 clip。除权日 = 复牌日（变换后新价格域首个交易日；登记/拆分停牌日沿 m3 无会话）。
3. **取整与零头（修订 1）**：整数比例下 `new = old × ratio` 精确整数、**零零头、零折现**（两真实事件断言零触发）；floor + preclose 折现的 fallback 路径仅保留给未来非整数比例事件（保守规则不变）。
4. **可卖性**：镜像 m4（变换新增份额取得日 = 当日、次日可卖）。实测两事件标的均为跨境 T+0 品种，此规则零影响，仅作通用契约登记。
5. **事件数据护栏（修订 1，取代原零连续性断言）**：`|preclose × ratio − close(t−1)| / close(t−1) ≤ 2%`——防错日期/错比例的合法性护栏，不要求跨事件价值零变化（停牌期间净值漂移是真实损益：实测残差 513100 −0.04%、513500 +0.77%，均过护栏）。变换本身的守恒由规则 1/3 的整数乘法恒等保证。
6. **在途订单**：不自动撤销。停牌日沿 m3 冻结；除权日依赖既有安全网——买入旧锚越界当日涨停价 → 限价合法性作废并计数（实测样例：513100 旧锚 5.192 > 01-14 涨停 ≈1.142，必须作废而非按 5.192 成交）；卖出旧锚高于市价 → 自然不成交，当日 15:00 决策点机械重锚至新价格域。两路径均须契约测试用实测价格链验证。**（S-v13-4 裁定补充，2026-09-19）**两条保护链按日历形态分工：混合日历（生产形态）下旧锚订单 live 于停牌日会话 → void_suspended + 停牌日 15:00 无锚跳过重挂 + 复牌日 15:00 新域重锚（ca3b 实证）；单标的日历下旧锚订单直接 live 于除权日会话 → 限价合法性作废路径真实触发（ca3 实证）。两条链均不可能在旧价格域成交，语义与本文一致。

### 10.1 语义设计（实施前冻结）

全部新语义只在新 `kind` 上生效；沿用 §7 既有边界：半日限价单、同 session 不可变更、严格穿透、跳空按限价（止损单例外，见 10.1-3）、T+1 逐 clip、卖出资金次 session 可用、整手、费用通式不变。

**1. 阶梯买入意图 `ladder_buy`**。字段：symbol、σ0（价格单位，运行层给定）、档位表 [(近沿偏移系数, 份额占比)] = [(0.5, 0.40), (1.5, 0.40), (2.5, 0.20)]、总股数（整手，按信号日 w_T×权益/P0 折算）、失效线 = P0−3.5σ0、expiry、priority。行为：
- 每个决策点对每档**剩余**股数挂半日限价单，限价 = P − 偏移×σ0（P = 该决策点价：11:30 用 am.close，15:00 用官方收盘）；成交判定沿 §7.2（session low < 限价 → 按限价成交）；逐档 fill-stop（某档成交即停，不影响其余档）。
- 三种终止：expiry（下一信号日 +1 历日）/ 同名义覆盖（新信号月整组替换）/ **失效**——session low 穿透 P0−3.5σ0 时，下一决策点起取消全部未成交档（当 session 已挂的档不受影响，先成交后失效的次序冻结为"该 session 成交优先"）。

**2. 止盈意图 `take_profit`**（成本锚定、目标固定、不重锚）。字段：symbol、mult（b1=2.0 / b2=3.0）、frac（b1=0.50 / b2=1.0）、σ0、expiry。行为：
- 每决策点目标价 = WAC（当前所持全部 clip 的加权平均成交价，费用不计入）+ mult×σ0；数量 = floor(frac×当前持股/100)×100（b2 的 frac=1.0 时含公司行动零股全卖）。b1/b2 为两条独立意图并存；同 session 双双触价则都成交。
- 成交：session high > 目标价 → 按目标价成交（跳空按限价，保守）。**无 k3 兜底**（profit 类，§7.2 原语义）；expiry 静默失效。
- 止盈成交**不取消**仍在途的 ladder_buy（产品语义：三档买入计划独立存续；换手代价由门 5 裁定）。

**3. 止损意图 `stop_sell`**（棘轮移动止损、常驻触发单）。字段：symbol、mult=3.0、σ0、expiry。行为：
- 状态：HWM = 自该票本信号月首笔成交的决策锚起、至当前决策点止的**决策价最大值**（停牌 session 冻结；不用日内 high，保守且与表单口径一致）；触发线 = HWM − 3σ0，**只升不降**（历史最大线生效）。
- 触发与成交：session low < 线 → 按 **min(线, 该 session 开盘价)** 成交（跳空穿越按开盘，比限价语义保守；日内穿线按线价，中性假设，披露）。卖出全部可卖 clip（T+1 过滤）；当日买入不可卖部分 → 次一 session 开盘市价兜底（k3 既有机制武装，计入门 8 分母）。
- **同 session 止损与止盈同时可触发时，判定次序冻结为止损先**（保守：不利方向优先）。止损全清后同名义 ladder_buy 一并终止（席位回收进入冷却）。

**4. 席位回收（成员资格进引擎，静态帧 + 引擎内确定性规则）**。帧新增月度候选表：每信号月一个有序列表（rank、symbol、industry、σ0、P0），附 K、IND_CAP。引擎在每个决策点执行同一条规则：
- 活跃集扫描：沿 rank 自上而下，跳过（i）已持有（保留其 TP/SL）、（ii）**本月已清仓冷却**（止损或止盈全清后至下一信号日不得回补）、（iii）行业已满（计入已持有 + 在途 ladder 的行业计数）、（iv）ladder 已失效/已耗尽；当 (持有数 + 在途 ladder 数) < K 时放行下一位候选的 ladder。
- 月度边界（信号日）：上月持有且本月 rank ≤ 2K 者续持（缓冲语义沿 F3R3）；rank > 2K 或掉出名单者全仓退出（risk 卖，吃 k3）；随后按活跃集规则补位。
- 该规则与 M3 教训一致：成交依赖的成员资格必须在引擎内闭环，宿主不得依据成交结果展开帧。

**5. 门 8 v1.4 口径**（v3 口径在新订单类型上的重述）：分母 armed = 止损触发但未成交的留滞（T+1 跨日、停牌跨日）；分子 = k3 兜底成交 + armed 后自行成交；stuck==0 硬断言不变。止盈到期与买入档到期/失效**不入分母**，单独披露计数。
