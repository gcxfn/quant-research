# C3-C 合同局限（模型选择与现实近似的界限）

- 证据目录：`docs/evidence/trust-rebuild/20260922T035220-trust-c3-c8af13/`（下称 `<EV>`）
- 本文件只**披露**局限，**不改**本轮正式合同、费率或引擎行为。

## 1. 哪些是模型选择，不是交易所真相

| 规则 | 内容 | 性质 |
|---|---|---|
| 严格穿透 | 买 `session low < 限价` 成交于限价；卖 `session high > 限价` 成交于限价；**触价（==）不成交** | 排队保守假设。真实市场里触价可能成交（取决于排队位置与主动单），本模型一律不成交 |
| 跳空按限价 | 跳空穿过限价时仍按限价成交，**不取更优价** | 保守假设。真实成交价可能优于限价（开盘价更有利） |
| 半日粒度 | 一个半日只有一个 bar，**不假设半日内价格先后** | 由数据可得性决定。因此「同半日买后卖」「用同半日卖出款买入」按合同禁止 |
| 卖出资金晚一 session | am 成交→当日 pm 可用；pm 成交→次日 am 可用 | 比真实 A 股（当日可用）保守，是「同半日先卖后买不可观测」的必然结果 |
| 无 bar = 不可交易 | 停牌/缺半日行 → 该半日不可成交、风险计数冻结 | 与数据卡一致（缺行不是价格 0） |
| 涨跌停缺行 = 拒绝 | 缺 `(symbol, day)` 行时不做价格合法性判定，保守拒绝；K=3 兜底在缺行日按「无法判跌停」执行开盘市价 | 保守方向：不把缺行当「无约束」 |

**一致 ≠ 真实**：两条独立实现（引擎与 matcher）在这些语义上逐笔一致（5,260 单 + 74 次兜底，
见 `c3_case_report.md` 第 3 节），这只证明**模型内部一致**，不证明交易所逐笔成交会完全相同。

## 2. 分钟样本能核验什么、不能核验什么

已授权分钟样本：`data/processed/minute-feats-20260918/minute_feats.parquet`
（manifest：`minute-feats-20260918`，run `20260918T080205-p2r14-minute-structure-f59f`）。
**性质**：每股每日一行的**投影特征表**（`close_share30`/`tail_amt_share`/`last30_ret`/`day_high`/
`day_low`/`am_range30`/`first_bar_vol`/`pm_touch_limit_down`/`limit_close_state`），
**不含分钟价格序列**，也没有分 session 的分钟极值。

抽样口径：从 `<EV>/order_reconciliation.csv` 取 `never_crossed` 限价单（这类订单的判定正是
「半日极值有没有穿过限价」），均匀抽样 1,030 笔（跨年份/跨臂），产物
`<EV>/minute_vs_halfday_check.csv`。

| 核验项 | 结果 |
|---|---|
| 半日 bar 极值是否落在分钟全日极值区间内（越界 = 制造数据） | 1,030/1,030 在区间内，**零越界** |
| 细粒度（全日分钟极值）下本可穿透、但半日判定不穿透的笔数 | **246/1030 = 23.9%** |
| 其中可严格归因于**本 session**（另一 session 极值未穿价） | **19/1030 = 1.8%** |
| 反向误判（半日判成交而分钟不可能成交） | **0 例** |

**读法**：246 与 19 的差来自「全日极值可能属于另一个 session」，投影表没有分 session 极值，
所以 23.9% 是上界、1.8% 是严格归因值。方向恒定为**保守少判成交**（半日粒度比分钟粒度更保守），
没有一例是「半日虚判成交」。

**未核验（能力边界）**：
1. **订单生效半日之前是否已穿透**（C1 数据卡第 2 卡缺陷 4 同一条）：投影表没有分钟顺序，
   无法判断「穿透发生在订单 live 之前」。要核验需**单独申请受控提取**原始分钟序列
   （`data/raw/user_minute_1m/`），本轮未授权、未做。
2. **排队成交率**：没有订单簿/逐笔数据，不可证。因此「触价不成交」只能声明为保守模型选择。
3. 分钟样本本身只覆盖部分 `(symbol, day)`（Dev 窗实测 4,598,367 行 / 4,181 只）——
   本次抽样的 1,030 笔恰好全部命中（`coverage_rate=1.0`），但这不是全市场覆盖率声明。

## 3. 时间与范围边界

- 时间：本阶段一切行情读取都经 C1 Dev 沙箱，窗口 `2015-01-05..2020-12-31`；
  2021+ 与 2025+ 未读取（`no_2021plus_verification`）。合成切片用 Dev 窗内日期 + 全合成价格。
- 标的：**只覆盖主板股票半日合同**（`sh.60*` / `sz.00*`）。创业板/科创板/北交所标的、
  ETF 腿（单合成 pm 会话、T+0 名录、基金涨跌停带宽）**未覆盖**，不得据此声称。
- 未成交原因分类：`never_crossed / suspended / limit_illegal / limit_missing / expired /
  cancelled_cap / cash_short / below_lot / t1_locked / no_position / at_target / replaced`
  已与 C1 `event_order_lifecycle` 枚举对齐；**没有**「排队未成交」这一独立原因
  （本模型无法区分「没到价」和「到价但排队未成交」），这是合同局限而非实现缺陷。

## 4. 已授权的近似与它影响的结论

| 近似 | 影响范围 | 是否影响 C3 结论 |
|---|---|---|
| 严格穿透 + 触价不成交 | 成交率系统性偏低（保守） | 不影响「两套实现是否一致」；影响**任何绝对成交率水平**的解读 |
| 跳空按限价、不取优 | 成交价系统性偏高（买）/偏低（卖） | 同上 |
| 半日粒度无日内路径 | 无法核验同半日先后 | 不影响；合同已明文禁止相关路径 |
| 缺涨跌停行整日拒绝 | 3 个整缺日（2017-03-07..09）+ 若干单标的缺行 | 影响极小，且方向保守；已在 `order_reconciliation.csv` 逐行留痕 |
| 无订单簿 | 排队成交率不可证 | 影响「是否可以视作可实盘」的判断；**不支持**任何实盘可成交性声明 |

## 5. 校准政策

按主计划 8-C3-C：任何模型校准**只做差异披露，不改变本轮正式合同与费率**。
本文件的 246 / 19 两个数字就是披露项；它们不进入合同，也不用于回填任何历史结论。
若未来要改合同（例如引入「触价可按比例成交」或「跳空取开盘价」），必须另行预登记并作为新版本比较。
