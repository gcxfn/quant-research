# 手算预期表说明（C2）

本文件解释 `hand_calculated_expected.csv` 的每一行来源与手算过程。A 表
（TV-A01..A05）的期望值直接取自 `docs/quant_stage_plan_20260922/05_test_vectors.md`
第 7/9/11/13/15 行，**先于任何主引擎结果写定**（该文件 2026-09-21 冻结，测试文件
在其后编写，未读取也未引用主引擎输出）。E 系列为实施者扩展的手算案例。

费率与舍入沿 C1 `interface_contract.json` 的 `fee_schema`：佣金
`max(名义×0.0001, 5.00)`；卖出印花 2023-08-28 前 0.001、当日及以后 0.0005；
每笔现金变动 ROUND_HALF_UP 到 0.01 元。现金时序沿 C0 `contract_snapshot.json`
的 `settlement_delay`：am 卖出款当日 pm 起可用，pm 卖出款次一交易日 am 起可用，
同一 session 内先卖后买不可用。

## 扩展案例手算

### E1 多次部分卖出 + FIFO
- 初始 100000；day1 买 1000@10：成本 10000+5=10005 → 现金 **89995**，批次 A（取得 06-02）。
- day2 买 500@12：成本 6000+5=6005 → 现金 **83990**，批次 B（取得 06-03）。
- day3 上午卖 1200@11：名义 13200，佣金 5，印花 13200×0.001=13.20，净 **13181.80**；
  am 卖出款当日 pm 起可用 → 现金 83990+13181.80=**97171.80**。
- FIFO 消耗 A 1000 + B 200，剩 B **300** 股；市值 300×11=**3300**；权益 **100471.80**；
  累计费用 5+5+5+13.20=**28.20**。

### E2 分红后卖出
- 初始 100000；day1 买 1000@10 → 现金 89995。
- day2 除息 0.50/股 × 1000 = **500** → 现金 **90495**；mark 9.50 → 市值 **9500**；
  权益 99995（与除息前一致）。
- day3 上午卖 1000@9.60：名义 9600，佣金 5，印花 9.60，净 **9585.40** →
  现金 90495+9585.40=**100080.40**；累计费用 **19.60**。

### E3 非整数送转零股 / E3b 整手对照
- E3：初始 100000；买 300@3 → 佣金 5 → 现金 **99095**。除权 ratio 1.9848：
  300×1.9848=595.44 → half-up **595** 股；新增 295 股是**零股**，按合同当日可卖
  （sellable=595）；mark 1.50 → 市值 892.50，权益 **99987.50**。
- E3b（对照）：买 1000@3 → 现金 **96995**；ratio 1.3 → 1000×1.3=**1300**；
  新增 300 股是**整手**，取得日=当日 → 次日才可卖（sellable=1000）；mark 2 →
  市值 2600，权益 **99595**。

### E4 同 session 卖出款不可用（反例 + 正例）
- 初始 10020（刚好够买 1000@10 的 10005）；买后已结算现金 **15**。
- 反例：day2 上午卖 1000@10（净 9985，pm 才可用）后**同上午**买 20000@9，
  参考校验必须报 `SettlementTimingError`（同一 session 卖出款不可用）。
- 正例：把同一买入放到 day2 **下午**，可用现金 15+9985=10000 → 买 900@9
  成本 8100+5=8105 → 现金 **1895**，持股 900，市值 8100，权益 **9995**，
  累计费用 5+15+5=**25.00**。
