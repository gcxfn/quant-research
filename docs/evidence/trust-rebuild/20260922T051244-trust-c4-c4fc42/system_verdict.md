## 3. 没证明什么（局限，不夸大）

1. **交易所逐笔与排队成交率**：无订单簿，严格穿透/跳空取限价是**模型选择**，不是交易所真相；
   半日粒度相对分钟是**保守少判**（1,030 笔抽样 0 例反向误判），但「订单生效前是否已穿透」未核验。
2. **ETF 腿**：C2/C3 的账本与撮合核验只覆盖股票半日合同；ETF 腿（pm-only 路由、日线撮合）未在本轮对账。
3. **板块**：主板股票半日合同之外，创业板/科创板/北交所**一律未碰**。
4. **样本**：2021 年及以后未读；已发生的 val 标签接触（AL-01/AL-05）不可清零，见 §5。
5. **25% 单名帽的绑定情形**：12 个被对账臂中帽从未绑定（cap 命中 0），
   引擎与 matcher 的 am 快照潜在口径差因此**无观测样本**；若未来某臂绑定须先对齐（C4-DEF-02）。
6. **attrib2 无订单级产物**：其席位/漏斗结论未做订单级对账（产物缺口，已登记）。
7. **11:30 不变性为合成切片**（真实 provider + 真实引擎代码），非真实 run 回放。
8. **费率舍入规则**仍是审阅者默认裁定（C0-BLK-01→C1），**待用户追认**；
   主引擎全程 float 不舍入的实现事实未改。
