> **§1.3 阶段、权限与角色**

> 阶段推进采用"用户逐段授权"：每个 C 阶段开始前由用户在该阶段指令中写明授权范围；未获授权的阶段不得开工，也不得把上一阶段的完成当成下一阶段的许可。

> **权限必须如实申报**：若分支保护、独立执行环境、数据隔离或身份认证尚未部署，阶段报告必须显式写 `enforcement_level=procedural_only`，不得声称技术上无法越权。任何阶段不得修改 `data/_meta/` 下的校验基线或以新版覆盖旧证据。
