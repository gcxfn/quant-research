## 2. 十二个固定因子（11:30 收盘截面计算，一次定死）

| 编号 | 定义 |
|---|---|
| F1 | 上午收益 = close_1130 / open_930 − 1 |
| F2 | 上午超额 = F1 − 截面中位数（当日） |
| F3 | F2 × 量比（vol_am / 过去 20 交易日日均 vol，日线口径） |
| F4 | 隔夜跳空 = open_930 / preclose_official − 1 |
| F5 | F4 × F2（跳空后上午延续） |
| F6 | 振幅位置 = (close_1130 − low_am) / (high_am − low_am + 1e-12) |
| F7 | 量比 = vol_am / 过去 20 交易日日均 vol |
| F8 | 近 5 日上午超额均值 × (−1)（上午反转因子） |
| F9 | 上午触板占比 = am_limit_up_touch_minutes / 121 |
| F10 | 尾段动量 = close_1130 / close_1100 − 1 |

| F12 | 全日收益对照 = close_day_official / preclose_official − 1（**对照，不计入通过分子**） |
