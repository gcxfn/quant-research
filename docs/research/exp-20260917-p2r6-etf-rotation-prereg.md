## 1. 可证伪假设与基准

### 1.1 假设（方向与判据明确）

**H-R6（动量正向）**：在按 §2 规则构建的历史时点（PIT）ETF 池上，按动量（买过去强的、不买弱的）排序的 Top3 等权轮动组合，在 dev 窗口（2016–2020）费用后对同池等权基准的年化超额 ≥ +2.0 个百分点，且多数日历年超额为正（≥4/5 年）。

证伪路径（任一成立即假设不成立）：
- 毛口径（扣费前）超额 ≤ 0——与个股五轮结论同构，ETF 截面同样是反转/无梯度结构，动量在该资产层不存在；
- 费用后超额为正但 < +2.0pp/年，或优势年 < 4/5——梯度存在但不足以构成可交付的方向；
- 绝对收益为负（净年化 ≤ 0）——相对优势无意义。

背景与为何值得检验（一次性说明，不构成额外配置的理由）：第 4 轮个股普查显示个股层面动量 IC 为负（反转结构、Q5 崩坏），但那是 3–10 日持有期的个股截面；ETF 是指数级工具，截面维度（资产类别/行业主题）与持有期（月频）均不同，且消除了个股特有崩坏尾部。旧 V3 月频轮动是被标记幸存者偏差的方向级线索。若本轮也证伪，则"动量"在该账户可及的全部资产层（个股、ETF）均无费用后证据。

| 滑点 | 0 | 与 P2 前五轮一致；P3 才引入三档敏感性 |

**披露**：佣金与最低佣金为用户确认的账户实况（2026-09-17）；无印花税/过户费与 tick 为制度事实；滑点 0 为与前五轮一致的研究假设。Top3 名义（≈6.67 万/笔）下往返约 2bp，费用墙很低——淘汰判据重心放在绝对收益、稳定性与回撤（§6），费用不是主要解释变量（这与个股五轮"费用吃掉边际"的失败模式不同，须在结果文档中明确对比说明）。

## 6. 淘汰标准（数值判据，运行前固定）

**dev gate（全部满足才可进 validation；12 配置逐一独立判定）**：
1. dev 净年化 > 0（绝对收益为正，否则无论相对优势直接死）；
2. dev 年化净超额（对 B1 同池等权）≥ **+2.0pp**；
3. dev 5 个日历年（2016–2020）中净超额 > 0 的年数 ≥ **4**；
4. dev 最大回撤 ≤ **20%**（账户回撤预算，主计划第四次更新）且 ≤ dev 期 B1 最大回撤；
5. 换手：年单边换手 ≤ **1200%**（全配置统一上限）；月频配置另须 ≤ **600%**；
6. 收益集中度：净利润 top-1 标的占比 ≤ **40%** 且 top-3 合计 ≤ **70%**；
7. 对 B3 随机基准：dev 净年化 ≥ 随机 20 种子均值 + **1.0pp**；
8. 执行完整性：计划再平衡的实际执行率 ≥ **95%**（因停牌/缺数据未成交按跳过记录）。

**validation gate（判据固定，不得调参；dev 通过者若多于 1 个，取 dev 净超额最高 1 名进入，其余标记 dev-pass-not-advanced 并全量披露）**：
1. val 年化净超额（对 B1）≥ **+1.0pp**；
2. val 两个年度（2021、2022）净超额均 > 0；
3. val 最大回撤 ≤ 20%；换手与集中度不超 dev gate 第 5/6 条同值上限。

**test 规则**：val 通过的配置在 2023-01-01..2024-12-31 **只跑一次**：test 净超额 ≥ 0 且 test 最大回撤 ≤ 20% 才宣布"P3 候选"；test 失败即方向死亡，不得回头改参数或换段重跑。

**多重测试纪律**：12 个预登记配置全部评估、全部披露（含毛/净、逐年）；进入 P3 的存活者上限 **1** 个；任何事后重挑、加窗、改判据均降级为探索性。若 12/12 淘汰，ETF 轮动方向按主计划 §6 负面淘汰留档并回讨论层，不自动追加窗口、频率或因子。
