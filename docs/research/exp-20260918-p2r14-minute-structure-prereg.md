## 2. 六个判定单元（阈值全部取自提案原文冻结）

**U1 H-40 尾盘量占比**：close_share30 对 T2（次日 open_930→close）rank IC ≤ −0.02 且 NW(5)|t|≥3；方向对齐年化毛 D10−D1 ≥4% 且同号月 ≥60%；增量门：对 log(amount)+当日收益正交化残差 |IC|≥0.015。
**U2 H-41 拉尾盘事件**：事件=last30_ret ≥+1.5% 且全日收益 <9% 且 tail_amt_share ≥20%；对照=同日全日收益 ±0.5% 桶未触发者；事件−对照 T2 ≤ −0.5pp 且 NW|t|≥3、逐年同号 ≥4/6；事件基率 <0.5% 判样本不足不立项。
**U3 H-42 触跌停冻结**：pm_touch_limit_down 组 vs 当日收益 ±0.5% 桶且 low>limit_down×(1+0.3%) 对照：次日（次开→次收）差 ≤ −0.5pp 且 t≥3、同号 ≥4/6；事件 ≥500 股票日；最重单月占比 >30% 登记聚集风险。
**U4 H-43 涨停三分（裁决性，双向门）**：炸板组 T2 − 同全日收益桶（5–9.5%）未触组 ≤ −0.5pp **且** 封板组 T2 ≥ 未触组 +0.5pp，两组同时成立才登记；炸板组亦正 → 假设死。附带裁决：F09-T2 正读数是否混合假象（无论门过与否都写结论）。
**U5 H-44 早盘波动集中度**：am_range30 对次日振幅 rank IC ≥ +0.02 且 t≥3；对 vol20+当日振幅正交化残差 ≥ +0.01；用途门：对池内最弱上午十分位（R10 宿主代理，操作化披露）上四分位剔除后单笔 P5 改善 ≥10% 且净均损失 ≤0.5pp。两门全过才有价值。
