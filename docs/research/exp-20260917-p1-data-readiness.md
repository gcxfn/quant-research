## 已验收内容（全部有测试或运行证据）

1. **冻结边界强制执行**（`src/quant/data/baostock_daily.py`）：`DailyLoader` 在读取层硬过滤 `date <= 2024-12-31`。合同测试用含 2025 行的伪造 CSV 验证冻结行永不出现在下游。真实样本 `date_max` 实测 2024-12-31。
2. **确定性 200 只样本**：排序代码 + 首行≤2022-01-04 + 末行≥2024-12-31 + 步长 20；排除 688/689 科创板。选择函数本身有真实数据合同测试（数量、去重、排除、确定性）。
3. **列名契约对齐**：读取层把 baostock 的 `code` 规范化为因子层的 `symbol`；真实样本端到端通过（compute_factors 直接可用）。
4. **数据集指纹**：`daily_dataset_id` 按排序后 symbol 逐组哈希 IPC 序列（date,close），行序不影响身份；测试验证确定性、内容敏感性、排序不敏感。真实样本指纹 `f6d218825840dcdb`（72.46 万行）。
5. **状态字段可读**：真实样本 200 只含 16,793 行 ST 标记、25,296 行停牌（tradestatus=0），为 P2 池过滤提供时点状态。
