## 一、研究纪律（所有实验共同遵守）

| 规则 | 内容 |
|---|---|
| 预登记 | 假设、参数、判据**运行前冻结**；跑完不许回头改；不事后挑好看的组 |
| 时间三分 | 开发期 2015-2020 / 验证期 2021-2024 / 冻结区 2025+ |
| val 是底牌 | 验证期数据消费须用户批准，每消费一次少一次；**dev 过门才有资格消费 val** |
| 单次运行 | 每个预登记 dev 只跑一次；失败不调参重试；实现 bug 可修但须留痕并全部重跑 |
| 真实执行 | 不假设触价成交、不取更有利价；费用全算（万 1 佣金最低 5 元、卖出印花税 2015-2023.08 按 0.1% 此后 0.05%、ETF 免印花）；T+1、涨跌停、停牌保守处理 |
| 数据 PIT | 财务用真实披露时间（ann_date）；ST/上市状态用历史时点；池、标签、成交不跨时间边界 |
| 台账 | 每条判定曲线计数入账；失败记录同样归档，禁止只展示最优 |

## 二、账户与执行契约（当前有效文本）

- 账户：默认初始 50 万；总仓位 ≤100%；单标的 ≤25%；
  持仓 ≤7 只（进攻 ≤4 只股票、防御 ≤3 只 ETF）——K=10 曾按用户
  指示实验性放宽，契约文本未改；
- 决策点：Day0 收盘（生成次日计划）、Day1 11:30 与 15:00；每个
  决策点只用已完整结束的行情；
- 订单：半日限价单，**严格穿透才成交**；风险减仓单三半日未成交
  走开盘兜底，止盈单到期失效；同一半日不改性；
- ETF 配置腿（2026-09-21 决策）：可按**市价成交**（次执行点收盘
  ±千 1 滑点，涨跌停边/停牌不成交）——限价穿透语义对股票继续有效；
- 三层风控：单标的（止损/止盈/移动保护线）→ 袖套（进攻/防御分账）
  → 账户级（单日/阶段/高水位回撤降仓，已预登记三档）；
- 第一阶段只研究验证，不接券商、不自动下单。

## 四、核心科学结论（跨实验）

1. **信号在截面平均、收益不在头部**：A 股量价/基本面截面信号真实
   （IC 五年全正），但利润分布在全市场几千只的平均里；个人账户
   集中多头（前 4-10 名）取到的是模型最不确定的头部；
2. **反转的利润在空头端**：避开会继续跌的——纯做多账户结构性拿不到；
3. **dev 优势可能是风格**：C1 的 +16%/四年全赢在 val 归零反转
   （−5%/0/4）——四年长度都不足以区分能力与风格；
4. **合成器与真实执行差距 4-5pp/年**：ETF 动量的 +13.3% 到引擎
   剩 +4.7%；任何"月末瞬间换仓"假设的策略都要打折；
5. **50 万资金不改变结论**：K=10 即等价实验；最低佣金 5 元在
   单笔 5 万以上不再绑定；
6. 拥挤与 T+1 是日频形态的结构性成本（未测部分见第六节）。
