## 3. 组合规则（冻结）

- **信号网格** = dev 月末交易日（P3R2 先例：2020-12-31 丢弃为信号、保留为到期锚；
  最后一信号 = 2020-11-30）。
- **可执行池(t)** = R16 `signal_pools` 冻结口径逐字（主板、isST=0、上市>120 交易日、
  20 日中位成交额 ≥5000 万、收盘 ≥2 元）∩ **组合覆盖**（该股当月末 ≥ ⌈M/2⌉ 个代表因子
  非空；M=代表数。覆盖规则只用代表可用性，与臂无关，两臂共享同一池）。
- **定向与标准化**：代表 i 在可执行池截面内取秩百分位 p∈[0,1]，分量
  x_i = (p − 0.5) × sign(ic_i)（ic 取 F2R1 ic_mean；有界、稳健、与评估口径同族）。
- **主案 F3-EW**：组合分 = 可得分量等权均值。
- **对照 F3-ICW**：组合分 = Σ(|icir_i|·x_i)/Σ|icir_i|（可得分量内归一；icir 取 F2R1 冻结值）。
  **运行前澄清补钉（2026-09-19，未发生任何运行）**：x_i 已按 sign(ic_i) 定向（高分=预期好），
  故权重取 |icir|——若按带号 icir 加权，原负 IC 因子的定向分量会被反向加权，与本臂
  "按预测强度加权"的语义相悖。
- **排序**：组合分降序，并列按 symbol 升序（决定论）。
- **持仓规则（两臂同）**：K=10 席、等权目标 0.10/席；入池 = 组合排名 ≤10；
  离池 = 排名 > 20（2K 缓冲带，复用 R16 `buffer_membership` 原语、q5 过滤关闭）；
  **无月中再平衡**——存续席权重随价格漂移不修正（登记映射注记：省意图、低估换手）。
