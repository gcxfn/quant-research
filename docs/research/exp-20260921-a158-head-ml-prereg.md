状态：**已冻结（运行前）**。用户 2026-09-21 批准执行。

## 1. 可证伪假设

Alpha158 特征集的排序信号真实（Rank IC 0.046，t=4.94，五年全正）但消费端
（top4 集中多头）不盈利（dev 回放净年化 −0.34%）。假设：失败原因之一是
训练目标（全截面回归排序）与消费方式（只要前几名）不对齐；把标签改为
"是否进入截面前 20%"的二分类、模型改为概率分类器后，同样的特征、池、
结构与判据下，top4 回放净年化转正并过八门。若八门失败，量价机器学习
路线在集中多头结构下正式关闭（第三种也是最后一种形态）。

## 2. 相对 alpha158 版（20260921T125117）的全部改动（冻结，仅此四处）

1. 标签：每月截面 `y = 1 if FWD[t][s] >= 该月截面 80 分位 else 0`
   （训练截面二值化；预测月不需要标签）；
2. 模型：`objective="regression"` → `"binary"`，
   `LGBMRegressor` → `LGBMClassifier`，输出 `predict_proba[:, 1]`；
3. `ml_scores.json` 内容由回归分数改为概率（键结构不变，回放端零改动）；
4. 评估新增两个**只报告不设门**的指标：top4 命中率
   （被选股票次月收益 > 截面中位数的比例）与概率 top4 月均收益
   对全池等权的超额。

以下逐字节不变：158 特征与截面计算、特征截面 rank 归一化（NaN→中位 0.5）、
滚动训练 ≤24 个月截面且预测下月、超参（n_estimators=300, lr=0.05,
num_leaves=31, min_child_samples=100, feature_fraction=0.8, random_state=7）、
股票池（R16 历史池）、K=4 buffer 席位（入前 4 / 出排名>8）、MF 腿结构、
宽止损（3×ATR20, 10%..20%）、账户级 D3、40/60 防御配比、费用
（万 1 佣金最低 5 元 + 卖出印花税 0.05%）、band_engine v1.5
`f3650f8440c713b8` 半日时钟、八门判据与 B1mix/B3' 基准。
