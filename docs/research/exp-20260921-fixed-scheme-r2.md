# 探索结果：放宽止损 × 降低调仓频率（exp-20260921-fixed-scheme-r2）

## 结论

两项干预都如期改变了行为（止损次数 −63%~−65%、换手 −24%~−45%、回撤
改善），但**净收益没有恢复**——"止损-频率冲突是主要死因"的诊断被本轮
证伪：真正的死因是**股票腿选股信号本身没有正超额**。

## 解读

1. **放宽止损：行为大改、收益不变**。止损 365→127 次，但 R2A 收益
   +2.70% ≈ 对照 +2.74%——止损减少的割肉损失被"跌而不止损的继续
   持有"几乎等额抵消。+2R 止盈在放宽后**仍然为 0 次**：不是止损把
   盈利单提前打掉，而是持有期内根本走不出 +2R（约 +20–40%）的行情。
2. **季度调仓：回撤 −17.4→−13.4%，收益 +2.74→+1.52%**。低频换仓
   减少了交易摩擦与追高，但也错过月度信号的部分反弹段；净效应为负。
3. **对月度基准的超额在所有变体上稳定在 −2.7 ~ −3.2pp**：无论止损
   与频率如何，这个混合结构里的股票腿都跑不赢"同池等权 + 防御 60%"
   的理想基准。F3-ICW 因子组合（乃至其前身 F3 系列）在该账户结构下
   不提供正选股超额——这是方向性结论，不是参数结论。

  （当前 20 代表因子组合两轮全灭后，因子线本身需重新审视）；c) 结束
  该方向、复盘全部证据后另起课题。
