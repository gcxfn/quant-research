## 5. 偏差与实现决定披露（预登记未覆盖处，逐条；判据/阈值/池零改动）

1. **C05 分母数据源**：冻结公式"应计=(净利−经营现金流)/总资产"需要总资产，而配置数据清单中的
   cashflow/income/daily_basic 均无该字段；采用同批次族 `balancesheet/20260909-r3`（在库、sha256
   对账通过，行级与 cashflow 按 (ts_code, end_date) 内连）。income 批次经核实无公式所需字段，
   未消费（仅 manifest 级校验）。公式与阈值一字未改。
2. **C03 跌停阻断代理**：提案原文点名用 stk_limit；配置数据清单未列。采用 `xiaodefa/stk_limit/
   20260913-bulk1`（按列名归一、含唯一空表头文件 chunk_20220705 显式列名读取、sha256 对账通过）。
   主代理 = 计划退出会话（t+5）收盘封死跌停（close ≤ down_limit）；"任一可卖日（t+2..t+5）封死"
   变体同时披露（dev 1.32× / val 1.56×，同样 <2×，不改变结论）。
3. **C05 金融业剔除**：tushare stock_basic 无行业字段；按任务指定改用 xiaodefa stock_basic
   （20260913-bulk1，L+D 块）行业快照，剔除 {银行, 保险, 证券}（现时快照、非 PIT，已披露）；
   行业字段缺失的股票 fail-closed 剔除（A股 336 只，对应队列行 2,511）。
4. **C05 多版本报告的 ann_date**：同一 (ts_code, end_date) 存在多版本行（更正公告 ann_date 为
   更正日）。实现取最新版本的 ann_date（与最新数值配对，防泄漏的保守口径）。实测该口径使
   p90 队列行 PIT 较期末晚 2.3–2.8 年（FY2018 有 15.6%、FY2019 有 21.1% 的行 PIT≥2021），
   产生 §3 所示 FY2017/2018 尾部落入 val 的现象。替代口径（首版按首发日）未被消费：主判据
   1.02× 距 1.5× 门差距悬殊且对时点口径不敏感，按"偏差先披露后消费"留档不重跑。
5. **匹配器细节**（预登记只定"同日、ret5 十分位 × circ_mv 五分位"）：1:1 就近匹配（同格内
   |ret5 差| 最小，平局取 symbol 小者），对照可复用，无对照事件剔除并计数（各单元 2–328 条）；
   Bootstrap 2,000 次、种子 17、按信号日整簇重抽。
6. **C01 事件粒度**：每个解禁组取"否决器首个激活日"为事件（非窗内逐日），激活日 = max(公告后
   首个会话, float−21 会话) 且严格早于 float≥2 会话；窗内其余天仅进 C06 的 v1 标记。
7. **C04 去重与分段合并**：同 (ts_code, ann_date) 多行合并为单事件（取最大 change_ratio）；
   G/P 副命题合并 G、P 两类；"分段各判"实现为 pre 与 post 两段都须过主门（更严格的诚实读法），
   pre 段无 val 覆盖，val 只判 post（披露）。
8. **C06 宿主起点**：全族覆盖交集为 2019-01-01（disclosure_date 覆盖限制），C06 的 dev 实际为
   2019–2020 两年；"P5 改善"注册为 (P5保留 − P5宿主)/|P5宿主| ≥ 10%；费用后（万1最低5元+
   印花分段，2 万名义）为附注：dev 剔除组净均值 −0.45% vs 宿主 +0.26%（剔除本来有利但尾部
   改善不达标），val 剔除组净均值 +0.16% vs 宿主 −0.01%（剔除反受损失）。
9. **收益与复权契约**：信号 t 收盘生成、t+1 开盘入场、t+N 收盘退出（5 日 = t+1 开 → t+5 收）；
   复权沿 P1 契约（adj = 价 × xiaodefa adj_factor，比率水平归一自由）；sh.600069 因深扫登记的
   因子振荡缺陷被 fail-closed 整体剔除（1,378 行）。
10. **事件入池衰减**：事件须在信号会话位于注册池（主板、非 ST、非停牌、20 日中位成交额
    ≥5,000 万、上市>120 日、协变量齐全）才可配对。forecast 族通过率约 31%（首披即负
    14,881→4,578；下修 887→284——预告集中在业绩季，小市值/ST/停牌占比高），holdertrade
    C-DE 为 39%（14,269→5,555）。所有判定均为"池内条件收益差"，与预登记的池定义一致；
    衰减比例在此显式披露。
11. **失败留档**：同日 3 个更早 run（§前言所列）在列名校验阶段失败，无任何部分指标，全部保留
    在案；完成 run 以 e8a4f049 为准。

## 6. 解读（非盈利结论）

- 五个事件否决器在冻结阈值下无一达标。方向上仅 C02（下修）与 C05（60 日副判据）呈现与
  假设同向的描述性读数：C02 dev 样本不足（168<300）按条款不判活（描述性：深下修 dev
  −0.62pp vs 首披即负 −0.005pp，差 −0.62pp 达到"劣于首披 ≥0.3pp"的方向；val 深 −2.94pp vs
  首披 −0.05pp，但按纪律不作判定）；C05 主判据（发生率比 1.02×，5 年无一≥1.5×）以大差距
  失败——"应计极端组是坏消息供给端"的机制假设在其主判据上不成立；其 60 日收益跑输
  （−1.9～−2.1pp）作为副判据为真，留档但按"主判据过即过"不改变判定。
- C03 的两个风险面（尾差、阻断率）方向一致但量级只有门限的 60% 上下；C04 在 2017 新规后
  段方向反转为正，与 E3/MC8 的方向性缺失结论一致。
- C06 链效应的失败集中在尾部改善不足（3.7% vs 10% 门）：五标记合计剔除约 11–12%，被剔组
  均值确实更差（dev），但左尾压缩幅度不足以满足预登记门槛。
- 按停止条款：**事件否决链线关闭**。五个标记保留为"已测无效"；若未来要重开（例如 C02 在
  数据扩展后样本充足时），须重新预登记，本档 val 描述性数字不得作为通过证据引用。
