# T1 下游预登记：业绩预告归因的事件研究——"归因标签有没有 type 之外的增量信息"

- 实验 ID：exp-20260920-t1-reason-event（本文件，2026-09-20 冻结）
- 上游：T1 数据集 `data/features/fcst-reason-struct-full-20260918/`（65 批 38,567 行收官，[SUMMARY](../../data/features/fcst-reason-struct-full-20260918/SUMMARY.md)）；用户批准（2026-09-20 对话："批准t1"）
- 试验计账：因子线 FT-02（沿 FT-01 先例；事件研究为 1 项试验，敏感性不另计）

## 1. 背景与可证伪假设

- 背景：F2R1 的 E 族预告类因子死于月频覆盖门（forecast 表 2018-09 起），已知教训在案；T1 的 38,567 行归因标注（primary/secondary 15 类 + sd + confidence）尚未回答一个问题——**它的信息量是否超过 tushare 自带的 type 字段（预增/首亏/…8 类）**。若不超过，标注无交易价值；若超过，下一步设计归因因子进 F3 管道的形式（另行预登记）。
- **H1（主假设）**：控制 type 后，primary_code 对公告后 20 日收益仍有区分度——按 §5 主判定（type 组内去均值后的类别 ANOVA）p < 0.05。
- **H0**：公告后漂移完全由 type 解释，primary 无增量（p ≥ 0.05）→ T1 结论为"标注质量合格但无 type 外交易信息"，E 线关闭。
- H0 是可接受结局，不存在凑显著动机。

## 3. 分组结构

- 基准层：type 8 类（预增/首亏/预减/续亏/略增/扭亏/略减/续盈；"不确定"535 行剔除并披露）的原始漂移——sanity 方向：预增组 > 预亏组（文献共识方向，只验证不判定）。
- 主检验层：**同 type 内按 primary_code 分组**（15 类词表沿 schema.md；dev 内每类事件 ≥100 才进两两比较，不足 100 并入 other 并披露）。
- 次检验层（探索性，标注为准不判定）：sd（+1/0/−1）与 confidence（high/low）的漂移差——验证 SUMMARY 的"sd=−1/low 行为异常"预警。

## 4. 统计口径（冻结）

- 时间聚集处理：事件扎堆于 1/4/7/10 月披露季，收益先**按公告月减去该月全体事件均值**（月份固定效应），再做类别检验。
- 主判定：月度调整收益上，type 组内去均值后的 primary_code 类别间 ANOVA F 检验 p < 0.05 → H1。
- 类别级报告：每类 vs 同 type 其余的均值差 t 值，Benjamini-Hochberg 校正（15 类），仅报告不单独判定。
- 分年稳定性：2018（9-12 月）/2019/2020 三段类别均值方向一致性（描述性）。
- 集中度：各类别内收益的股票集中度（top 股贡献占比）披露，防单票驱动。

## 5. 冻结判定线

1. 主判定：§4 ANOVA p < 0.05 → H1 成立 → 下一轮预登记设计归因因子进 F3 管道；p ∈ [0.05, 0.20) → 边缘，呈用户；p ≥ 0.20 → H0 成立，E 线关闭。
2. 敏感性（不改变主判定，仅披露）：剔除 sd=−1 与 low 行后重跑；h=5/10 短窗；不去重的原始样本。方向反转（敏感性下主判定翻转）→ 结论降级为"脆弱"，如实呈报。
3. 边缘案例与任何口径疑问 → 停机呈主对话裁定。
