## 7. 实现决定与偏差（全部先披露、后消费；判据/公式/池零改动）

1. **预热数据文件**：250 日滚动高、60 日隔夜和与 1999 年起的上市序号需要 2015 年前历史；冻结配置点名的 `daily_2015_2024.parquet` 无法产出 2015 年信号的 C2，与冻结覆盖声明（C1/C2/C6 自 2015-01-05 全窗）冲突。改用同目录、同一 manifest 身份的 `daily_1999_2024.parquet`（sha256 入 run manifest），并断言其 2015+ 切片行数与点名文件一致（9,532,019 行）。R10 有同一先例。
2. **历史窗 own-session 约定**：C1 60 日、C2 250 日、C6 20 日、流动性 20 日中位、上市序号一律按个股自身成交日推进（停牌不计入），与 R10 惯例一致。
3. **hk_hold 披露滞后 = T+1**：月末信号 s 只用 s−1 与 s−21 两个交易日的披露值（保守读法）。
4. **金融业剔除来源**：xiaodefa `stock_basic`（东财行业，2026-09-13 快照，sha256 入 manifest）行业 ∈ {银行, 保险, 证券, 多元金融}（共 120 只）；非 PIT 快照近似，仅作用于 C4 截面（剔除 9,996 行）。
5. **冻结边界**：`build_history` 结构性丢弃 ≥2025-01-01 行；2024-12-31 月末信号被丢弃（其 T+21 开盘越界），最后判定月 = 2024-11。财务表读取时过滤 end_date ≥ 2025-01-01。
6. **执行口径**：入场要求信号次日该股有成交（mkt_idx=s+1），否则前瞻置 null 计入覆盖；出场为首个 mkt_idx ≥ s+21 的自身成交日（停牌顺延）。本普查不建模涨跌停开盘阻断（因子候选轮；组合轮必须建模执行）。
7. **C3 弃判规则操作化**（本轮唯一的方法学偏差，披露如下）：预登记"缺失率>10% 月份弃判"绑定行数完整性 probe。实现上"缺失率"若按全池分母，则每个判定月缺失 11–36%（北向披露宇宙结构性只覆盖池内约 70–88%：2019–2024 池内 27% 股票零披露行，双峰分布），C3 将整轮不可判。按预登记语境（probe=源行数完整性）操作化为**成员相对缺失率**：分母=披露宇宙成员（信号前 61 交易日内有披露行的池内股票），从未披露的股票=因子域外（资格属性），与 C5 无大宗交易股同理。该操作化在任何 C3 IC 计算之前、仅凭覆盖元数据（presence 分布+成员缺失率表）定死；未做"换时间轴约定"（个股自身披露序列 shift(20) 方案曾模拟过覆盖、同样全面 >10%，被放弃以避免事后自由度）。被废弃的前一全窗 run `20260918T070814-p2r13-lowfreq-survey-051143da`（全池分母误drop全部月份）与 `20260918T071849-p2r13-lowfreq-survey-ef284a44`（成员 asof join 缺排序导致成员数退化）均已留档，最终以 3916aadf 为准。
8. **C4 符号约定的歧义披露**：配置把负号写进公式（C4=−应计）又把方向记为 −1（"低应计→买（负）"）。本轮按配置字面实现（公式值 × −1 对齐分位）。若按经济学侧对齐（应计本身为负向），C4 分位门为 +5.27%/66.7%（过），但其 **IC 门在两种约定下都不变（|IC|=0.0175<0.02）**，故判定不受影响。C1 同理（其 |t|=2.88<3 恒拦）。
9. **冻结配置解析**：配置文件含 `"direction": +1`（非合法 JSON），以 `yaml.safe_load` 宽松解析，磁盘文件未改动（sha256 入 manifest）。
10. **run 目录命名**：首个 probe run `20260918T070109-P2-R13 G4 …-42125f13` 误用配置全名（含括号空格），不符合 run_id 约定；目录按"不覆盖记录"原则保留原状，其后所有 run 改用 `p2r13-lowfreq-survey` 短主题。
11. C4 科目口径：净利=合并 `n_income`（含少数股东），分母=`total_assets`（含少数股东权益），口径一致；年报行 report_type=1、end_date=1231、每报告期取最大 update_flag。
