# exp-20260918-nearmiss-overlap：惜败配置回撤重叠测量（"死×死组合"前置检查）

- 性质：结构性测量，**零回测、零判据消费、零新 run**。数据为已消费 dev 段（2016-01-04..2020-12-31）的既有 run 权益曲线。
- 背景：用户提问"死掉的之间/死掉×接近通过/接近通过之间组合是否有信号"。组合能改善回撤的数学前提是成员亏损期时间上错开；本测量先验证该前提是否成立，再决定是否值得为此开预登记轮。

## 方法

对象五配置：R8-C01（FIX75 锚）、R8-C09（D60-8%）、R8-C10（PDD 10%→40）、R9-C01、R9-C08（唯一 dev 全过者）。逐日净权益（R8/R9 正式 run 的 `equity_curves.parquet`，截 2020-12-31）计算日收益、滚动峰回撤；深水日 = 回撤 < −10% 的交易日。

## 结果

| 量 | 数值 |
|---|---|
| 各配置最大回撤日 | **全部为 2020-04-01（五个完全相同）** |
| 两两日收益相关 | +0.952 ~ +0.994 |
| 深水日两两 Jaccard 重叠 | 0.85 ~ 0.94 |

## 结论

前提不成立：这些配置是同一动量内核穿了不同风控外壳（收益相关 ≈0.97 的两个组合合并，回撤从 −17% 最多降到约 −16.5%）。**"惜败者相互组合"线关闭**，不再为此开预登记轮；正当组合路径仍是前瞻性新信息组合（如 R10 二轮、G2×G3 架构）。
