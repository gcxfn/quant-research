## 4. 信号→契约映射（§7.5 冻结先验 + 本节补全项）

1. 月末信号在当月最后交易日的 **15:00 决策点**进入（§7.5）。
2. buy_open → 买入限价单；锚 = 决策点价（15:00 官方收盘、11:30 用 am.close），限价按带偏移。
3. 信号持续期间**每个决策点**：全部在途单机械重锚至该时点最新价、数量按目标名义重算；同 session 内订单不可变（§7.1）。session 末失效的未成交意图在下一决策点**重挂并重锚**（信号存续期内，§7.7-M3），仅 expiry 撤销、新信号同名义覆盖。成交率回升属规则差异（vs v0 死锚、vs R16 次月开盘），入差异表披露。
4. sell_full（换期/跌出缓冲带/资格丧失）→ 卖出 **intent=risk**（K=3 session 市价兜底、开盘跌停顺延）。【本轮补全项：离场类统一风减语义，延续 P3R1 的 K=3 兜底，避免未成交仓位无限滞留】K=3 计数键 = (标的, intent, 来源信号)，机械重锚不重置、同名义新信号重置（§7.7-M1）。
5. rescale 增持 → **加仓 clip**（信号驱动，不限回踩）；减持 → **风减单**减至目标权重（intent=risk）（§7.5）。
6. expiry = 下一个月末信号日；到期未成交撤单、新信号同名义覆盖。
7. 上限（§7.7-M2）：总仓位 ≤100% ≡ 现金非负 + 费用预留（买单占用 = 限价×数量 + max(限价×数量×万1, 5 元) ≤ 可用现金）；单票 ≤25% 在订单构建时按决策点权益快照校验，越限**整单作废**并计数披露；漂移越限不强制减持、仅记录；引擎不做上限裁剪式部分成交。
8. 利润梯（intent=profit）原语本轮**不被 R16 信号映射使用**（R16 无止盈梯信号）——登记为映射空洞，非原语无效；因此 §7.7-m2 双卖意图并存重估场景本轮不出现（重估主体=宿主下一决策点，引擎不代做）。
9. 卖出资金次 session 可用、同 session 禁买（§7.2）；股票逐 clip T+1。
