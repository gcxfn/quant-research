# F3R3 动态引擎因子组合重测结果（exp-20260921-factor-round-f3r3）

## 结论

**F3R1 的淘汰结论在重建后的动态引擎上成立。** 两臂仍 0/8 门淘汰，
10% 收益目标未达到，验证集零接触。动态执行模型修复了执行率门
（75–77% → 96.9%），但换手门恶化（席位置空被重发消除后换手上升），
净收益普遍下降：旧引擎的高收益有一部分来自未成交座位的意外空仓。

运行目录：`artifacts/runs/20260921T024449-f3r3-dynamic-45037d/`
（50.5 秒、峰值内存 3.85GB、manifest 时间戳已修复为真实 UTC 时钟）。

## 与 F3R1（旧引擎 v1.3 静态帧）的逐项对照

组合、去重（43 存活 → 20 代表，确定性重算与 F3R1 完全一致）、基准
（B1(m) +1.66%、B3′ −1.89%，两次独立运行 bit-exact 相同）全部不变；
唯一差异是执行模型（半日时钟 + intent_provider 席位重发）。

| 指标 | F3-EW 旧 → 新 | F3-ICW 旧 → 新 |
|---|---|---|
| 净年化 | +9.47% → **+6.50%** | +15.28% → **+8.52%** |
| 最大回撤 | −39.75% → −38.84% | −41.19% → −39.50% |
| 单边年换手 | 5.77 → **9.58** | 6.21 → **9.93** |
| 单票最大权重 | 24.0% → 14.5% | 22.4% → 16.4% |
| 门8 执行率 | 74.9% → **96.9% ✓** | 76.7% → **96.9% ✓** |
| 失败门 | 3、4、8 | 3、4、5、8 |

（失败门编号：3 优势年 ≥5/6；4 回撤 ≤20% 且 ≤基准；5 换手 ≤6；8 执行率 ≥95%。）

F3R3 两臂失败门均为 **3（优势年）、4（回撤）、5（换手）**：
F3-EW 新增换手门失败，两臂的执行率门均转为通过。

## 归因与解读

- **执行率门修复的机制**：买入意图半日失效后由 provider 从真实账本
  （cash / equity_snapshot / positions）判断席位仍空即重发，6 年窗口
  2924 个决策点、每臂 2632/2855 条意图注入、座位执行率 96.9%
  （F3-EW 1066 座位：成交 1033、过期空座 33）。
- **收益下降的机制**：旧引擎下整月未成交的买入座位等于整月空仓避险；
  动态重发把这些座位补齐建仓，额外建仓的组合贡献为负。ICW 降幅更大
  （−6.8pp），说明其超额部分更依赖这种执行摩擦的幸运面。
- **换手上升的机制**：成交及时后月度换仓完整执行（旧引擎部分换仓被
  未成交稀释）。换手 9.6–9.9 超过门 5 的上限 6。
- 停牌持仓估值：冒烟暴露 am 快照守卫把正常停牌当数据缺陷；已修复为
  冻结最近成交收盘（无未来信息），交易日照缺 bar 仍拒绝（合成测试
  d8/d8b，全仓 617 passed）。
