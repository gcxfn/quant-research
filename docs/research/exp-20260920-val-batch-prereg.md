## 2. 判据（冻结，逐字沿 R16 `evaluate_val_gates`，与 TL-30 同源）

1. `1_excess_ge_1pp`：净年化超额 vs B1(m)(val) ≥ +1.0pp；
2. `2_advantage_years_ge_2_of_4`：优势年（逐年净收益 > B1(m)(val) 同年）≥ 2/4；
3. `3_mdd_le_20pct_and_le_B1m`：maxDD ≤ 20% 且 ≤ |B1(m)(val) maxDD|。

非门披露项（照算照报不进判定）：净年化 vs 10% 目标列、逐年收益表、换手、单票权重、门 8 v3 口径算术；F 线另报 dev 败点（门 3/8）在 val 窗的对应表现与归因事件标记在 val 的覆盖统计。

## 3. 基准与端口验证纪律（先 dev 复现、后 val 消费）

- B1(m)(val)：`simulate_r16(fractional=True, fee_bands=RATE_ONLY, T200-40)` 于 val 窗现算；端口验证=同装配 dev 窗重算须逐位复现 R16 metrics.json configs.C05（容差 1e-9）后才算 val（TL-30 §4 逐字先例）。TL-30 已得 −0.148%/−23.44%，本轮重算应逐位一致，不一致即停。
- 混合族 v3 4 臂：轮动 ETF 配置零新参数，val 窗直接跑（TL-30 runner 派生先例）。
- H2-01/03/04：先建 R16 信号层 val 端口，**dev 窗端口产物须逐位复现其 v2 dev run 对应臂**（1e-9/逐字节按帧类型沿 v2 口径）后才展开 val；复现不了 → 该配置停机呈报，不消费。
- F 线：
  - 17 因子 val 分数：F2R1 因子管道对 2021-2024 展开；**dev 端口验证=重算 dev 分数须逐位复现 F2R1 原产物**（FA-S2 先例）后才展开 val。
  - 归因事件 val 标记：T1 全量 38,567 行中 2021-01-01..2024-12-31 子集（约 20,985 行）按事件研究同口径构建（去重/池过滤/60 日窗）；dev 端口复现 events_dev（6,664 事件逐位）后展开。
  - 各臂 runner：F3R1/F3R2/F3R3/F3R4-A 的历史 runner 换 val 窗与 val 输入（因子分数/事件标记/composite 生成对 val 重做；F3R4-A 的 b 冻结值 0.10164738676824621 沿用不重估）。

- 12 个全部报告，不挑选、不排序叙事；三门逐字判定。
