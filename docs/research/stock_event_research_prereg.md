## 2. 主判据（事前固定，Dev 2015-2020）

每个候选输出：全账户日权益、股票/现金暴露、订单生命周期、
净 CAGR、日频最大回撤、回撤持续、分年收益、换手、未成交损失
归因、退出原因计数（修复版 reason 口径）、与同风险暴露基准差。

淘汰线（同时不满足即淘汰）：
1. 费用后净 CAGR > 0 且 > BM1（修复后 FULL-bin 基线）；
2. 分年超额 vs BM2 ≥ 4/6 年；
3. 日频最大回撤 ≤ 25%（Dev 探索档；10%/20% 是研究总目标，
   不在本轮门内事后追认）；
4. 订单执行率 ≥ 90%（席位-信号口径，与基线同式）；
5. 硬约束零违例（引擎 fail-close 语义下无 cap/现金违例存活）。

主评价持有窗口：**20 个自身交易日**（B 家族另报 5/10/40 为
诊断，不用于判定）。稳健性＝邻域扰动点方向一致（净 CAGR
符号不变）＋成本压力下仍过线 1。

## 3. 家族 A：相对强势 + 波动收缩后的趋势延续

假设 HA：处于 60 日相对强势前列且刚经历波动收缩的个股，突破
确认后的趋势延续在费用后、合法执行下为正。

冻结定义（每月末信号日截面计算资格，日频观察触发）：
- 相对强势：过去 60 个自身交易日收益的截面分位 ≥ 0.80；
- 波动收缩：近 10 日平均真实波幅 / 近 60 日平均真实波幅
  ≤ 0.70；
- 触发前提逐日检查（Day0 收盘后），成交只允许下一半日。

**A1 突破参与**：日收盘创 60 日新高且当日量 ≥ 20 日均量 0.8
倍；限价 = 触发日收盘 × 1.01（追价上限）；失效：连续 3 个半日
未成交，或收盘回落至突破位 − 1×ATR20（保留现金，不回填）。
邻域扰动点：① 收缩阈值 0.60；② 3R 清仓→移动保护线
（+1R 后保护线随 20 日高点 − 1×ATR20 跟踪，不设全部清仓的
固定百分比）。

**A2 回踩参与**：突破（同 A1 定义）后 10 个自身交易日内收盘
回落至突破带（突破位 ± 1×ATR20）且保持在 20 日均线上方，随后
收盘重新收于突破位上方时触发；限价 = 触发日收盘 × 1.01；失效
同 A1，另加：回落跌破 20 日均线即失效。邻域扰动点：① 回踩窗
15 日；② 移动保护线变体（同 A1②）。

持有期设计：数周（退出由个股规则与席位复核驱动，非日频换手）；
月频席位复核时 A 家族持有者不因月度排名退出（只有跌破退出
条件才退），防止把周线形态切成月频轮动。

## 4. 家族 B：带版本时间戳的业绩变化 + 价格确认

假设 HB：同一财务期业绩预告的**可核实上修**（B1）或改善归因
+ 短窗价格确认（B2）在合法入场后 20 个自身交易日内有费用后
正超额。

**覆盖披露（不能把样本集中于开发期末当成六年独立证据）**：
T1 事件表的 ann_date 自 **2018-09-04** 起（dev 内 17,582 起原始
公告、池过滤后 6,664 起、27 个公告月）。因此 B 家族在 dev
2015-01—2018-08 **零事件**，其全部证据实为约 **2.3 年**
（2018-09—2020-12），分年评估中 2015—2017 无样本、不参与分年
门；B 家族的淘汰线只在有样本年份上评估，报告必须逐年列样本量。
A 家族不受此限（价格数据全期覆盖）。

数据纪律（承接 T1/F3R4，不重新开题归因本身）：
- 保留历次公告（按 ann_date + update_flag 排序），禁止先按最终
  公告覆盖历史；
- 保守时钟：ann_date 当日收盘后才视为可得，最早决策点 = 下一
  交易日 11:30；非交易日公告顺延至下一交易日；
- B1 上修定义：同一 (ts_code, end_date) 至少两次预告，后公告
  type 严格改善（略增→预增、预减→略增、首亏→预减、续亏→扭亏
  等按 type 收益字典排序）或净利润区间中位数上移且区间下限
  不降；只用公告时点已知的版本；
- B2 定义：type ∈ {预增, 扭亏} 且 T1 归因 primary_code 为改善类
  （impairment 方向为正类），加价格确认：公告后 5 个自身交易
  日收盘收益 > 0 且 > 当期池中位数（确认窗结束才决策，仍是
  下一半日执行）。缺一致预期数据，不使用"超市场预期"标签。

B 家族入场：限价 = 决策日收盘 × 1.01；失效 3 个半日；持有主窗
20 个自身交易日，个股退出规则同 A（止损/保护线仍生效）。
邻域扰动点（与 §0 预算表一致）：B1① 上修判定严格版（净利润
区间中位数上移且区间下限必须上移）；B1② 20 交易日冷却窗内
重复上修只取首次；B2① 确认窗 10 日；B2② type 集缩至{预增}。
（消融项"B2 去价格确认"单独入账，与上述扰动点互不重复。）

执行预算说明：B 家族在 Dev 的事件数，去重主样本 6,656 起
（漏斗口径池过滤通过 6,664 起、去重差 8 起，源
`20260920T113527-t1-reason-event-b690` run.log 漏斗与 S1 段；
两数口径不同，报告引用时须注明用的是哪一个），预计月均数十个
触发，4 只上限与现金竞争由引擎现有优先级（先到先得 + 价格
优先）处理，未成交不回填。
