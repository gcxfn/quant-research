# 账户级风险覆盖预登记

experiment_id: exp-20260920-account-risk-overlay  
状态：已根据用户确认建立，尚未运行。  
研究目标：在不改变股票因子、ETF 防御底盘、费用、成交和 T+1 语义的前提下，验证账户级降仓能否降低 F3 组合回撤，并保留费用后年化 10% 目标。

## 1. 固定范围

- 输入策略：沿用当前 F3R2 混合底盘的同一进攻层和防御层；不新增因子，不调整股票排名、ETF 候选、持仓数量和单票上限。
- 账户：研究初始权益 500,000 元；总仓位不超过100%；单只标的不超过25%。
- 成交：沿用已验收的半日引擎、T+1、涨跌停、停牌、整手、费用和未成交处理；不得使用分钟路径补成交。
- 样本：2015–2020 开发期；2021–2024 不参与本轮调参；2025年以后冻结区不读取用于研究。
- 只改变账户级进攻暴露系数 `E_t`。基础进攻目标权重乘以 `E_t`，剩余资金留在防御层或现金，不改变股票袖套内部排序。

## 2. 三个固定配置

| 配置 | `E_t` 规则 | 检验问题 |
|---|---|---|
| C0 控制组 | 恒定 `E_t=0.90`，无账户级降仓 | 没有账户级覆盖时，混合底盘能否逐位复现 |
| C1 市场趋势 | 000300 收盘价高于 SMA200 时 `E_t=0.90`，否则 `E_t=0.40` | 大盘趋势降仓能否减少组合急跌 |
| C2 账户回撤 | 账户权益距自身历史高水位回撤不超过10%时 `E_t=0.90`，超过10%时 `E_t=0.40` | 组合自身回撤触发能否比指数信号更快保护资金 |

规则只在状态发生变化时产生调仓目标；状态不变时不重复交易。固定恢复和冷却语义如下：C1 趋势恢复需要连续两个已完成交易日重新站上 SMA200；C2 回撤恢复条件为回撤回到5%以内；两者恢复前都必须经过三个已完成判断会话的冷却期。11:30 重读前一收盘数据不重复计数。第一版使用一个固定降档，不同时搜索多个阈值、均线窗口或降仓比例。

## 3. 必须报告的指标

- 费用后年化收益、最大回撤、回撤持续时间和恢复时间；
- 相对 B1(m) 的超额、分年份表现、收益集中度和亏损月份；
- 账户级触发次数、降仓天数、恢复次数、每次触发时已承受的指数/账户回撤；
- 进攻仓位、防御仓位、现金路径；
- 换手、成交率、未成交风险单、跌停/停牌顺延和现金守恒；
- 与 C0 的逐日权益差异和每次状态切换带来的收益贡献。

## 4. 判定纪律

- C0 若不能逐位复现基准，停止判定，C1/C2 结果作废。
- 研究目标必须同时满足现有八项策略门槛，并且费用后年化收益达到10%；只降低回撤不能称为目标达成。
- 账户级覆盖不能通过降低交易真实性、假设止损必然成交或放宽费用/成交门槛来过线。
- 本轮只验证账户级覆盖，不同时调单标的止损、R倍数止盈、移动保护线和因子权重。
- 任一配置通过开发期后，验证期只能一次性运行；开发期结果用于选择配置后，未选配置的失败结果仍需保留。
