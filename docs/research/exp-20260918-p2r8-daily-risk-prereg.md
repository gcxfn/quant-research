## 0. 定位与诚实性声明

- **dev（2016–2020）已被 R6/R7 两轮消费**：本轮 dev 结果标注"探索性（重用二）"，证据强度较 R7 再降一级，任何通过者仍须以 validation/test 为正式裁决。val（2021–22）/test（2023–24）维持"从未参与决策、已被计算留档"口径。
- **重开依据（决策链可审计）**：R7 证伪的是"月频采样敞口机制"——敞口路径在 108 个月频信号日采样，失败判据已收敛为单一回撤（8/12 只败判据 4），最深回撤窗口 2020-02-25→04-01 且无一机制在急跌前降档；同时 TREND 判断在池级有效（B1(TREND) dev 回撤 −14.96%，全部基准最浅）。即：**判断有效、执行速度不足；检查频率是 R6/R7 均未测试的杠杆**（R6 剔除周频的理由是换手超限，不是检查频率本身）。
- **证伪的连带推断（写死）**：日频是该杠杆的天花板（收盘信号 + 次开执行下再无更快档位）。若本轮 dev 仍 0 全过 → "亚月频风控"整体关闭（含周频），不再以频率理由重开；届时仅剩 G2（半天截面）、G3（事件补充）、G4（>10 日持有）与"趋势 + 极度分散"形态。
- 钉死参数的证据：W={20,60}（R7 中 W2S 臂 C01/C03 优势年 5/5、失败唯一化为回撤；W2L 臂 2020 超额集中 +30~+55pp 属脆弱结构）；N=3（R7：N=5 回撤深 3.3–4.0pp 且不降换手）。E_on=0.90 与 0.75 在 N=3 下同为 25%/腿（饱和），写 0.90 以对齐 R7 TREND 便于 B1(m) 比较。

## 3. 执行语义增量（其余逐字继承 R7 冻结配置）

1. **状态变化才交易**：E_t = E_{t−1} → 无风控交易（在持腿权重漂移照旧）；不等 → t+1 开盘把全部在持腿按比例重定至 min(E_t÷3, 25%) × t 收盘总权益（成员不变，只缩放）。
2. **月度信号日与风控日撞期**：合并为一次目标（成员更新 × 当前 E_t 预算），t+1 开盘单次执行。
3. **顺延**：缩放腿 t+1 无行情（停牌）或开盘触 ±9.5% 代理 → 顺延至次一可交易开盘；顺延期间目标再变，以最新目标为准；月度选币的顺延/槽位规则不变。
4. **锚定回归（先于任何判据消费）**：C01 与 R7 正式运行（run `20260918T004441-p2r7-etf-exposure-d01f4e7a`）的 C01 净值曲线**逐位一致**；B1(FIX-75) 与该 run 的 B1(FIX) 一致。不一致 = 实现缺陷：修复、重跑、留档作废运行，不得消费。
5. 费用（万1 最低 5 元）、名义 20 万、种子 17、冻结边界、批次身份全部继承 R7。
