## 三、结论（robustness 判读，非选优）

1. **家族优势是平台、冠军点值是峰**：邻域平台净年化 +6.6~+9.0%（超额 +6.0~+8.4pp）且九个有效邻域全部八门过、回撤全部受控；但 +11.06% 的冠军点在邻域内无 ±2pp 以内同伴——它是被 dev 目标列选出来的局部最优点（选择锐化的典型签名）。
2. **诚实期望**：该族的稳健期望应读邻域中位数 ≈ **+8% 净年化**（而非 +11%）；与 val 样本外 +1.8~+2.3% 并观，完整画像为"回撤控制稳健、超额存在但量级依窗口大幅衰减"。
3. **槽位轴**（仅 RB-04/08 可读，top2 行无效）：top4 比 top3 低 0.4~1.3pp，无结构性改善；**回看轴**：4m/9m 均降 2.8~4.5pp，6m 为邻域最优；**成员轴**：逐成员剔除均仍 8/8（剔 513100 降 3.7pp 最敏感、剔 513500 降 2.1pp——两 QDII 合计贡献约一半超额，为家族最集中的单一风险）。
4. 子窗（零成本）：R3-05/06 超额集中于 2017-18（+34/+33pp）与 2019-20（+27/+34pp）两个基准弱势段，2015 年双双跑输 16-18pp——超额来源是"基准差时少亏"，非全天候。
