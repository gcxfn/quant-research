# 手算场景与反证测试规格

这些是拟实现测试，不是量化策略表现，不是仓库测试已通过的证据。完整冻结合同优先于本规格；语义不一致时先记录冲突，不能任选使收益更好的版本。

## A. 两个可以直接手算的真实费率案例

**TV-A01 平价往返。** 2020年，初始现金500000，买5000股×10元，次一允许交易日卖5000股×10元；假设两个半日都严格穿透、无公司行动，买卖次序合法。买佣金5元，卖佣金5元、印花税50元。最终现金499940元，总费用60元。卖出时资金进入待结算，下一许可半日才变可用；权益包含待结算现金，不应额外下降。

**TV-A02 上涨20%的往返。** 仍买5000股×10元，合法后续卖5000股×12元。买佣金5元；卖佣金6元、印花税60元；最终现金509929元，盈利9929元。市场路径由合成数据事先构造，不是挑真实历史赢家。两个例子不含任何未登记额外成本。

**TV-A03 税率日期。** 同样卖出50000名义，合成卖出日期2023-08-25与2023-08-28，印花税分别50/25元，佣金均5元。不加载该时间段真实行情，测试费用公式不等于批准访问Val。

**TV-A04 股息。** 合成持有1000股，除息前10元，无其他市场变化；按合同现金分红0.50元/股，除息估值9.50元。股票市值9500、应计入合同账户现金500，合计仍10000。若合同是付款日记账，先列相应应收/记账时间，不偷偷改时点。测试禁止分红和复权估值双计。

**TV-A05 拆股。** 1000股、10元、明确2:1股份变化后2000股、5元，总价值10000不变。非整数比例、零股和可卖时点另由合同规定，独立手算，不套用“含分红复权因子”当份额倍率。

| TV-B13 | 挂单过期/被替代后延迟wrapper放行 | 原单不能复活；只处理合法新单 |
| TV-B14 | 同intent部分成交后重挂 | 仅处理剩余数量；不得再买满一次 |
| TV-B15 | take_half已触发但未成交 | 不标经济完成；重发不新增一次独立止盈 |
| TV-B16 | 同证券两个不同成本批次分批卖 | 数量、剩余成本、FIFO消耗及风险线可独立对上 |
| TV-B17 | 外部手动完全清仓 | 旧止盈/止损事件清扫；后续新持仓不继承旧状态 |
| TV-B18 | 卖出、时间退出、D3回补同点冲突 | 事先固定唯一优先级，无超卖/卖后同点违规买回 |
| TV-B19 | 当期已有3持仓+1活跃待成交 | 新事件不占第五席；旧单失效后应释放席位 |
| TV-B20 | 同点10个事件、空4席 | 前后状态可追溯，接纳排序明确；Day0候选上限另检查 |
| TV-B21 | 相同信息但输入行顺序乱序 | 冻结排序后输出一致，不由DataFrame偶然顺序决定 |
| TV-B22 | 价格上涨使已有持仓市值超过25% | 沿合同披露被动漂移，不自动判创建订单违规/强制清仓 |
| TV-B23 | 创建新单的目标超过单名帽/现金不足 | 按合同拒绝/处理，不为达标自动缩单或借款 |
| TV-B24 | 风控触发、冷却、恢复确认重复am/pm | 同一已观察日不重复计确认；恢复条件可手算 |
| TV-B25 | 归因事件2020-12-28、20日终点在2021 | 保留事件但不纳入Dev完整20日标签均值 |
| TV-B26 | 修改未来行情/资格 | 当前候选与订单逐位不变；未来标签可变化但不回流 |
| TV-B27 | min=max的盈利点预测；min>max非法区间 | 按数据合同区分点值与错误，不笼统丢弃所有相等值 |
| TV-B28 | 同财务期历史修订与同日多版本 | 时间顺序、版本可得性、去重规则明确，不读最终版替历史 |
| TV-B29 | 首年账户先赚、后续几年亏 | 首年收益被正确输出，不宣称“每年全负” |
| TV-B30 | 固定成交序列额外提高费用 | 末权益不增加；此单调性不外推到动态策略路径 |
| TV-B31 | 两份源名称不同、上游相同 | 标同源交叉核对，不冒称独立行情来源 |
| TV-B32 | 错一手、漏一笔费、故意把<=换成<等缺陷注入 | 独立校验应捕捉预先列出的缺陷；不是只测正确样例 |

## C. 对参考实现本身的反证

至少注入：重复成交、价格单位×100、分红每手误当每股、成本符号反转、卖出款提前可用、旧batch止损状态残留、未来价替代上午价、首年收益遗漏、负号MDD误比较。

故意注入只能在隔离测试副本，不修改归档/生产合同。预设缺陷若未被校验抓住，不能宣布参考系统已经覆盖该风险。发现旧测试预期错，要由独立合同证据修正，保留过程。

## D. 如何确认真的执行

每一项测试要有：测试ID、输入数据路径/哈希、预期输出路径/哈希、预期来源（手算或独立实现）、实际输出、差异、真实命令、exit_code、日志/JUnit、审阅者复跑证据。仅表格写“PASS”无效。
