# 有问题时发给实施 agent 的返工指令

本次只处理审阅意见中的指定issue_id：填写这里。不得扩大范围、增加策略、打开新数据或更换整套引擎。

每个issue按以下顺序交付：合同条款与根因；最小失败样例；独立正确预期；最小补丁；针对测试；对已有有效run的影响；必要重放；无关路径控制；剩余限制。

不得删除失败用例、修改预期迁就当前实现、抬高数值容差、吞异常、跳过关键测试、覆盖旧run或手改输出。旧测试真的错误时先提交其错误证明和替代预期，由独立审阅者确认。

同一根因连续两轮未关闭，不再自行第三轮大改；提交缩小范围/局部接口重设计/更换责任人的决策申请。所有未执行项写not_run。

提交新证据后停止，等待绑定新代码身份的独立复核。旧review不自动适用于新补丁。
