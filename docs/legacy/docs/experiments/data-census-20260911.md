## 1. 共用方法与纪律

- **数据源**：`data/raw/user_dataset/2026-09-03/{上证,深证}/不复权.zip`（在市股票日线，快照 2026-09-03；上证 2,316 + 深证 3,185 = 5,501 只）。字段映射与 `quant.history.UserDataset` 同源（`USER_FIELD_MAP` 中文列），流式逐行读取（窗口外行在解析层即丢弃，不构造 dict）。
- **交易日历**：tushare trade_cal SSE `is_open==1`（`data/raw/tushare/trade_cal/20260909-r1/chunk_sse_20180101_20261231.csv`），与引擎 `market_calendar` 同源冻结口径；窗口内 **728 个会话**（2020-01-02..2022-12-30）。
- **分区纪律**：读取窗口经 `experiments.factor_miner.partition.train_only_window` 收口（TRAIN=2020-01-01..2022-12-31，左右缘均封死）；脚本级硬断言任何进入计数的行日期必须落在窗口内；**绝不读取 2024-01-01 之后任何数据**。上市判定使用 `partition.warmup_read("TRAIN", 365)`（2019-01-02..2019-12-31）授权的唯一预热通道，仅产出 `listed_pre` 布尔元数据（该股 2019 年内是否有行），不参与任何统计数字。
- **覆盖率分母**：`listed_by_d` = 该日已上市股票数（`listed_pre` 股票自窗口首会话计入；其余自其首个窗口内行计入；窗口内零行股票不计入——455 只全部为窗口后新股，见 §2）。
- **扫描字段（B-02）**：open/high/low/close/preclose/volume/amount 共 7 个（任务指定的 5 个量价主字段 + 同一行已解析的 preclose/amount，边际成本为零，证据只增不减）。分类口径：`none`（空/不可解析 → None，与 `quant.history._f` 同语义）、`nan`、`pos_inf`、`neg_inf`、`nonpos_price`（有限价格 ≤0）、`neg_qty`（volume/amount <0）。**volume==0 不计污染**（停牌形态，单列统计）。
- **实现纪律**：逐股流式、分段 250 只落盘 checkpoint（23 段）；逐段原子替换（tmp+os.replace）支持断点续跑；价格全为未复权原始价（非正判定不受复权影响）。自检 8/8 组通过（纯合成数据：字段分类、共同缺行检出、缺口统计、覆盖率分布、停牌行计数、窗口过滤、抽样确定性、checkpoint 往返），不触真实数据目录。
- **双遍核验**：pass1 全量扫描后，按窗口中位成交额十分层抽样 500 只（每层 50，seed=20260909，可复现）做第二遍独立复扫，逐股核对行数/首末行/缺行/最长缺口/停牌天数/逐类命中数。

## 2. 问题一（B-03）：真实全市场是否存在"全体样本共同缺行的交易日"

**结论：不存在。TRAIN 窗 728 个交易日中，覆盖率=0（全池共同缺行）的会话数为 0；且本数据集在该窗口是"完整面板"——每一天每个已上市股票都有行，连个别股票缺行都不存在（停牌以"有行无量"编码，见 §4）。** B-03 所担忧的"全池共同缺日→旧并集轴越过会话"在本地在市数据层没有被证实的历史实例；修复后的冻结日历建轴语义在此数据上不产生与"股票行日期并集轴"不同的断窗位置。

数字（pass1 全量，5,501 只 × 728 会话）：

| 指标 | 数值 |
|---|---|
| 宇宙（在市，快照 2026-09-03） | 5,501 只（沪 2,316 + 深 3,185） |
| 窗口内有行股票 | 5,046 |
| 窗口内零行股票 | 455（**455/455 全量核验**：文件首日 > 2022-12-31，均为窗口后上市新股，非缺失） |
| listed_pre（2019 预热有行） | 3,826（全部恰为 728 行/只） |
| **共同缺行（覆盖率=0）会话数** | **0**（直接回答 B-03） |
| 覆盖率（rows/listed_by_d）=100% 的会话 | **728/728**；<100% 清单为**空**（分布桶 ≥99.5%/≥99%/≥98%/≥95%/≥90%/<90% 全为 0） |
| 最低覆盖率 | 1.0（无任何会话低于 100%） |
| Σrows − Σlisted | **0**（3,232,780 = 3,232,780，逐会话 rows==listed 全部成立） |

注：coverage_universe（rows/5501）从 0.6955 升到 0.9173 完全由窗口后 IPO 造成（分母含未上市股票），故 B-03 判定使用 listed_by_d 分母。逐日完整表见 `artifacts/data-census-20260911/coverage_daily.csv`（728 行，含 rows/listed/两种覆盖率/停牌行数）。

## 3. 问题二（B-02）：既有数据层是否存在 inf/NaN 污染

**结论：不存在。TRAIN 窗全样本（5,501 只 × 728 会话 × 7 字段 = 22,629,460 个单元格，共 3,232,780 行）中：NaN 0 处、+inf 0 处、−inf 0 处、非正有限价格（OHLC/preclose ≤0）0 处、负 volume/amount 0 处。** B-02 设想的脏输入（无穷价格/NaN 成交量）在本地在市数据层的 TRAIN 窗没有真实实例——审计原文"不能断言真实数据已经含该输入"现在可以正向断言"不含该输入"。验证器修复（拒绝非有限值）仍应作为边界加固保留，但历史工件不存在此类污染输入。

| 命中类别 | open | high | low | close | preclose | volume | amount |
|---|---|---|---|---|---|---|---|
| none（空/不可解析） | 0 | 0 | 0 | 0 | 0 | **1,842** | **1,842** |
| NaN / +inf / −inf | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 非正（≤0 / <0） | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

- 唯一命中（volume/amount 同时为空，1,842 行成对出现）：**321 只股票、289 个交易日**，全部落在 2021-09-17..2022-12-30（2020: 0；2021: 307；2022: 1,535；峰值日 2022-05-05 共 31 只）。**1,842 行全部为一字平价行**（open==high==low==close，`flat_ohlc=1842 / other=0`）——即停牌行的第二种编码形态（见 §4），不是 NaN/inf 污染；在生产 `UserDataset.load` 口径下这些行 volume=amount=None 且 tradestatus=0。
- 无截断：所有类别命中明细数均低于留存上限（`hit_truncated` 全 False），`hits_all.jsonl` 为全量明细。
- 双遍核验：分层 500 只第二遍复扫共 354 处命中，与 pass1 逐股计数**0 分歧**（行数/首末日/缺行/最长缺口/停牌天数/逐类命中数全一致）；明细见 `hits_500_detail.jsonl`。

## 4. 附加发现：停牌在本数据集的两种编码形态（描述性）

对"个别股票长期缺行（停牌）"的定位结果是：**本数据集不为停牌留缺行，而是补"有行无量"的平价行**，且存在两种形态，分界约在 2021-09-17：

| 形态 | 窗口内行数 | 股票数 | 编码 | 年度分布 |
|---|---|---|---|---|
| A（≤2021-09-16） | 4,425（其中一字平价 4,393、非平价 32） | 570 | volume=0.0（amount=0.0） | 平价口径：2020: 2,797/2021: 1,562/2022: 34 |
| B（≥2021-09-17） | 1,842 | 321 | volume/amount 为空 → 解析为 None | 2021 307/2022 1,535 |

对照项：一字平价但**有量**（一字涨跌停等正常交易）9,040 行（2020: 5,054/2021: 2,123/2022: 1,863），不属于停牌。两种停牌形态在生产装载口径下 tradestatus 均推断为 0；差异在于下游拿到 volume=0.0（形态 A）还是 volume=None（形态 B）——形态 B 的 None 在引擎算子语义中按缺值断窗处理。此为数据格式事实披露，供引擎字段语义与 B-02 验收参考，本普查不据此提出任何规则变更。

## 6. 局限披露

1. **只覆盖在市股票**（快照 2026-09-03 在市 5,501 只；双源分工下退市股唯一来源为 baostock）。"无共同缺行""无 inf/NaN 污染"的结论不外推至退市股、ETF/指数或 baostock 通道；如需对退市股下同样结论，须另做 baostock 侧普查。
2. 结论对象是**本地原始数据层**（及其经 `UserDataset` 的规范装载口径），不是引擎 bundle 层：引擎实际宇宙受资格掩码进一步收缩，原始层无共同缺行意味着引擎层不可能因市场级数据洞产生共同缺日；个股首末行括弧之外的会话仍由冻结日历轴按缺行 None 处理（B-03 修复语义），该语义价值不因本普查结果而减弱。
3. `listed_pre` 依赖 2019 年预热窗（授权通道）有行布尔；2019 年全年停牌且窗口初期仍停牌的极端个案理论上可能被误计为窗口内上市（会低估其缺行——但本普查缺行总数为 0，该方向误差不存在）。
4. 价格为未复权原始价；本普查的 NaN/inf/非正判定不受复权影响，但不对复权后序列（qfq/hfq zip）作扫描。
5. 形态 B（volume 空值）自 2021-09-17 才出现，属供应商导出格式变化的形态学证据；"空值是否曾在更早停牌中出现"已由全窗口 0 例排除（2020 年 0 例、2021 年仅 09-17 起）。
