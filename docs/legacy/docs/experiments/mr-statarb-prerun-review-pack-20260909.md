## 实现中发现的预登记歧义点（9 条，代码 `interpretation_notes()` 已披露）

**请 Codex 逐条裁决这些解释性读法是否可接受；如不可接受请指出须改的读法。**

1. **会话网格单位**：取个股 study（P1 状态资格 + 股票/指数数据齐全）会话；ST/停牌/指数缺失日不进滚动窗口与持有计数（60 日窗口、10 会话回归概率、half-life 均在此网格上）。
2. **过滤器窗口**：信号日「前 5 个交易日」按市场日历含信号日取 5 天；公告按 ann_date 次一交易日的「可用日」落入窗口即跳过；被过滤的穿越被消费（须回升再触发）。
3. **买入受阻只尝试一次**：掩码/无量/涨停/避雷/入池门禁均记 no_trade（预登记只给卖出受阻顺延定义；此读法低估样本量，保守方向）。
4. **右端 MTM 费用**：未了结持仓按第 5 会话强退同口径计双边成本（按右端最后可得收盘计价，口径统一偏保守）。
5. **持仓期间穿越**：不重复计且消费穿越状态（退出后须回升到阈值上方再触发）。
6. **no_trade 事件计入分母**：净收益 0、计入总事件数与 bootstrap 事件日池；C「有效事件数≥30」按已成交事件计。
7. **失败归因启发式**（预登记只给类别名，实现用确定性规则）：持仓窗内有预减/首亏可用日→公告利空；事件→退出决策行业累计收益≤−5%→行业崩溃；|Δε|≥2×选择窗残差波动率→关系断裂；其余→流动性。
8. **行业 in_date 门控**：按「归属自 in_date 生效」保守读法，之前会话视为指数缺失跳过（对 SW2021 后改判行业的个股会截短窗口，screening 如实计数）。
9. 小口径：β/残差波动率用总体 std、z 用样本 std；MTM 卖价=右端最后可得收盘行；均在代码注释标注。
