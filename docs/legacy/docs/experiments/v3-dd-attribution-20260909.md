## 0 口径与对齐规则

- **trading_calendar**：交易日历以标的自身 bar 为准：指标一律取该标的 trade_date<=参考日的最后一根 bar（含参考日）作为当日观测。
- **dd_series**：净值=report.equity 逐日 equity 字段；report 内部 equity=cash+market_value，market_value=持仓股数×当日收盘，即收盘口径。
- **round_pairing**：回合=同标的按 exec_date 时序相邻 buy->sell 配对。实测数据同标的买卖严格交替、无部分卖出/叠加层（FIFO 等价）；未平仓 buy 列入 open。
- **lag**：趋势破坏日=持有期内（close 可观察日：buy_exec<=d<sell_exec）首个 close<=SMA120 或 R60<=0 的交易日；滞后交易日数=破坏日之后到 sell_exec 之间的标的 bar 数（不含破坏日与卖出日；0=破坏次一开盘即已退出，即理论最早可退出点）；滞后段仓位变动=股数×(破坏日收盘-卖出执行价)（>0=破坏后继续下跌金额，<0=破坏日后价格回升，未计费用）。以持有期内首个破坏日起算——若月中破坏后修复、其后再次破坏，仍按首个破坏日记（保守口径）。
- **episode_round**：落入区间的回合=该回合 sell exec 落在 [区间峰日, 区间修复日)（未修复则到样本末）。
- **whipsaw**：同标的 sell exec 之后 60 个市场交易日（以 report equity 交易日历计）内再次买入，且该再买入回合已平仓并再次亏损。
- **gate_check**：对每笔 BUY，以 signal_date 当日及之前数据核算 close>SMA120 且 R60>0（趋势门禁）；上市满 252 日与 20 日流动性单独核算仅作信息。违例=买入已执行但信号日趋势门禁不满足。
- **window_attribution**：区间归因 c_s=区间内该标的发生额(卖净-买总) + (谷日持仓市值-峰日持仓市值)；对所有标的求和恒等于区间权益变动（现金零息），残差仅来自浮点。
