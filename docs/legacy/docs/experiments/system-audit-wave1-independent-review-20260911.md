## 一、阻断项

### W1-01 / P1：TRAIN 成本回测的预热截断造成日期错位

位置：`experiments/factor_miner/director.py:681–690`，正式调用来自 `run_real_pipeline` 的 `region_start_idx=tr_idx`。

`raw` 已截去预热段，但 `cost_ladder` 仍接收完整 `dates`。回测按同一下标读取因子和日期，导致区域内未来因子被用于更早日期，并使尾部信号变成缺失。独立调用捕获：日期长度 110、因子长度 90，日期首项 2020-01-01，因子首项实际属于 2020-01-29。探针仅替代统计门禁和成本调用以观察接线，公式求值及截断走真实实现；这不是正式数据收益复算。

要求：统一截断日期与因子，核查后续聚类/月度统计使用的日期也同步；进入回测前验证每条序列与日期轴等长。增加非零预热段的端到端反例，断言具体信号日期与成交日期，而非仅能运行。

### W1-02 / P1：递延仓位未约束其他股票买入，月收益也未形成连续账本

位置：`experiments/factor_miner/backtest.py:335–420`。

`open_pos` 只生成股票代码的 blocked 集合，不扣减可用于其他股票的资金。合成单槽位反例：A 于 02-03 入场，原计划 03-02 退出，停牌使其延至 03-05；03-02 改选 B，仍显示 `n_executed=1` 且无受阻原因。A 的全仓资本尚未释放，B 却能再次使用一个完整槽位。

此外，递延交易的完整未来退出收益直接计入原持有期，跨月期间没有连续估值及收益拆分。`n_still_held_into_next` 是披露，不是资金约束。不能将当前实现宣称为 D-02 账本闭合。

要求：按时间处理现金、旧仓、卖出资金释放与新仓，统一月末估值/实际退出收益归属；增加“旧仓 A 未卖出、下一月选 B”的资金守恒测试。若保留独立交易标签用途，必须从组合收益/门禁口径中明确剥离，不能只加免责声明替代修复。

### W1-03 / P1：执行日部分状态未知及非有限成交量仍被接受

位置：`experiments/factor_miner/backtest.py:108–128`。

直接复现：仅 `{volume:1}`、`isST=None`、`volume=None`（其他状态正常）及 `volume=inf` 均返回可交易；字符串成交量触发 TypeError。实现只拒绝“全字段缺失”，不兑现报告所称的未知状态 fail-closed。信号日资格不能代替执行日状态。

要求：明确执行状态的必需字段及合法值，缺失/非法/非有限值返回稳定拒绝理由；正式输入缺少执行日 ST 状态不得默许成交。P3-3 不仅是类型异常文案问题，应与部分缺失场景一同提升为 P1 修复。

### W1-04 / P2：无候选的真实现金月被从收益均值中删除

位置：`experiments/factor_miner/backtest.py:423` 附近 `if not hold or n_immature`。

全因子为 None、无旧仓、行情完整的合成月份输出 `n_hold=0,gross=null,net=null`，后续均值剔除此月。此时收益是现金的零收益，并非不可估值的未成熟仓位。应区分无信号现金月与持仓不可估值月；不能将二者合并成 None。

## 二、用户点名的三项裁决

1. **TW-1 采用按明确数据轴广播，不采用一概编译期拒绝。** `IF(cond,x,0)` 是正常表达式。轴长必须来自显式日期/数据轴契约，不可由标量自身或任意首个字段推断。纯路径/numpy 同步覆盖常量算术、常量 IF 臂、窗口算子常量输入、嵌套表达式及缺字段/不等长输入；输出长度断言防止 zip 静默截短。纯常量公式是否允许、CS_RANK 常量的 universe 必须写清。R0 影响按 W1-05 更正。

2. **认可 20bps 的算术推导，不认可将它宣称为 Top15 的真实统一成本。** 按本项目给定费率和原 10bps 滑点假设，在最低佣金不生效且买卖金额近似相等时：双边佣金 5 + 卖税 5 + 滑点 10 = 20bps。20万元/15只约 1.333万元一仓，最低佣金生效，同样近似下约 22.5bps。20bps 不能代表所有仓位金额。若未来修订基准且保持压力档 +10/+20，应明文登记 20/30/40，并处理原 34bps 粗筛阈值与成本档的关系；本次不默改冻结阈值，也不改写历史17/27/37工件。当前逐笔精确费用未包含该10bps滑点，宜称“精确税佣净额”，不能叫完整成本权威净收益。最低5元在万2.5佣金下的临界金额是2万元，不是5万元；相关注释应统一。

3. **37bps 描述字段、dev-smoke 三档字段统一修正；执行状态升级修复。** 压力阶梯字段应读对应 `net_edge_proxy`，精确税佣净额另列清楚，避免不同档位同值却显示为压力测试。正式门禁缺 proxy 或 proxy 为 None 时应拒绝/标不可判定，不宜隐式换指标。现有 helper 实际也会在值为 None 时回退，范围宽于文档的“仅缺键”。执行状态按 W1-03 处理，不能只补一个 TypeError 捕获。
