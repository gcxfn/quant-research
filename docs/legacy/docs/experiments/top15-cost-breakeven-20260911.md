## 1. 公式与口径定义

记号：k=持仓只数（槽位数）；V=账户规模；单笔名义 `N = V/k`；佣金率 `r = 0.025%`；最低佣金 `F = 5 元`；印花税率 `s = 0.05%`（仅卖出）。

**（1）最低佣金分界点**：`r·N ≥ F ⟺ N ≥ F/r = 5/0.00025 = 20,000 元`。
- N < 2 万 → 最低佣金**生效**（按 5 元收，有效费率被抬高于万 2.5）；
- N = 2 万 → **等值点**（`max(0.00025×20000, 5) = max(5,5) = 5`，不产生额外费用）；
- N > 2 万 → **不生效**（按比例收）。

**（2）单边有效费率**（以毛收益=0 的盈亏平衡点计，即卖出侧名义=N；实际卖出费按退出市值计，毛收益≠0 时略有差异，见 §7 第 4 条）：
- 买入：`c_buy = max(r·N, F) / N`；
- 卖出：`c_sell = max(r·N, F)/N + s`；
- 双边合计：`c_double = c_buy + c_sell`（单位 bps 时 ×10,000）。

**（3）月频换手拖累**：设月度**单边换手率** h（=当月被替换槽位占比，与 `backtest.py` 的 `t_k = |新入仓−旧持仓|/|旧持仓|` 同义；h=100% 即全换，另建仓月 `t_k=1.0`）。当月买卖各成交 `h·V`，月成本占组合比例 `m = h × c_double`（等权下每笔名义同为 N，最低佣金按笔生效，故可直接用单笔双边费率加权）。
- **年化拖累（12 个月复利口径）**：`Drag_annual = 1 − (1 − m)^12`；
- 简单加总对照：`12 × m`（复利拖累恒略低于简单加总）。

**（4）盈亏平衡**：月度毛超额收益 `g*` 满足 `g* = m = h × c_double`（bps/月），即当月毛超额恰好被当月交易成本吃掉的临界线。

**（5）滑点桥接口径**（仅用于与既有 17/27/37bps 档对照，非本表主口径）：沿用 17bps 档文档构成中的"滑点双边 10bps"成分，桥接双边成本 = `c_double + 10bps`。

**（6）理想化假设**：等权名义按 `V/k` 精确切分，忽略 100 股整手取整、卖出 proceeds 再投资时点差异；ETF 行仅为费率对照，不参与本产品。

## 6. 结论（中性；决策权在用户）

1. **分界点数字**：最低佣金生效线=单笔名义 **2 万元**（20 万账户对应 **k=10 为等值点**，k≥11 生效）；k=15 的双边有效费率 **12.5bps**；全换月拖累：k≤10 为 **10bps/月**、k=15 为 **12.5bps/月**、k=20 为 **15bps/月**（年化复利 119.34/148.97/178.52bps）。
2. **k 的费率含义**：k∈{3,…,10} 费率完全相同（双边 10bps）——在纯费率口径下，从 3 只分散到 10 只**不增加任何费率成本**；k=15 与 k=20 分别多付 2.5bps 与 5bps/往返，全部来自 5 元最低佣金的摊薄，属于「分散度买断价」。
3. **换手含义**：换手对年拖累近似线性（h=20%→50%→100% 大致 1:2.5:5 的年化关系在低 h 处因复利略压平）。稳态 h=20% 时各 k 的年拖累仅 23.97–35.94bps，但建仓月一次性全双边会把 k=15 的年拖累推至约 39.93bps（§3 脚注）。
4. **与研究口径的关系**：本表纯费率数字（2–15bps/月）均低于 17bps 最低成本档；一旦计入既有 17bps 档构成中 documented 的 10bps 双边滑点，全换月（h=100%）在任何 k 下都超出 17bps 档、但全部落在 27bps 档内，34bps 事件粗筛线在最紧处（k=20、全换）仍余 9bps。此为量级对照，不构成对任何 (k,h) 组合的可行性判定。
5. **与 `DEFAULT_TRADE_NOTIONAL=50000` 机制假设的关系**（`experiments/factor_miner/backtest.py`，权威净额=每笔精确费用层）：
   - **假设成立（N≥5 万）**：k∈{3,4}（20 万账户）。k=4 恰为 N=5 万边界点。
   - **假设数值不成立但费率 bps 不变**：k∈{5,8,10}（N=4 万/2.5 万/2 万，均 ≥2 万阈值）。费用按比例线性，每笔精确费用的 bps 结果与 5 万假设完全一致（仅元额不同），回测净额不受影响。
   - **假设失效（最低佣金生效，N<2 万）**：k∈{15,20}。研究层以 N=5 万计的 10bps 双边在本表口径下被低估：k=15 实际 12.5bps（低估 2.5bps/往返，全换月低估 2.5bps/月）、k=20 实际 15bps（低估 5bps/往返，全换月低估 5bps/月）。方向恒为「研究偏乐观」。
   - 机制上该假设已参数化（`monthly_backtest(trade_notional=…)` 可传实值，如 `200000/k`），传实值即可复现本表费率，无需改代码；是否传、传什么属规则决策，本文档不做选择。
   - 17/27/37bps 描述性 proxy 档不受 `trade_notional` 影响（其为换手×bps 近似，已标 `descriptive_proxy`），但「k=15 时 proxy 档与真实费率孰高」取决于是否计入滑点成分（§4.3）。

## 7. 与既有文档/代码口径的出入清单（如实披露，未做任何改动）

1. **17bps 档构成中的佣金率与现行股票费率不一致**：`docs/plans/factor-mining-program-20260909.md` 记 17bps=佣金万 1 双边(2bps)＋印花 5bps＋滑点双边 10bps；现行用户确认股票佣金为万 2.5（双边 5bps）。若按万 2.5 重排同构成应为 20bps 而非 17bps。本文档不裁定孰是：主表按冻结事实万 2.5 计算，对照矩阵显式桥接 10bps 滑点成分。
2. **本表主口径不含滑点**：任务冻结成本事实只含佣金＋印花税；滑点仅出现在 §4.2 标注为「桥接」的矩阵（采用既有文档构成中的 10bps 成分）。任何把 §4.1 数字与 17/27/37bps 档直接相减的读法都是口径混用。
3. **h 集合解释**：任务原文换手集合写作 `{20%,50%,100%,100%（全换）}`，100% 重复；本文按三个不同取值 {20%,50%,100%} 处理，100% 即全换（与代码 `t_k=1.0` 建仓/全替换语义一致）。
4. **卖出费的名义基准**：代码中卖出费按**退出市值**计（`stamp×exit_value`，随毛收益变动）；本表按盈亏平衡点（毛收益=0，退出市值=买入名义 N）计。毛收益远离 0 时（如深度亏损触发最低佣金分界变化）卖出有效 bps 会与本表略有出入，量级 <1bp。
5. **理想化切分**：忽略 100 股整手取整与价格漂移导致的实际名义偏离（实际单笔名义不会恰为 V/k），分界点 k=10 的「等值点」在实盘中会因名义略低于 2 万而偶发生效；ETF 行仅费率对照，本产品为个股。
6. **一致处**：本表 k=15 结论与 `backtest.py` 的 `scope_note` 自注（"真实 20 万/15 只等权 ≈1.33 万/笔会使最低佣金 WOULD bind"）定量一致（13,333.33 元/笔，双边 12.5bps）。



## 附录 A：复算方法

一次性脚本要点（`python - <<'EOF'` heredoc，`decimal` 精度 50，用后即删；下面为可直接复算的核心片段）：

```python
from decimal import Decimal as D, getcontext
getcontext().prec = 50
COMM, MINF, STAMP, V = D('0.00025'), D('5'), D('0.0005'), D('200000')
ks = [3, 4, 5, 8, 10, 15, 20]
hs = [D('0.2'), D('0.5'), D('1')]
def powd(b, n): return (b.ln()*D(n)).exp()          # b**n
for k in ks:
    N = V/D(k)
    buy  = max(COMM*N, MINF)                        # 买入费（元）
    sell = max(COMM*N, MINF) + STAMP*N              # 卖出费（元，含印花）
    c_double = (buy + sell)/N*D(10000)              # 双边 bps
    for h in hs:
        m = h*c_double/D(10000)                     # 月拖累（小数）
        annual = (1 - powd(1-m, 12))*D(10000)       # 年化复利拖累 bps
        print(k, h, c_double, annual)
# 敏感性：V ∈ {100000, 200000, 500000} 同式重算；桥接：c_double+10bps
```

校验样例（手算级）：k=15 → N=40000/3，买入费 `max(0.00025×13333.33, 5)=5`，`5/(40000/3)=0.000375=3.75bps`；卖出 `3.75+5=8.75bps`；双边 12.5bps；全换月拖累 12.5bps，年化 `1−0.99875^12=148.97bps`。
