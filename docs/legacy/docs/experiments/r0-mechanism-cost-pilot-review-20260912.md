## 发现并修正的真实收益失真

初版同时禁止ST买入和卖出，使REV_vola_11所持sh.600766从2021-04-01持有至2022-10-10，含339个ST会话，贡献55392元。真实17次拒卖中15次满足原限价/量能条件，首次2021-06-01可按3.51卖出5500股。

依据[上交所2021年官方说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20210720_5526016.shtml)，已有风险警示股票可以卖出。新增显式st_sell_eligible仅用于已知ST且正常交易的已有可卖仓位，ST新买仍拒绝；停牌、未知状态、无效价格、T+1、送转未可卖股份、量能和限幅继续约束。小试传入历史ST限幅；[深交所2020年通知](https://www.szse.cn/disclosure/notice/general/t20200710_579459.html)区分创业板改革前后规则。旧默认调用未自动切换，不改变生产产品。

138项相关回归通过。所有30条路径用相同信号重跑，不只重跑赢家。sh.600766按原月度订单在2021-06-01退出，净贡献变为−4452.60元；REV_vola_11三年累计97.627%→73.738%，下降23.889个百分点。差量还包含释放资金后的后续交易，不可把全部差量简单等同该股贡献差。

原META_combo_02持有退市sh.600146造成的缺价，在更正ST卖出后于2020-08-03退出；低PB对照的sh.600978于2020-06-01退出、sz.000564于2021-03-01退出，未再持有到先前无法解释的退市/重整事件。没有删股票或清零损失。

旧批与旧数值留档，不能继续作为有效收益证据。真实探针rev1曾用错拒绝原因字符串得到0条，由有17条实际记录的rev2替代。后续摘要格式化也曾遇到DATA档收益None，未将None改成零或重跑以求数值。

主档REV_vola_11的年化20.27%，三年分别31.98%/14.07%/15.41%，平均资金投入47.26%。其净盈利147476元，前五只贡献99544.55元（67.50%），最大一只20.34%；去掉前五贡献后的余项只是账面归因，不能冒充删股重新配置资金的回测。固定三档均为正，但数量取整和现金路径会随成本改变，不能把各档差量当固定持仓线性手续费。

该公式实际上是过去5日平均日内实体收益的负值`-MEAN((close-open)/preclose,5)`，名称含vola不代表低波动因子。按35个有下月执行的月末、同日daily_basic数据，其目标流通市值在P1参考池内的百分位中位约36.67%；低换手/低波动对照分别99.25%/96.18%。分数与低流通市值Spearman中位0.118。总体相关不高不能否定尾部选股的市值暴露；对照池和实际投入差异较大，跑赢对照不等于风险调整后Alpha。

META_pxval_10主档累计30.07%仅略高于低换手28.59%，前五贡献占净盈利103.79%；REL_cond_13最大一只贡献占净盈利290.66%。这支持降低它们的追加研究优先级，但尚不足以严谨宣布原机制无效。其他候选较弱也只说明本小试交易结构，没有据此判死家族。

唯一未完成经济解释的路径是META_combo_02/10bps：2020-07-10持有sh.603879共100股，源分红送转条款（每股现金0.05、送转0.4）与裸价preclose跳变相差约0.0757元，超过冻结一分钱容差。保存原输入及近似账本，标DATA_ISSUE，收益不报；不放宽容差或删除该股。主档和其他候选的已知实际依赖不受此事件影响，该问题进入该路径数据待办，不阻断其他机制诊断。
