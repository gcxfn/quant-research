## 三、剩余解释性读法（8 条，保守）

1. 顺延买入目标名义额冻结在原调仓日开盘 NAV，不按成交时点重算。
2. 全量调平=留任者亦付一买一卖；卖出受阻者被迫留任（2 例披露，无法调平）。
3. nav_ref=调仓日开盘（卖出前）NAV；受阻期现金残留极小（≈卖出费率/N）。
4. 缺失/无量买入顺延至可成交开盘，跨月取消计数；涨停跳过不重试。
5. 未成立月持仓延续估值；期末不强制平仓按最后收盘计贡献。
6. 权重制无手数取整（研究口径）；逐日转储起点 2019-12-01。
7. 夏普 rf=0；年化复利公式；并列因子符号升序 tie-break。
8. 停牌以缺行/缺价/无量代理识别（数据无显式停牌标志）。
