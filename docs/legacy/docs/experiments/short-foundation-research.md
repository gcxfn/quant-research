## 诚实限制（全部适用）

1. 旧池快照含**幸存者偏差**与池构建前视；全部历史已看过；本归因不构成任何可执行依据。

3. 八组是试验范围限制，不是统计显著性保证；单因素读数存在交互作用盲区。
4. **P1 严格池上的同规则复测未做**（幸存者偏差对以上数字的影响方向未知）——这是下一步；
   P2 分钟撮合对照须待独立审查后加入。
5. G7 的高收益来自资金占用放大而非单笔优势提升，且回撤超约束——不构成"提高仓位"的建议。

## 读数（实现者初步，待独立评审）

1. **momentum_market 的历史正收益不能直接归因**：严格池上的负读数与旧池差异
   同时混入池宽、资产类别、历史 ST/退市处理、价格/qfq 和候选竞争集合；在匹配
   对照运行前，只能说旧池结论需要重新检验，不能把 −21.5% 全部归因于幸存者偏差。
2. **相对排序部分稳健**：宽基门槛在真实池上仍是最重要的正贡献（去门槛
   −53.3% vs 基线 −21.5%）；G3 开盘买入在两个池上都相对最好。但该窗口只有
   7/8 组严格池读数为负，G3 为 +0.393%，相对优势不能直接包装成盈利优势。
3. G7 的杠杆效应在真实池上是灾难（−40.6%/−61.7%）——再次确认资金放大
   不是策略优势。
4. 池宽效应：5387 只池提供的候选远多于 172 只，排名落选率更高；宽基门槛
   的拦截作用在更大池上更重要。

## 数据与验证链

- qfq 构建（因子语义）：在市股验证组的非事件日严格一致；`sz.300750` 因子切换日
  1 处约 0.37% 口径差单独归类披露，不能写成事件日 6/6 严格零差异。
- 严格池构建（历史工件）：5387 只、历史 ST 日期剔除共 798,306 行、退市区间过滤、
  市场条件序列 sh510300 从旧池快照注入（用户数据集无 ETF，披露）。
- G1 等价断言通过（旧引擎 == 分解流水线）；运行
  `python -X utf8 experiments/short_foundation_research.py p3-p1pool`；
  证据 `artifacts/short-foundation/p3-p1pool/`。
- 已知近似（修复前工件）：退市股 qfq 由因子构建（在市股验证外推）；ST 期间序列断档；
  两池规模差（172 vs 5387）本身是池宽效应的一部分。

## 结论与下一步

**修复前工件不能支持“无幸存者偏差池上全部规则无正收益”的基线事实**：G3
在该窗口仍为 +0.393%，且池宽/状态/退市等混杂尚未由匹配控制拆分。P4 重建仍应
先过严格池，再看旧池对照；所有数字保持研究/不可执行，等待独立复审。
目标（年化 10%/夏普 1.5）在真实可选池上的难度仍不能由这份修复前工件定量确认。
