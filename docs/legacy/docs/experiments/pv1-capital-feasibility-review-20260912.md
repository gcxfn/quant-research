# PV1原十分位与20万元账户的适配检查

2026-09-12。工件`artifacts/pv1-capital-feasibility-20260912-1/`，脚本`experiments/pv1_capital_feasibility_20260912.py`。复用已核TRAIN分数，按原降序/代码同分排序选择floor(n/10)，每月十分位至少10只才成立；最后未成熟月不执行。

本检查逐月独立假定20万元、原最高十分位100%等权，读取信号日主源未复权收盘价，仅算目标资金、板块最低数量/步长和最低佣金。普通股票100股、科创板200股起且1股步长，沿现有`market.quantity_rule`。不是跨月账户回测，未模拟成交、涨跌停、后续价格、卖出回款或现金变化；不使用复权价格判断买不买得起。

35个月、3051只不同证券、8276个目标观察，原价缺失0。每月186–291只、平均236.46只。

- 75.8096%的等权目标预算低于对应最低申报数量的购买金额。
- 按信号日价格、扣费前目标数量取整，平均名义资金投入仅18.8613%。这是每月重新以20万做静态算例，不能解释为真实回测平均仓位。
- 可买部分的最低佣金产生平均单边77.183bps（按每月总买佣金/名义买入金额，再跨月均值），未含印花税、过户费或冲击，不是实际年度成本。
- `sizing-review.json`核对全部8276目标的数量上下界、步长和费用，费用差0。主原始价格和分数输入保存在`sizing-evidence.json`，数字可复算。

主审裁决：**原最高十分位等权组合与本轮20万元规模明显不适配**。这不否定PV1信号，也不证明真实账户亏损；它说明不能直接把旧十分位的研究收益解释为这个账户可实现的收益。旧17bps/单笔至少5万元假设不成立。

本阶段停止为该原结构下载3051证券全期分钟或展开完整执行回放，避免投入大量资源验证一个多数目标无法按预算买入的组合。PV1保留为正向信号研究资产，可在后续明确登记的少量持仓多因子结构中使用；不得静默改Top10/重分配无法购买目标的资金后沿用原策略身份。新组合属于新的研究假设和搜索尝试，待本轮其他候选结果齐备后统一制定，不能将此次可行性检查当成新组合验收。
