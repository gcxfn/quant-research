# V3 执行日收盘前视审计（2026-09-09）

**旧缺陷已定位，修复已通过限定独立复核。** 旧版 `quant.portfolio_candidate.run_rank_portfolio` 在执行日开盘买入新标的前，以 `cash + mark(d)` 计算预算；`mark(d)` 读取同一执行日的 `close`。因此未知的收盘价会改变同日开盘新买入的份额，构成前视。现代码改为执行时已知的持仓开盘估值；无当日 bar 的旧仓使用此前已知价格，收盘只用于当日净值。

旧版复现见 `python -m unittest tests.test_monthly_etf_t0_v3_audit`：固定1月末A/B、2月末A/C的排名和全部开盘价为10，仅改变3月1日仍持有A的收盘5→15，旧代码会改变C在3月1日开盘的买入数量。现代码的同一反例订单数量不变；缺少旧仓当日bar时使用此前已知价格的变体也通过。测试中的旧行为是回归反例，不是对现代码的描述。

`artifacts/monthly-etf-t0/v3-review-20260909-r2/report.json` 的历史数字保留作问题定位证据，但不得视为无前视、无偏或独立样本外的收益验证。修复后的 `artifacts/monthly-etf-t0/v3-review-20260909-r3/report.json` 已由主审作已观察历史工件限定复核；仍不消除当前在市ETF幸存者偏差，也不是独立样本外。

窗口参数的默认 `None` 调用语义保持不变；改变的是开盘预算的估值信息集，已移除执行日收盘的未来读取。因此不得表述为“V3行为完全不变”。
