主审结论：原净利润明显依赖日线引擎给出的开盘价格改善，但固定数量价格压力尚未消除全部正收益。不能判定因子无效，也不能认证真实盈利。下一阶段确需动态成交重放，而非继续把固定现金扣减当回测。先以现有20日分钟数据作订单级时序接线，使用原限价、0.5%逐bar共享容量、部分成交与真实费率；仅对此子样本验证规则，不能混合20日分钟/其他日旧规则所得收益冒充全量验证。全量账户需覆盖原订单及改轨后新订单依赖后才报告收益；不得只下载原成功成交日而漏掉原未成交订单。R0 IC无需重算，留出与生产仍冻结。
