## 解读

1. **复现 PASS**：修正生产池直跑与 R3 存档全指标逐位一致（年化/夏普/回撤/现金日/
   交易数/三段收益）——生产与证据同源，且本地腾讯数据自 R3（2026-09-09）以来无
   影响结果的复权修订。
2. **三只的历史贡献为正且量级可观**：反事实臂年化 +2.99pp、夏普 +0.086、回撤浅
   3.48pp、现金日 52→16。分段看增益集中在 2020—2023（+13.32pp，黄金 2020 牛市）
   与 2024—2025（+13.11pp，黄金大牛市）；**2026 至截止段修正池反而更好**
   （+3.85pp，动量排名选了其他标的）。
3. **方向申明**：剔除三只是**规则驱动**（D-2026-09-09-04：商品 T+0/定价机制不同、
   沪深港含港股成分跨境），非业绩驱动；本对照仅为透明留档，不构成把商品加回的
   依据。反事实臂的优势属**已观察历史的事后选择效应**——若按"历史上表现好"加回，
   等于用结果倒推前提。
4. **D-04 预留条款触发披露**：D-04 记录"若对照回测明显恶化，用户届时可走正规程序
   重议规则"。修正池相对反事实在已观察历史上少约 3pp 年化、回撤深 3.5pp，属"明显
   恶化"量级，**如实上报用户**；在用户重议之前，D-2026-09-09-04 排除规则与 52 池
   生产配置维持冻结。若用户选择重议，须按预登记流程（新预登记草案→用户确认→实施
   →独立审核），不得直接改池。
5. 边界：两臂均为已观察历史复核（非新样本外）；当前在市池幸存者偏差未消除；B 臂
   55 池同为在市快照。B 臂配置文件头注明"仅量化池构成敏感性，不授权重新纳入"。
