## 已实现（离线合成数据验证）

- **订单类型**：limit（限价排队）/ stop（触发式，跳空穿越以开盘价成交、盘中触达以触发价成交）。
- **时点纪律**：订单仅在 `activate_at` 严格之后的 bar 成交——日线信号最早次日、分钟信号不能同 bar 成交；同 bar 先卖后买（卖出资金当日可用），不使用未来卖出。
- **诚实口径**：涨跌停方向不可成交（一字板保守处理）；停牌行有价无量不成交；部分成交按参与量上限且费用按实际名义本金计；止盈止损同触达按更差结果为主并标记 ambiguous（注明替代路径更优）。
- **账本**：T+1（当日买入不可卖）、送转股当日可卖、除权除息开盘前入账、佣金含最低分段、卖出印花税逐笔；账本对账测试（初始资金+Σ流水=期末现金）。
- **手数规则**：复用 `market.quantity_rule`；顺带修复点号代码（`sh.688001`）被误判为主板的兼容问题（`market.board/is_etf` 归一化）。
- **费用口径差异（有意为之）**：回放不计滑点项——限价成交价即真实价格（`t0.buy_cost` 的 slippage 是做T 估计用途，重复计会双重惩罚）；排队/延迟由撮合规则体现。
