## 阻断及修复验收

### B-01 / P1：常数窗口产生伪 ZSCORE 信号

位置：operators.py `_std_sample` / `_zscore`。60 个完全相同的 1.1，Fraction 参考方差严格为零；实际 ZSCORE=-0.9916316520429012，继续 SIGN 得 -1。此前 numpy 求和同序化复刻的是这个旧行为，兼容性通过不消除数学缺陷。

影响：含 ZSCORE/STD/CORR 及其下游排名、条件分支的因子；是否命中具体历史窗口尚需 TRAIN 定位。不能由此宣布所有因子或 V3 作废。

验收：常数、近常数、大数消减、极端有限输入用独立精确参考；明确零方差输出规则，两路径同步；修订计算语义和身份，命中因子从因子值节点重算，不沿用旧结果。

### B-02 / P1：公共行情验证器接受无穷价格与 NaN 成交量

位置：quant/validation.py `validate_bars`，由 quant/cli.py `_gate_symbol_bars` 和池读取入口调用。OHLC 全为 +inf、volume=NaN 的单行返回空错误列表。价格只拒 NaN/非正，没有拒 inf；成交量仅检查 <0。

影响：公共 CLI 日线门禁存在明确漏检；不能断言真实数据已经含该输入或已经产生可执行信号。

验收：OHLC/volume 的非有限、缺键、非数值输入明确失败；验证入口到报告的降级路径，避免检查器本身因类型比较崩溃。

### B-03 / P1：因子日轴依赖已存在价格行，缺日会压缩

位置：engine.py `build_market_axis`，`build_real_bundle` 已获取市场 calendar，却仍用股票行日期并集建轴。合成 2020-01-02、2020-01-06 两行不会补出中间交易日。全体样本共同缺行时，RET/滚动窗/期限都会越过该会话。

验收：以冻结交易日历建轴、缺行占 None；全池共同缺日负例应保留会话并降级。真实全市场是否共同缺行尚未审计；这是结构缺口，不是已证实历史缺日。

### C-01 / P1：TRAIN 没有落实冻结的多重检验收紧

位置：director.py `train_test`→stats.py `continuous_gate`→`monthly_block_bootstrap`。实际 CI 固定 `[0.025,0.975]`，调用无 N 参数。全 factor_miner 只在 LOCKBOX 找到 Bonferroni `0.05/N_frozen`。

预登记 §5 同时写有描述性 95% CI 和每轮粗筛 `α=0.10/N`；D-28 扩候选决策明确以自动收紧承担统计代价。描述区间可以保留，但当前代码没有对应的校正晋级判据。N=246 时若用双侧区间实现校正，端点应为约 0.000203252/0.999796748，而不是 0.025/0.975；最终 N 必须来自冻结正式检验清单，不能直接拿文档数字充当运行证据。

验收：冻结 N 的构造/窗口去重与失败计数定义；N 进入实际门禁和报告；用固定 IC 输入演示 N 改变时校正门禁改变；核对 TRAIN→registry 晋级链。现有 TRAIN 粗筛资格不能据固定 95% 区间直接推进。

### C-02 / P1：NaN 显著性输入可通过门禁

位置：stats.py `continuous_gate`。6 个 NaN 返回 `pass=True`。NaN 穿过绝对值、区间跨零与方向比较，各项拒绝条件均未触发。

验收：统计输入和 bootstrap 输出均校验有限性、合法范围、上下界顺序；NaN/inf/损坏区间必须失败。当前正常 Spearman 路径不必然生成该反例，历史触发范围未证明，但门禁边界不应接受非法值。

### C-03 / P1：锁箱中断无访问痕迹，候选集合身份可受排序影响

位置：director.py `run_lockbox`、`manifest_hash`、`_read_ledger`。合成 builder 连续两次进入并抛异常后，仍无 ledger；同一候选集合逆序后 hash 改变。代码直到全部计算与结果写入完成后才追加消费台账，检查与占用没有跨进程原子锁；不同 out_dir 的并发调用也没有共用原子占用点。

历史解释：D-2026-09-10 的旧 round-3 送审材料和 decisions 明确容许“计算异常不消费”。本次不是把旧裁决隐去后指责实现擅改，而是指出它不满足本次审查计划 C5 的“失败/中断访问也留痕”，且扩大了重复观察风险。

验收：读数据前原子建立访问记录，保留 STARTED/FAILED/COMPLETED；同一冻结候选集合采用规范化排序身份；串行重试和并发访问均测试。异常后能否重跑按具体污染范围裁决，不由程序自动恢复预算。不得改动真实旧台账。

### C-04 / P2：十分位描述统计随字典顺序翻转

位置：stats.py `decile_top_bottom_spread`。20 个因子全相同，收益不变，只逆转 factor 字典顺序，mean_spread 从 +1.8 变 -1.8。注释承诺并列平均秩落组，实际稳定排序后截取首尾各 q 个。

影响：描述性 Top-Bottom 指标；没有证据它直接决定当前 TRAIN gate。验收应明确并列分组政策并按股序不变量验证，不以任选代码次序包装出因子区分力。

### D-01 / P1：因子月频回测把停牌/零量算作成交

位置：factor_miner/backtest.py `_holding_return`、`_exit_open_index`、`monthly_backtest`。只有开盘价和涨跌停检查，没有执行日 ST/停牌/成交量检查；信号日 pool_mask 不能替代成交日资格。

合成行 tradestatus=0、volume=0，入场10、退出11，返回 `(0.1,'executed',False)`；月报 `n_executed=1`、扣17bps后 `net≈0.0983`。同样的问题可发生在信号日合格、次日才停牌的股票。

影响：director.evaluate_units 的 TRAIN 成本阶梯和 run_validation_stage 的净边际门禁。不能用 quant.execution 已通过的测试替代这个独立回测实现的验证。

验收：按执行日真实状态拒绝买入/顺延退出；分别测信号后停牌、ST、未知状态、无量、缺 raw_preclose，保留每笔无成交/顺延/MTM 原因。

### D-02 / P1：非成交、递延与基准样本没有统一账本约束

位置：同文件 monthly_backtest。未成交股票从 gross_vals 剔除后重新等权，prev_hold 却更新成目标 hold；锁单延期返回最终收益却不返回实际退出日，后续月份独立再开仓；net 与 bench 分别过滤缺月再求均值，未强制同月配对。这些实现不足以证明组合现金、占用资金与同期净边际。

证据等级：静态数据流确认，尚未给每个分支完成全链人工账本。不可直接用此模块给 Top15 组合产品签执行资格。20万元/15只的名义等权约1.33万元，也不满足当前17bps研究口径“单笔≥5万元最低佣金不生效”的前提；这是新产品成本模型必须重新冻结的范围，并非擅改旧研究阈值。

验收：人工账本覆盖未成交留现金、延迟退出资金占用、目标与实际持仓、同月基准配对和实际逐笔费用。旧研究口径若刻意保留，应明确它是代理指标及其晋级适用性，不能标为真实组合收益。
