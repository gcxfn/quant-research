## 去留决定

原48格如实封存。F2不反向重选，C1/C2不追认为候选，不扩大原网格，不打开2024+。现有统计相关性没有转化为可用的扣费赚钱证据。

按盈利计划第7节，只允许提出一个有明确依据的新假设族。低波动候选微弱毛收益支持讨论“延长持有能否覆盖每次交易成本”，但本结果并未验证此假设。新方案必须披露来自已看结果、重新预登记、使用新批次，且持有周期超出用户确认的1—5会话目标，须用户确认后才实施。若用户坚持原周期且没有新增经济依据，暂停相同价量短线研发。
