## 总判定

**方案足以作为可执行的探索统计与前向登记方案**，前提是落实D1–D10最小修正。修正全部是定义、登记与留档层面的补充，不新增推断机械、不恢复V5、不引入复杂oracle、不解锁任何数据窗口。统计UNKNOWN与晋级BLOCK只作用于研究晋级声明和生产发布门禁，**不构成对P4–P6真实算法、后端联调与影子运行的阻断**；影子态保留executable=false、审核门禁与"接入不等于Alpha证明"的表述。方案的正确核心应明确背书：分母未知下不算探索p值、不称显著/确认，是统计上诚实的处置，应保持。

## 适用范围

- 探索历史：TRAIN 2020–2022三个年度分钟动态重放与迁移窗口2023-01至2024-12（设计24账户月）。"已观察"指信号与数据已实读并参与过评估与选择；确切已观察账户月合计数尚未核对，本文不作精确计数断言；三账户完整迁移收益待任务板最新实际批完成，本方案指标清单先冻结，数值后填。
- 适用对象：REV11（主序列）、固定50% PV1/REV11（次要描述序列，与REV11共享因子不作独立Alpha）、低换手对照（仅历史语境；退市缺MTM期间不作有效比较，恢复须另行登记）。TRAIN分钟口径：REV11 71.9355%/20.8684%、组合61.8740%/22.1057%、对照26.5005%/8.6191%，均为样本内描述。
- 前向：仅REV11主账户一条计入序列；起点为"后续数据授权且快照管线真实启用"后的第一个完整月末信号周期，按D1/D2的计入与绑定规则执行。2025+与当前2026数据不因本方案自动解锁。
- 不适用：任何对探索数据的显著性/确认性声明；晋级解除（BLOCK保持）；真钱放行与生产发布（另行决策）；V5类复合统计方法；为搜索分母编造精确总数。

## 搜索分母未知边界

- 已知计数只作下界登记：R0修复批248唯一评估单元（250假设/246结构）、R1池215行/213结构、财务26+5构造，彼此重叠不可相加；真实独立搜索分母未核定，状态保持UNKNOWN。
- 选择漏斗本身属搜索：在同类成功标准下多轮评估后存活2个结构（且共享REV11因子），不能当作2个独立检验；PV1分派修正、迁移旧批中止与重跑等数据依赖的实现迭代也属探索过程，一并披露（批次以任务板最新实际批为准）。
- 后果一：探索期不计算p值、不做任何误差控制声明（分母未知使逐比较校正无从谈起），报告措辞限于"样本内描述/探索性"，禁用"验证、确认、稳定、显著"描述探索输出。
- 后果二：未来任何确认性设计必须引用上述下界计数与漏斗披露作多重性考量，不得以"只测了两个"缩小名义检验数。
- 下界登记随候选冻结包一并版本化；后续新增机制批（B08）追加计数，只增不减。

## 具体缺陷与最小修正

| 编号 | 缺陷 | 最小修正 |
|---|---|---|
| D1 | "启用后第一个月末"未定义哪些月计入前向序列，存在事后补录空间 | 记录管线启用日期；某月计入前向仅当其建议在实施窗口前完成D2版本化留档。启用前已流逝月份（含已授权未登记的）只作回顾性探索历史，不计前向月数，照报不混入 |
| D2 | "唯一REV11主账户"缺身份冻结字段，前向可审计性不足 | 冻结包绑定公式/方向/参数/配置或代码版本、baostock分钟主源规则、费率与压力参数；每次建议留档绑定input_digest、strategy_version、strategy_snapshot_id、market_snapshot_id、input_account_version（与quantdesk.strategy_adapter.v1字段一致）及摘要哈希。算法变更（含缺陷修复）登记日期与原因，效应按版本分段报告；分段数据如何进入确认性分析由该方案自身事前登记决定，不预置计数重启规则 |
| D3 | 已观察窗口跨两段数据制度（TRAIN分钟重放vs迁移账户批），无披露合并会掩盖制度差 | 月度序列按段标注；任何2020–2024合并统计显式标注跨制度；迁移段数值待任务板最新实际批完成填充，缺失月照列不内插 |
| D4 | 固定描述清单缺费用、执行摩擦与数据状态维度 | 清单固定为：逐月/逐年净收益、回撤、暴露、集中度（含单股利润贡献份额）、佣金税费与摩擦合计、未成交订单率、现金日占比、逐月B01式数据状态（DATA_UNCERTAIN_DESCRIPTIVE等）、固定压力变体、配对月差与相关。部分年度只报累计不年化 |
| D5 | 前向仅REV11一条序列，效应描述需基线，且不得引入新数据前置 | 以可用现金0收益为已冻结可投资基线，即行可用、不新增数据依赖与前置门禁；如自愿补充宽基指数等参考，仅作附加描述，不作门禁、不作Alpha检验。低换手对照不纳入有效比较的裁决保留，退市MTM解决后另行登记再启用 |
| D6 | "成熟月"未定义；停牌/退市的估值处理未定（不得虚构清算或沿用陈旧价） | 月m账户收益于m月末估值输入齐备后成熟；因子研究的下月收益标签与前向月账户收益是两个概念，不得混用。退市不得按最后交易价虚构清算（002505已发生无法卖出、实际持有）：保留持仓与现金，无有效估值则NAV不可验证，该月照报但不计入有效比较。停牌仅在已核历史当日价格字段可估值时按该值计并标记，不得任意沿用陈旧收盘价。规则一次冻结不改 |

## 前向登记最低字段

1. 管线启用日期与首个计入月；数据授权范围声明（不自动含2025+/2026）。
2. REV11身份冻结包引用（D2全部字段）与现金基线定义（D5）。
3. 逐月建议留档：时间戳、版本与快照绑定、推荐列表与目标权重、现金/未成交、执行前归档证明（哈希）。
4. 成熟月规则与停牌/退市处理（D6）；逐月数据状态标记（D4）。
5. 12个月描述复核输出模板与确认性方案的登记触发条件（D7）。

## 明确不做

不恢复V5或任何复合统计oracle；不为探索数据计算p值/置信区间/显著性；不把2023–2024或前向首月称为未见确认集；不因UNKNOWN阻断影子工程，也不因影子运行顺畅反向放宽统计状态；不自动解锁2025+或生产。本审查不改变B02/B03/B04任何在途工作与裁决。
