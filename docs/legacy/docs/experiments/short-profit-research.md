## 可运行的候选

`configs/short-term-candidate.json`保存用户费用组训练选出的`momentum_market`：沪深300ETF收盘>SMA120且R60>0时才研究新买入；个股/ETF仍要求收盘>SMA20>SMA60且R20>0，按R20降序。条件数据必须覆盖当日，缺失则暂停新开仓；旧仓继续复评、止损、止盈。市场条件数据可读，不受是否开通该ETF交易权限限制；新买入候选仍受账户板块权限约束。

下一交易日限价=收盘−0.5ATR，止损=限价−1.5ATR，目标=限价+3ATR，费用后盈亏比至少1.5。数量仍受现金、单标上限和风险预算约束。5交易日复评，扣费浮盈且趋势持续可续持，最多10交易日。研究代码也保留未被最终选中的`trend_dip`：收盘>SMA60、SMA20>SMA60、R20>0、R3<0，按`−R3/(ATR20/close)`降序；此排序值不是预测胜率。

```powershell
# 研究计划：填入自己的账户；没有账户时是10万元等研究默认
python -X utf8 -m quant.cli short --short-config configs/short-term-candidate.json --account data/account.json

python -X utf8 -m quant.cli short --short-config configs/short-term-candidate.json --offline

python -X utf8 experiments/short_profit_research.py --config configs/short-profit-user-costs.json --output artifacts/short-profit/new-run
# 使用保存的协议、参数和实际行情复现，不依赖后来变化的清洗缓存

```

普通`short`仍采用原配置作对照；新候选通过显式`--short-config`调用。通用`short --backtest`输出的60/20/20分段与本次固定年份分段不同，请以实验报告判定本轮结果。

## 证据与限制

完整证据：`artifacts/short-profit/20260905-six-fixed/`（默认费用失败组）和`artifacts/short-profit/20260905-user-costs/`（用户费用校准组）。各含`protocol.json`、`base_config.json`、`input_pool.json`、六项训练逐笔回放、`selection_frozen.json`、基线/候选全期回放、压力参数与回放、`report.json`和`report.md`。输入快照支持以后在同一行情上复现；不修改原始数据。累计运行两组各六项训练比较（不是只试一项），所有结果都保留。

当前175只池经门禁后172只有数据，并非全A股历史动态股票池；当前在市池含幸存者偏差与池构建前视，历史ST、退市与板块权限历史不全，全文件质量门禁也依赖现在可见数据。前复权历史可能重写。日线触价仅为成交代理，不证明盘中可成交；停牌/一字行情不假定成交，同日双触及止损优先。期末含未平仓浮盈亏。

没有分钟级历史及人工实际成交样本，本轮没有将日线回测当作做T盈利证据。实际资金与佣金已校准，下一步需要可重现的盘中数据、今后积累的模拟/人工成交记录和独立审查；不能只靠在已看过的历史上不断改参数获得可信收益。

方法参考：[The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)。重复选择规则会夸大历史表现，因此本轮披露全部尝试、失败情景与测试集复用事实。
