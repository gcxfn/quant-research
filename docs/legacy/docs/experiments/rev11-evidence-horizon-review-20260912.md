# REV11确认证据期限：量级判断

2026-09-12。脚本experiments/rev11_evidence_horizon_20260912.py，证据artifacts/rev11-evidence-horizon-20260912-1/planning.json。仅用已完成TRAIN分钟结果；不改门禁，不做模拟，不读留出，不计算显著性。

扣除事先确定的起始2020年1月空仓月份，35个投资月收益标准差5.687965%。按[NIST已知标准差单侧均值检验样本量公式](https://www.itl.nist.gov/div898/handbook/prc/section2/prc222.htm)，以单侧5%与80%功效作说明，n=((z.95+z.80)*sigma/delta)^2。将当前样本标准差代替已知sigma后，年算术均值5%/10%/20%对应1153/289/73个月；36个月对应可检测年算术均值约28.29%。年算术均值=12×月均值，不是复合年化。

这些数字不是实际要求等待的期限，不是严格下界，也不是经过验证的真实功效。独立正态、稳定且已知方差均未证明；候选经过大量同窗选择，标准差估计有不确定性；真实收益存在相关和尾部风险。这里只回答绝对收益对零，不回答相对低换手的增量，更不允许把几千只股票当作几千个独立月份。

主审据此裁决：不承诺短期前向即可统计认证，不为凑PASS继续更换HAC/阈值，不设一个实际上等同永久停工的机械年限门禁。研究推进和证据等级分开；可继续有限历史迁移与前向准备，正盈利描述、可复现执行、统计增量证据、持续有效性分别记录。

确认计划具体收敛：

1. 维持单一REV11原方向/窗口/固定交易结构；不增加策略变体。低换手对照与候选必须同执行/费用口径，现有日线对照不能直接当分钟候选的严格增量端点。补齐这一对照属于比较基础，不是对同一引擎新增验证层。
2. 历史2023–2024只拟做一次固定配置的迁移检查，承认既有观察史，完整报绝对/对照差、年度/个股贡献、覆盖及成交限制，不授予全新样本外或科学PASS。入口仍按现有权限冻结，须完整可执行方案审核后才解锁，不能用本说明绕过。
3. 真正前向起点晚于最终冻结时点；先落盘事前权重/订单、输入时点、代码及账户身份，实际成交人工录入，允许研究账户零成交。前向监测中的中途观察、错误修正、版本变更全部留痕；看见赚钱就停止统计或回改起点均不允许。
4. 确认主端点仍拟定为同口径REV11减低换手的月净收益均值；相应差分波动与最小经济增益尚未冻结，不借本绝对收益量级示例冒充其功效设计。统计方法仍待有限方案审定，旧V5否决不变。
