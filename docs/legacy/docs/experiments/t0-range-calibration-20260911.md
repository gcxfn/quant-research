- 日期：2026-09-11；脚本：`experiments/t0_range_calibration_20260911.py`；工件：`artifacts/t0-range-calibration-20260911/`
- **研究性质，不改生产**：不修改任何生产入口（`quant/t0.py` 未动），不产出可执行信号，不构成择时或做T自动化依据。
- **这是区间校准研究，不是价格方向预测**：只回答「以置信度 p，当日波动幅度大概率不超过多大」，输出为校准的区间宽度，禁止表述为点位或方向预测。
- 选择窗纪律：仅使用 **2020-01-01..2023-12-31** 本地数据（`data/raw/user_dataset/2026-09-03/` 前复权，经 `quant.history.UserDataset`）；2024 起数据一行未读。内部稳定性对照=2020-2022 vs 2023。

- 目标口径：TR=当日(high−low)/preclose（日内区间）、TB=当日|close−open|/preclose（日内实体）。覆盖定义=实际 ≤ 预测。

## 2. 三个构造的冻结定义

| 构造 | 定义（占前收盘价比例） | 事前可知时点 |
|---|---|---|
| R1 | k × 昨日 (high−low)/preclose | 昨收后 |
| R2 | k × Parkinson：σ_P=sqrt( mean20(ln(H/L))² / (4·ln2) )，20 个可交易行窗；日 bar 数=1（×√1） | 昨收后 |
| R3 | k × ( 0.5×\|open_t/preclose_t−1\| + 0.5×mean20((H−L)/preclose) )，权重冻结 0.5/0.5 | 开盘竞价后 |

歧义读法（冻结声明）：

1. R2 按规范 Parkinson 除以 4·ln2（任务文本「Parkinson 波动估计」以标准定义为准）；且用 ln(H/L) 保证前复权价格水平不变性。已知后果：BM 下 E[range]≈1.6·σ_P，k=1 系统性欠覆盖属预期，不据此改公式。
2. R3 隔夜项取**当日**跳空（开盘后即知，事前可用；做T决策点在开盘后），20 日均项截至 t−1。
3. 停牌行（有价无量）不进入回看窗与评价；「昨日」=该股上一**可交易**行。
4. k∈{0.8,1.0,1.2} 三档全部报告，不挑最好；覆盖率声称 80% 的诚实带宽=75%–85%。

## 6. 结论

### 诚实性判定（全期覆盖率是否落入 [75,85]）

落入诚实带宽的 cell：R1 k=0.8 目标TB（全期 76.63%）；R1 k=1.0 目标TB（全期 84.19%）；R2 k=1.2 目标TB（全期 80.28%）；R3 k=1.2 目标TB（全期 75.84%）。

### 描述性校准曲线（非重跑、非合格判定）

各构造 ratio=实际/基础预测 的经验分位（基础预测为 0 的行无比率定义、剔除，TR 口径剔除 210 行，主要是前一日一字板）：要把某构造用作「80% 覆盖」区间，所需 k 及其稳定性含义如下（仅为校准曲线披露；采用该 k 属新参数，须新一轮冻结）。

### 主审判断（2026-09-11，一次性结论；数字引用自上文各表）

**总判断：部分合格，且合格面窄。**

1. **TR（日内全程区间，做T最相关口径）：冻结的 9 个 cell 全部不合格。**最高仅 R1 k=1.2 的 65.4%，距 75% 下沿差近 10pp。R2（10.4%-38.7%）、R3（5.2%-27.7%）欠覆盖更严重，且高波半覆盖比低波半低约 3-15pp（如 R2 k=1.2：高波 31.1% vs 低波 46.3%），对市场状态敏感，属最不诚实。
2. **R1 是唯一稳定构造。** TR 口径 R1 k=1.0 覆盖 51.5%，2020-2022 vs 2023 仅位移 0.3pp，48 个月全部落在 48.2%-54.1%，高/低波半差 6.3pp——它是可信的「**中位数口径**」陈述：当日区间约一半情况不超过昨日区间（预测宽度中位 3.18%，与实际 TR 中位 3.17% 匹配，量级对做T有意义）。但它不支撑任何「80% 覆盖」表述。
3. **TB（日内实体）口径有 4 个 cell 落入诚实带宽**：R1 k=0.8（76.6%）、R1 k=1.0（84.2%）、R2 k=1.2（80.3%）、R3 k=1.2（75.8%）。其中 **R1 两档跨时期最稳**（高/低波半位移 5.5-6.7pp、2020-2022 vs 2023 位移 ≤1.2pp；2023 检查段 R1 k=1.0 达 85.0 贴上沿，超出 0.01pp，方向保守）；R2 k=1.2 高波半 75.5% 贴下沿勉强可用；R3 k=1.2 高波半跌出带宽（70.7%），不推荐。失真方向主要为过度覆盖（低波半 >85%），对上界区间属安全方向（偏保守、浪费宽度而非欺骗）。
4. **条件校准缺陷（对做T最重要）**：以 R1 k=1.0 为例，TB 覆盖随预测宽度单调上升——预测宽度 <2% 的日子覆盖仅 65%-74%，≥5% 的日子 93.2%。即「预测平静的日子」恰是区间最不可信的日子；全期覆盖率掩盖了这一条件性过自信。任何实际引用必须以 §5 分箱校准为准，不能只引用全期数。

**建议下一步（均为新研究动作，不在本轮内执行）：**

- 若产品需要 80% 覆盖的「日内区间」带：以 **R1 k≈1.5**（经验 80 分位 1.51，见校准曲线）为唯一候选参数，对 **2024-01 起的留出窗做一次性考试**——只验不改；通过并留档后方可作为「波动率情景区间」合规输出口径。禁止在选择窗内继续调 k。
- 本轮唯一可直接引用的诚实结论：R1 k=1.0 的约 50% 中位口径（TR）、R1 k∈{0.8,1.0} 的实体口径（TB，75-85% 且跨期稳）；引用时必须附带 §5 分箱校准与 st_unknown 披露。
- R2（规范 Parkinson）与 R3（跳空组合）在本任务冻结形式下不合格（欠覆盖 + 状态敏感），不进入下一步。
