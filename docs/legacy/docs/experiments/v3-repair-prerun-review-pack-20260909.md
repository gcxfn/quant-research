## 实现中发现的预登记歧义点（8 条，代码与工件已披露）

**请 Codex 逐条裁决这些解释性读法是否可接受；如不可接受请指出须改的读法。**

1. **臂C"前20个交易日等权日收益"**：读为截至信号日最近 20 个日收益（需 21 个收盘含信号日收盘）；等权组合日收益=共同交易日上成员均值；信号日收盘在次日开盘执行前可得。
2. **臂C 重叠日计算**：取全部成员最近 20 收益日期的交集，交集 <15 豁免（w=1.0 计豁免）。
3. **臂A 相关性窗口**：各取最近 120 个日收益按共同交易日对齐；共同日 <60 不约束；零方差无法计算视为不约束（不因数据缺陷扩大剔除）。
4. **k<3 槽位规则的适用形态**：预登记将槽位规则写在臂A 下 → 仅臂A 生效的形态（A/AB/ABC）按 equity/3 槽位预算、空槽持币；纯 B/C/基线沿用 R3 原行为（budget=total/target_count）。**注意：C 与 ABC 形态同时受 w 缩放与槽位规则叠加，ABC 中 k<3 时每只 = w×equity/3。**
5. **臂B 排名名次语义**：名次 1=最强，">6"为严格大于；并列取 1-based 平均名次。
6. **臂B 卖出与月末目标同日冲突**：B 卖出在月度调仓开盘先执行，当日不回买（沿用引擎 exited_today 保守路径）；被 B 卖出后月末再入选 → 月末再平衡允许回买（"月内不补仓"仅指月内）。
7. **臂C 调平的整手近似**：目标槽位按开盘价整手（100 股）取整；当日无 bar 的持仓跳过调平保留股数并计 REBAL_SKIPPED。
8. **水下总数起点**：从窗口内第一个收盘净值起算峰值（不含窗口前初始资金日），基线与变体同口径。
