# 个股与基本面数据源探针报告

- 探针日期：2026-09-04
- 目的：扩展数据面——个股日线（长历史、前复权）、全市场横截面快照、季度财务指标；全部**免 key**，与现有同花顺（ETF primary）互补。
- 结论：**个股日线采用腾讯前复权为 primary、新浪未复权为交叉复核（复用现有门禁）**；基本面快照与财务采用东方财富公开接口。

## 单位与口径对齐（关键）

- 现有同花顺 ETF 日线 volume 单位为**份**（510300 日成交 ~6-8 亿）。
- 腾讯日线 volume 单位**按板块不同**（2026-09-04 用 qt 快照换手率反推成交量交叉实测，10 只样本）：
  - 沪深主板/创业板/ETF：**手**，×100 折算为股/份；
  - **科创板（sh688）：原始即为股**，不再折算（若误 ×100 会把寒武纪/中芯国际等成交额虚增百倍，换手率反推 >100% 可证伪）。
  - 统一入库为股/份，保证 `close*volume≈成交额(元)` 的流动性口径全源一致。
- 前复权锚定最新价：腾讯与同花顺同口径；历史价随公司行为重写，复现以原始响应哈希为准（与 AGENTS 工程规则一致）。
- 跳变门禁沿用 21% 阈值：主板 ±10%、创业板/科创板 ±20% 加前复权除息漂移不应超 21%；ST（±5%）标的在股票池构建时已排除。

## 财务数据的时点纪律（防未来函数）

F10 接口只给报告期（REPORT_DATE），不含公告日。**研究约定：报告期 Q 的财务数据视为在 Q 结束后 90 天才可用**（保守滞后，覆盖披露上限），回测类因子严格按此取数；`analyze` 实时分析只用「最新已发布报告期」，不存在该问题。

## 印花税（个股成本模型）

A 股股票卖出印花税现行 0.05%（2023-08-28 减半），ETF 无印花税。个股回测成本模型在佣金/滑点基础上新增 `stamp_sell_bps: 5`，仅在卖出侧收取。

## 局限与风险

1. 东财接口为公开网页接口，无 SLA；字段语义经实测推断（f9=PE-TTM、f23=PB、f37=ROE 与 F10 值交叉验证一致），若字段变更需重探。
2. **限流实测（2026-09-04）**：腾讯 ifzq 行情接口在约 0.2s 节律连续请求约 250 次后触发 WAF——先是返回 `param error` 空数据，随后升级为 HTTP 501 拒绝全部请求（含此前成功的 URL 形状），约数分钟后恢复。**缓解**：抓取层页间 0.8s、逐标的 0.9s 节律 + 连续 10 只失败即熔断中止；东财 push2 主机同样存在 IP 限流（`qt/stock/get`+fltt=2 稳定断连），批量快照已改用腾讯 qt 主机。重跑脚本即可恢复，无需换源。
3. 幸存者偏差：全市场列表为当前在市标的；股票池构建时按上市日期排除次新股，历史回放仍含幸存者偏差（披露）。
4. 财务因子采用 90 天保守披露滞后，略晚于真实公告日，属保守方向（不引入未来函数，代价是因子可用性延后）。
