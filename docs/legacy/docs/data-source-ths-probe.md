## 已知伪影与处理

- sz159915 于 2024-10-08 在前复权序列显示 +24.56%（超 ±20% 涨跌停限制）。
  交叉复核新浪原始价：+19.98%，在限制内。原因为**除息日恰逢涨停日**，
  前复权调低了除息前基价。处理：用新浪原始价自动复核，
  原始收益在涨跌停限制内的跳变判定为伪影，保留标的并披露（见 `quant/cli.py` `_verify_jumps_with_raw`）。
- 跳变门禁阈值 0.21：区分「涨跌停 + 复权漂移」（≤~20%）与「份额折算」（实测 ≥27%）。

## 局限与风险

1. 前复权的历史价格会随未来分红重写——复现以原始响应哈希为准，不做跨时点静默对比。
2. 5 年深度导致样本下限显式下调（min_trading_days_total 1000、min_segment_days 240），已写入配置 sample_note。
3. 复权因子端点不覆盖 ETF，现金分红无法单独建模（已含在前复权价格中）；未复权执行价与复权估值间存在除息日口径差，当前以同一复权序列近似，报告中披露。
4. 免费/配额条款以官方帮助中心为准；本报告未验证长期配额与稳定性。
5. API key 只经环境变量 `THS_API_KEY` 使用，禁止写入仓库。
