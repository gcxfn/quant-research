## Safety & Trading Rules
- 周内入场固定对照（2026-09-05）：`experiments/weekly_entry_research.py` / `configs/weekly-entry-research.json`研究回撤企稳、放量突破首次回踩、ETF超跌修复；股票/ETF分开，共7组，共用五日退出、排名、价格、费用和风险。只按2020—2023选择，披露2024起、逐年及2016起结果。不得把两个独立10万元账户的收益相加；实验callback不能当默认short配置使用。证据见`docs/experiments/weekly-entry-research.md`，独立审查未完成。

- 盈利策略研究（2026-09-05）：用户接受约20%账户回撤的平衡取向，确认10万元、股票万2.5最低5元、ETF万1无最低。`configs/short-profit-research.json`固定六项假设；`configs/short-profit-user-costs.json`按确认费用重跑相同六项。完整证据见`docs/experiments/short-profit-research.md`。`configs/short-term-candidate.json`宽基趋势过滤候选通过本轮历史筛选，但训练优势小且历史已看过；仅显式研究调用，不替换V3或默认short，不标可执行，独立审查与全新样本外未完成。宽基过滤缺少当日已完成数据时停新开仓，已有仓位仍复评退出。做T没有分钟级盈利证据，不据此更改择时。

## Engineering Rules
- 原始行情、清洗数据、策略参数、回测结果和信号日志分层保存；原始数据不可被结果覆盖。
