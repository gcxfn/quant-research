## 1. 假设（家族级）

事件冲击后存在可交易的价格漂移（做多方向）；解禁是可避的坑（仅作过滤器）。A 股做空不可行，全部构造只研究做多与过滤价值。判定表述只能是"事件家族的代表构造在本成本/频率/执行口径下是否通过"，不判死家族。

## 2. 数据与运行前提

- forecast / express：20260909-r1 批次，已抽审 PASS（ann_date 100%）。
- repurchase / stk_holdertrade / share_float：20260909-r3 批次（下载中）。**运行前提 = 下载完成 + 主对话抽审 PASS**（行数、公告日非空率、退市股覆盖、周末公告处理、月度分布连续性）。
- 日线与时点池：P1 无偏池（本地数据集主源 + baostock 退市股/逐日 ST/停牌掩码）；涨跌停价统一 `quant.market.limit_price`。
- 口径：公告一律按**收盘后发布**处理（次日开盘入场）；事件表 ann_date 缺失行剔除并计数披露；时间轴按市场日历（tushare trade_cal SSE）。
- **缺行处理（冻结，继承 MR note_14 语义）**：股票缺行（无价格数据）以不可成交占位行补齐在市场交易日轴上；**市场交易日一律推进会话计数**（窗口/持有/强退日期不变），缺行日不产生信号、不可成交、无价格观测（不凭空补价）；**缺行只影响估值与可成交性**——到期日缺行无法退出 → 进入递延（§4）。

| 构造 | 源表 | 事件定义（冻结） | 方向 |
|---|---|---|---|
| E1 业绩预告 | forecast | 同股同报告期取 ann_date 最早一条；类型分层：利好={预增,略增,扭亏,续盈}、利空={预减,略减,首亏,续亏}、其他={不确定} | 仅利好做多；利空/不确定只作过滤器研究 |

| E3 重要股东增持 | stk_holdertrade | **同股同日一次交易机会（V4 裁决冻结）**：事件 = (ts_code, ann_date) 一次；同日多股东行合并为一事件，股东明细（holder_type/holder_name）仅用于分层披露，不进入收益加权；in_de='IN' | 做多 |

| E5 限售解禁·避雷过滤 | share_float | **可知性（防前视）**：仅 ann_date ≤ 决策日的记录参与过滤；ann_date 缺失行不参与过滤并计数披露（数据快照性质、无回填）。**过滤窗口（冻结）**：[float_date − 5 个市场交易日, float_date]（含两端）；入场会话落在窗口内且解禁已公告 → 剔除该入场事件 | 仅过滤器，不作做多信号 |

## 4. 两阶段设计

### 阶段一：毛筛（家族代表制，便宜）
- 对 E1–E4 各构造做事件研究，期限 h∈{1,2,3,5,10,20}，两组曲线并列报告：
  - **诊断组**（仅描述，不用于晋级）：公告前收盘起算，含跳空；
  - **可交易组（晋级线唯一依据）**：起价 = 公告次一交易日**开盘价**，终价 = 入场后第 h 个市场会话**收盘**（入场日计第 1 日；**会话按市场日历推进，缺行日也计入**）。
- 基准 = **全 universe 等权组合（V4 裁决澄清：独立于事件发生与否的全股票池，按对应时点价格有效性判定资格；资格规则可与信号池门禁不同，但必须真是全市场）**同窗同起止口径（同样次日开盘起算），超额 = 可交易组绝对收益 − 基准收益。
- 事件日块 bootstrap 95%CI（块长 20、B=10000、种子 20260909，沿用 MR R1 协议）。
- **晋级线（冻结）**：存在 h∈{3,5,10,20} 使超额毛均值 ≥ 2×17bps = 34bps 且 bootstrap 95%CI 下界 > 0。
- **期限唯一选择规则（冻结）**：多个 h 晋级时，取超额毛均值最大者；并列取更短者。**选择窗边界**：阶段一只用选择窗内完整标签（入场后 h 会话收盘 ≤ 2023-12-31 最后交易日）的事件——跨窗未完成标签的事件不参与期限选择。
- E5 过滤器价值单独评估：在 E1/E2 事件上叠加"解禁窗口剔除（§3 可知性规则）"前后对比，描述性报告，不设晋级线。**（V4 裁决澄清）E5 不得进入正式晋级、期限选择与阶段二——正式统计一律用未叠加 E5 的事件集；E5 只产出 E1/E2 的前后对照章节。**
- **（V4）选择窗左边界**：事件须在入场 ≥2020-01-01 才进入阶段一统计；预热数据不得成为筛选样本（与完整标签右边界一并执行）。

### 阶段二：净验证（留出窗）
- **成交/递延/期末估值继承 MR R1 四轮审核语义**：
  - 入场 = 公告次一交易日开盘（一字涨停开盘 no_trade 如实记）；
  - 强退 = 第 h 市场会话**收盘**（会话按市场日历推进，缺行日计入）；
  - **强退受阻（收盘跌停/无量/掩码/缺行占位）→ 转入待退出状态，次一可交易日【开盘】重试卖出（开盘价成交，exit_mode=force_deferred 语义）；开盘仍无法卖出则继续递延**——继承 MR 实现，非本轮新规则；
  - 期末未平仓 MTM 记双边费用【估算清算成本】口径。
- 持有期 h 取该构造阶段一唯一选定值，单值不扫描；费用 17/27/37bps 三档；机会净期望分母含 no_trade 事件。
- 窗口：2020-01-01→2023-12-31 构造/筛选；2024-01-01→2026-08-28 一次性留出（数据末端以实际批次为准并披露）。
- 披露：2024—2026 已被其他研究观察过，属冻结后历史留出而非新样本外。

## 5. 成败标准（事前，留出窗，逐晋级构造）

- **裁决规则（冻结）**：17bps 机会净期望的双侧 Bonferroni 校正 CI 下界 > 0，其中分位端点为 0.05/(2N) 与 1−0.05/(2N)（N = 晋级构造数）；且**已成交事件数 n_executed ≥ 30**（n 按实际成交计；no_trade 仍进入机会收益分母，与 MR R1 一致）；且 Top5 集中度 ≤ 50%。
- **Top5 公式（冻结，继承 MR 贡献度公式，按股票聚合而非按事件）**：contrib_i = 股票 i 在本构造内的 17bps 净盈亏合计（可正可负）；Top5 占比 = Σ_top5 |contrib_i| / Σ_all |contrib_i|；**Σ_all |contrib_i| = 0 → 该构造直接不通过**（零盈亏总量无法评估）。
- 块 bootstrap 退化处理（事件日 ≤ 块长 20）：fail-closed，该构造不通过（沿用 MR R1 规则）。
- PASS = 该代表构造成为研究候选（非可执行）；FAIL 如实封存，不追加参数搜索；家族级结论按"代表构造在本口径未通过"表述。
