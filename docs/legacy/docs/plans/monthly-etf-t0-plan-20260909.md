# 产品主线计划：月频ETF轮动 + 做T辅助（2026-09-09）

**状态：方向已确认；本轮用户指定Terra（high）实现、主对话派发审核，限定工程和固定样本工件已完成。严格样本外及数据缺口仍未完成，最终裁决见 `D:/AI/workspace/个人量化/docs/experiments/monthly-etf-t0-independent-review-20260909.md`。**

## 1. 决策与角色定位

- **引擎：V3 月频 ETF 轮动**（`signal`/`plan`/`backtest`，现行生产默认规则）——负责方向选择与beta控制，是收益的主要来源。
- **增强器：`t0 --symbol` 做T辅助**——只在已有底仓上摊低成本，不负责选标的。
- 放弃"每周价量短线选股当引擎"的路线：P3/P4证据表明，在真实成本结构下（年约80次往返×0.18pp≈16%/年成本拖累），日线价量因子的毛收益（最好约5.6%/年）数学上无法覆盖。P4 R2 ETF混合池预登记草案（docs/plans/p4-r2-etf-mixed-pool-preregistration-draft-20260909.md）随本决策**搁置**，其未确认条款不再推进；已批准的ETF排除规则（D-2026-09-09-04）继续有效，适用于一切ETF池构建。

## 2. 诚实量级预期（不得夸大）

- 月频ETF年换手约12次，ETF往返约0.12pp，年成本拖累约1.4%——成本结构在此频率下不再是瓶颈，这是本路线成立的数学基础。
- 做T增强的现实量级为每年几个百分点，**不能**把年化10%的目标押在做T上；目标仍主要依赖底仓方向收益。
- 做T建议无分钟级盈利证据（无1分钟数据，5分钟bar判断限价成交天然偏乐观）：t0输出是"费用后保本价位+波动带参考"，不是验证过的择时。不据此更改任何择时规则。
- V3基础规则为生产默认，但最严格的独立样本外验证未完成，此状态须在任何对外表述中披露；输出不构成收益承诺。

## 3. V3 月频 ETF 注意点

1. **规则不变**：月末 R20/R60/R120 横截面百分位等权合成 Top3 等权；门禁为趋势（close>SMA120 且 R60>0）、上市满252日、20日流动性。未完成独立样本外验证前，不得把 RSI、已实现波动、量能比、距高点等附加门禁写入生产排名或门禁。
2. **月频调仓 ≠ 月度才看盘**：调仓决策按月执行，但每日收盘后照常检查数据完整性与门禁状态；宽基过滤缺少当日已完成数据时停新开仓，已有仓位仍复评退出。
3. **趋势门禁的固有代价**：尖顶V型反转会吃掉第一段下跌才退出；持续阴跌段空仓拿现金是特性不是故障，不得在事后补回"错过"的反弹。
4. **ETF池维护**：现55只为在市快照，有幸存者偏差，须披露；排除QDII/跨境/债/货/北交所按 D-2026-09-09-04 冻结规则执行；池定期刷新，实时名称优先于旧池名称。
5. **涨跌停口径**：按已核验逐只、生效日 `limit_pct_schedule` 判断ETF 10%/20%，ETF tick 为0.001；缺少逐只元数据不猜测。`analysis.bar_side_locked` 工程修复已完成并经限定复核；做T档位在涨跌停价可得时按真实价格限制。
6. **费用口径**：ETF 万1、无最低、免印花税，滑点假设万5双边为研究保守口径。

## 4. 做T辅助注意点

1. **T+1 约束是硬规则**：只使用当日**可卖底仓**（非总持仓）；无底仓不给新T对；有底仓零现金可提供先卖后买的反T。新买入严格T+1。
2. **费用后保本口径**：只列扣费净额为正的档位，显式给出最小可行价差；禁止用未扣费价差误导。费用含双边佣金、最低佣金、印花税（ETF免）。
3. **最低5元对做T的实际影响（重点）**：股票做T单笔若1万元，万1佣金=1元但最低收5元，实际费率万5/边，保本价差被显著抬高——**股票小额T对在万1不免五下多数不划算**；ETF无最低佣金，不受此影响。这从成本上进一步支持"ETF底仓+做T"的组合。股票做T单笔金额需≥5万元万1才真正生效，t0引擎已按最低佣金分段建模（有单测），但用户应理解档位变宽的原因。
4. **数据门禁**：快照过期、当日无成交、日线失效、实时ST名称与旧池不符时不给新做T对；离线价仅作参考。
5. **人工执行**：`open_t` 为人工实际成交输入，未完成时只续算原交易、不重复建议开新轮；允许隔夜；不自动成交、不修改账户。
6. **手数与权限**：科创板最低200股且1股递增、北交所100股且1股递增、其他100股整手；账户板块权限可配置。

- 两个独立10万元账户的收益不得相加；费用按账户实际口径（股票万1最低5元、ETF万1无最低）。
