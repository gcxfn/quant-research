## 2. 统一粗筛协议（冻结）

- **窗口**：仅 2020-01-01→2023-12-31；2024-01-01 起零接触（任何读取/统计）。
- **事件型（②③全部）**：沿用事件家族 R1 冻结口径——事件=公告/上榜次日开盘入场（P1 完整门禁、一字涨停开盘 no_trade）；h∈{3,5,10,20}；超额=可交易口径绝对收益 − 全 universe 等权同窗基准；事件日块 bootstrap（块长 20、B=10000、种子 20260909）95%CI。
- **因子型（④）**：月末截面 RankIC（因子值 vs 下月收益）；**月块** bootstrap（块长 3 个月、B=10000、种子 20260909）95%CI；Top-Bottom 十分位组合月频毛收益差（描述性）。
- **晋级线（粗筛层，宽进严出）**：
  - 事件型：某 h∈{3,5,10,20} 超额毛均值 ≥34bps 且 bootstrap 95%CI 下界>0；
  - 因子型：|RankIC 均值| ≥0.02 且 CI 不含零 且方向与 §1 经济先验一致。
- **统一多重检验披露**：本轮 N=15，粗筛层 α=0.10/15（宽进）；**晋级≠有效，仅授权该构造进入精测预登记**（净成本+交易结构+留出窗一次性验证，逐个走全流程）。
