## 诊断问题（全部描述性）

1. **回撤时间结构**：最大回撤的峰/谷/（如有）修复日期；全部深度≥10%的回撤区间清单：峰日、谷日、深度、持续交易日、是否已修复、修复耗时。
2. **持仓归因**：最大回撤区间内逐笔已实现盈亏 + 区间内未实现MTM变化，按ETF汇总贡献排名；检验是否集中于创业板/科创类（20%限幅标的）。
3. **门禁行为分类（核心）**：对最大回撤区间及每个≥10%回撤区间内的亏损回合：
   a. 趋势破坏日（该标的首个 close<SMA120 或 R60≤0 的交易日）vs 实际卖出执行日 → 滞后交易日数、滞后期间该仓位亏损；
   b. 区分**规则内滞后**（门禁只在月末信号日评估，月内下跌属规则设计）与**规则违例**（若发现 signal_date 当日门禁条件不满足仍执行买入，属实现缺陷，单独列为缺陷项报告，不在本诊断修复）；
   c. **whipsaw**：退出后60个交易日内重新买入同一标的且该回合再次亏损的次数与合计亏损。
4. **beta 对照**：同窗 sh510300 买入持有回撤与区间收益；R3策略 vs 基准的超额回撤分解（市场beta贡献 vs 选择/轮动贡献）。
5. **现金日分布**：52个纯现金日落在哪些区间；门禁空仓是否避开了后续下跌（避开幅度描述性统计）。
