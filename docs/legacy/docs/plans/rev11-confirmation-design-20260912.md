## 统计与执行的停止线

旧V5保持METHOD_REJECTED，不修参数追回TRAIN显著性，不再对35个月做全248巨大模拟。此草案不指定未经验证的替代检验、置信阈值或观察期长度。

下一步按顺序完成：

1. 从REV11已存在账户中定位实际分红、成交容量与限价依赖，限定处理影响本候选的缺口，保留原批次。一般运行加固后置。
2. 在不打开留出收益的情况下，核候选直接访问记录及此前端点/交易结构选择；以现有文件补记录，缺失标UNKNOWN，不建设通用审计平台。
3. 根据拟接受的最小经济增益、相关性/尾部假设和可用月数制定一个有限统计方案及功效预算；必要的假设不能靠模拟PASS证明真实适用。达不到可识别精度就判证据不足，不扩大参数搜索。
4. 将历史迁移检验与真正前向确认分别预登记。历史检验仍须主审依据完整方案审核并遵守既有解锁权限；未授权时不执行。前向计划必须固定候选、起止日期、停止/改版规则和全部输出；中途改策略则另开版本、保留失败史。

R1/R2新机制不是永久停止，但不得以当前孤立正信号自动扩矿。当前不需要再做一轮全系统审计；先把真实收益可用性和有限确认出口做实。
