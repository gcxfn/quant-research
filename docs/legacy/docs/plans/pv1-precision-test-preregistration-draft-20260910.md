# PV1（隔夜收益动量）精测预登记（2026-09-10）

状态：**草稿，待用户批准冻结**。来源：家族批量粗筛轮唯一晋级构造（Codex 第一轮裁决确认：IC +0.026118、95%CI [+0.008051, +0.047142]、按 α=0.10/15 折算 99.333%CI 下界仍 +0.001974）。
定位：粗筛晋级≠有效；本轮为该单一构造的全流程精测——净成本+交易结构+**留出窗一次性验证**。N=1，无任何参数搜索空间。

## 1. 构造（与粗筛实现逐位同构，禁改动）

- **PV1 = 当月 Σ(open_t / close_{t−1} − 1)**：t 遍历当月全部市场交易日，t−1 为前一市场交易日（可为上月末收盘）；价格缺失/非正/非有限日不计入；当月有效日 <10 → 因子缺失不参与截面。
- 月末 t 收盘截面，P1 时点池（status_eligible ∧ pool_ok：252 会话+20 日流动性门禁，严格 <t 口径），与粗筛同池（含 baostock 退市股）。
- 方向：PV1 高 = 强（粗筛冻结先验 +）。

## 2. 组合与执行（冻结）

- **做多最高十分位**（按截面股票数向下取整，≥10 只才成立；等权）。Bottom 十分位与全池等权仅作描述性对照。
- 信号：月末 t 收盘后；执行：t+1 开盘买入（T+1 纪律，下月末调仓时 t'+1 开盘卖出/换仓）。
- 涨跌停：开盘=涨停价 → 该股本月不入场（计数披露）；开盘=跌停价卖出受阻 → 顺延至下一可成交开盘（保守，披露计数）。
- 退市：持仓股退市中断 → 按最后可得收盘估值剔除（披露）。
- 期末：最后信号月 2026-08 月末，持有至留出窗右端 2026-09-08 收盘按收盘估值，不强制平仓交易。

## 3. 窗口（冻结）

- 对照披露（已看过，不参与判定）：选择窗 2020-01-01→2023-12-31 同规则回测。
- 污染披露：2024 起曾被 MR R1/事件家族以一次性样本外观察（均负）；PV1 自身 2024+ 零接触。
