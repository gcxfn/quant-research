## 2. 审计缺陷分级：按真实影响定级，不按攻击词定级

- **A 级（阻断受影响路径）**：存在具体实现/数学缺陷，或存在现实可复现路径可污染研究结论。处置=阻断受影响路径直至 修复→作者针对性验证→独立复核 收口；不自动阻断全系统其他路径。
- **B 级（可靠性，可补偿）**：运行/证据可靠性问题（日志覆盖缺口、证据写失败、重跑覆写证据、快照口径漂移等）。若可通过隔离、独立工件复算、限定输出、事前哈希留痕等充分补偿，则不自动阻断研究；补偿措施与残余风险必须留档。
- **C 级（技术债）**：超出已声明威胁域的本机恶意/管理员级攻击、或无具体影响路径的理论加固。登记技术债，不阻断 R0 与研究主线。
- **篡改类不是天然 A 或 C**：按「真实风险+可复现路径」定级。按当前证据示例：launch_dir 全量协同改写骗过验收（r0-review Attack A）= A——现实路径、可污染验收结论（fix-round3 已修复，独立复核收口后解除）；作者探针脚本重跑覆写其证据文件 = B——重跑前哈希核验可补偿（mt-review F6 已按此处理）。
- 定级由主审内容裁决；实现/复核代理可提议分级并给理由；**争议项临时仅隔离受影响结果**（不自动全局阻断研究），定级待主审裁决；证据收集不因争议搁置。

## 3. 停止规则：审查层数有界，发现能力有 oracle，科学阻断有明确定义

1. **科学阻断的定义不限于「无效变有效」**（主审补充，源自《优化验证强度》讨论）：静默清零（本应产生的信号/幸存者被无声清空）、系统性误淘汰（真实候选被系统性排除出池/出批）、故障冒充研究失败（实现/数据/回测故障被记成「策略无效」）同样损害研究能力。三者均按 §2 分级阻断，直到有**正例 oracle** 证明发现能力——已知「应被发现的构造」（植入的已知有效样本或已知缺陷样本）在当前管线中必须被发现；发现能力未证明前，相关批次结论不得标注为科学结论。
2. **停止条件（收口判定）= 以下全部成立**：正常路径回归通过 + 历史缺陷回归（既有反例库全部复验）+ 事前按风险选定的关键正负例（含正例 oracle）通过 + 一次独立复核无新反例 + 无未处置的相关科学缺陷。
3. **不硬造数值配额**（如「必须 3~5 轮审查」「必须 N 层复核」），**也不无限叠加第三层**；重新触发审查的条件=新具体反例、受审字节哈希漂移、或输入数据/冻结协议身份变化。
4. 合成数据可证明**生成模型域内**的统计操作性质（如门禁在合成总体上的覆盖率/FWER 行为、管线正向链路与拒绝路径），**不能外推为真实 Alpha 证据**。本文不在合成与真实之间新设未定义前置（不把「真实批验证」等新造成门禁）；真实数据结论按既有冻结协议与已登记授权推进。
5. 每轮收口留档（反例编号→修复→复核证据→主审结论）入对应 fix_record/审查报告；本文不另设新账本。

## 5. 执行顺序（草案；并行线不缩目标）

1. 收口已有具体缺陷（各线 CHANGES_REQUESTED 项；启动器 fix-round3 待独立复核 Halley 收口）+ 统计门禁相关科学证据收口——**按「现冻结协议有效性」与「已登记处置路径」分别裁决：v4.1 生效不是唯一 R0 通道**；未知/未闭合项不得当作显著性 PASS；
2. 受控真实 TRAIN 风险样本/资源验收（R0-3 小样本演练；不触 VALIDATION/LOCKBOX）；
3. 主审启动包裁决；
4. R0 正式 TRAIN（授权边界不变：TRAIN-only；VALIDATION/LOCKBOX 与统计协议变更仍须用户单独授权）；
5. R1 及其他已存候选按既有冻结流程处理；**新的研究须既定冻结（预登记+用户确认）方可执行**；
6. 留出/组合/前向验证（攒批统考队列按既有授权范围推进）。

组合层风险（容量/逐笔费用/现金竞争/成交限制/收益集中）：按实际调用时点提前检查，**组合精测前必须闭合**；不把与当前调用无关的产品要求全部塞进 R0 门禁。

系统 S0–S7 与上述顺序并行推进，不因 R0 放行而终止或缩水。
