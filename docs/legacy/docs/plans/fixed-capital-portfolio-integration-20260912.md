# 固定20万元组合研究接入契约（2026-09-12，主审设计草案）

状态：待实现/验证，不是推荐规则冻结，不授权真实留出或产品上线。

## 已确认的复用边界

experiments/factor_miner/backtest.py monthly_backtest 当前每月执行 capital_base=max(0,k_slots-n_carried)*trade_notional、injection=capital_base-cash、cash=capital_base；买入以cash+fees_paid判断本金，随后扣本金与费用。该路径披露为研究proxy，不能直接充当固定20万元账户的资金曲线。保留原协议和旧结果，不在其上静默改变账户假设。

quant/execution.py Replay已有共享现金、可卖库存、逐笔费用、成交参与上限与公司行为基础。2026-09-12现有两组execution测试73项通过；并非组合产品验证。Ledger.equity对缺价默认0，组合适配层不能直接依赖该缺省行为。

## 新研究入口的最小接口

输入为冻结的带signal_at/data_as_of的目标权重序列、初始现金200000元、完整时间顺序行情、已核公司行为和显式费用参数。该入口接收权重而不生成/优化权重；股票数量、打分、行情调整、补仓及卖出规则仍须另行预登记。合成测试权重不构成投资推荐规则。

1. 初始注资只发生一次；外部现金流默认零。如显式导入实际现金流，单列并从收益中剥离，禁止为填满槽位自动充值。
2. 目标权重须有限非负、合计不超过1；空目标允许。锁单旧仓继续占用现金与风险预算，不能假设可立即变现。实际无法实现目标时披露偏差，不把不足强配给其他股票。
3. 信号时间后的成交按冻结顺序执行；卖出所得只有确认成交后可用于买入。整手舍入后买入本金加适用费用不得超过可用现金，未成交和剩余现金完整留档。
4. 复用Replay的T+1、资格、方向限幅与参与量约束。费用聚合粒度须显式披露，与券商费用校准分离；不将研究逐fill最低费假设宣称现实已证实。
5. 用原始价格和已核公司行为记账；不得在复权价收益之外再重复加分红。估值价格必须是截止时点可知，缺价则拒绝输出有效净值或使用明确记录时间戳的既知价并标陈旧；不得默认为零。
6. 每日/每月输出现金、数量、可卖库存、费用、外部现金流、持仓估值、未成交理由及权益。权益变动可由成交/公司行为/估值和现金流逐项解释。固定账户净值不可通过重置本金掩盖亏损。
7. 成本/滑点/容量参数来自事前记录；无法验证的参数明确列假设。微账本正确不证明容量真实，正IC不证明扣费组合盈利。

## 最小验收（复用已有测试，只补组合接线）

- 空目标全现金；单股完整往返；大于10股小额分配的最低佣金及剩余现金，独立手算总资产。
- 同次调仓多股票抢现金，卖出受阻时不能用未到账款；同日新买不可卖。
- 跨月锁单、恢复卖出及陈旧价格，整个过程中无隐含补资、无凭空消失/恢复持仓市值。
- 缺价、费用造成现金不足、权重非法、未来信号分别拒绝或产生明确未成交，不输出伪有效收益。
- 原研究proxy入口行为保持；新固定账户入口报告明确区分。先合成验收，再按授权范围做TRAIN抽样对账，不读取留出。

实现前先由执行者确认现有相邻模块是否已实现相同接口，避免重复框架。主审根据实际代码差异、手算与运行工件批准该技术能力；策略推荐规则与真实效益另行验收。
