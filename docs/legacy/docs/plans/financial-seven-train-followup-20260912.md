# 财务7个既有候选：统一TRAIN接续范围

本轮已获主审限定运行批准，总计划§4.64。不是重新发明7个因子；F1/F4/F18/F20/F26/F27/F30来自旧财务粗筛，旧2023参与选择的事实保留，不恢复“全新未见验证”的身份。

## 本批必须回答的问题

1. 修复后的全历史P1/上市退市/历史ST与停牌规则下，各候选35成熟月是否仍有可用数据，缺失来自财报、金融业分类、P1还是收益标签。
2. 原方向的月度IC及三个年度是否一致；完整保留反向、缺失与弱结果，不以数值验收通过冒充策略有效。
3. F30陈旧报表修复在实际P1和金融业排除之后改变多少股票月及成熟收益配对，区别于源层12779个股票月的上界范围。
4. F1/F4的跨表时点和单位、F18/F20周转率、F26现金收入比、F27每股现金流、F30最新可用ROE及历史窗口是否按原式复算。F27不是现金流收益率，不能把每股量直接解释成便宜。

## 固定范围与证据

- TRAIN 2020–2022，36个月末位置、35成熟标签；原方向、无窗口/参数变体、无新p值/bootstrap、无留出。
- 5552证券静态超集，经当前逐日P1及财报金融业排除。原行业快照成员资格不是这些财务公式的输入，本次不再据其限制股票池；明确属于旧粗筛到统一引擎的覆盖口径变化。
- 首披去重、冲突缺失、同报告期配对沿用原函数；F1总市值万元转元，原最多5交易会话回看不扩大。F30修复459日陈旧漏检，保留原8期上限与样本标准差。
- `stock-evidence.jsonl`逐股保存规范化财报、因子/原因、原两端价格、市值；`source_hashes.json`绑定文件，`results.json`列全部7个结果及F30实际影响。新目录`artifacts/financial-seven-train-20260912-1`，只追加，不覆盖旧工件。
- 独立复算程序`experiments/financial_seven_review_20260912.py`不导入生产财务/统计函数，重算报告期可得性、原式、收益、并列秩及所有月度IC。此证据检验计算和接线；共享源数据正确性不能由数值一致自动证明。

## 完成后如何决定

完整工件与有限独立复算通过即结束本批工程验收，不叠加第三层验证。原方向反向或年度不一致的构造保留失败/不足记录，不翻向求PASS；若有可解释的稳定信号，先比较与已有价值、规模、低换手暴露及候选间冗余，再决定极少量固定成本组合诊断。不得仅按最高IC拼多因子组合。

下一轮选择/成本结构须在新数值观察前明确写入预算和规则；R2、确认统计、留出、前向与生产资格仍分别验收。当前7个旧资格不构成任何科学晋级。
