## 1. 假设

- **主假设（待检验）**：对流动性充足的 A 股个股，其相对所属行业指数的对数价格**残差**存在可交易的短期均值回归：残差 z-score 深负后买入、回归后卖出，扣约 17bps 成本后净期望为正。**此为待检验假设：任何机制与盈利结论只能来自阶段 C 及以后，阶段 B 只产生候选。**

与已封存裸价量因子的本质区别（"凭什么强三倍"的事前理由）：
1. **行业中性**：剥离市场/行业系统性下跌，只交易个股相对同行的异常偏离——裸反转会把"行业跌6%它跌5%"误判为便宜，残差不会；
2. **个股资格筛选**：不要求规则对全市场有效，只交易均值回归统计性质（half-life、回归概率、平稳性）本身稳定的股票；
3. **预期毛收益为百分之一量级**（−2σ 偏离回归）——这是**待检验的动机性猜想，不作为成立理由**（外部审核#2：残差回归收益≠持股净收益，通过标准只认可交易股票的实际净收益，见第 5 节）；若毛收益与成本线同数量级，检验重点就从"肉太小"变为"肉是不是真的"。

## 3. 冻结定义、构造与统计口径（全局冻结，禁止逐股调参）

下列定义与口径全文唯一（外部审核#3 钉死），任何改动须另行预登记。

**冻结定义（外部审核#3）**：
- **残差**：对每交易日 t，用窗口 [t−59, t] 共 60 个交易日的 log(前复权收盘) 做 OLS：logP_stock = α + β·logP_industry + ε；取**该窗口自身回归在 t 点的残差** ε_t（即 60 个滚动模型各自产出的末日残差）。窗口内有效观测 <60 则该日跳过。
- **z_t** = (ε_t − mean(ε_{t−59..t})) / std_sample(ε_{t−59..t})；mean/std_sample 取与残差同一构造的 ε 序列 [t−59, t]（端点含 t）的均值与样本标准差。
- **缺失处理**：股票或行业指数当日缺数据则该日跳过；选择窗内有效会话 <200 的股票剔除并计数。
- **half-life**：对**选择窗内 ε 序列**（末日残差逐日序列）做 AR(1)（与 ADF 条同一"选择窗内 ε 序列"口径）：ε_t = c + ρ·ε_{t−1} + u；0<ρ<1 时 hl = −ln2/lnρ；ρ≥1 记 +inf（资格不通过）；ρ≤0 记 0。
- **ADF**：对选择窗内 ε 序列做 Δε_t = c + φ·ε_{t−1} + γ·Δε_{t−1} + u（滞后 1 阶固定），φ 的 t 统计量对照 MacKinnon 近似临界值（1% −3.43 / 5% −2.86 / 10% −2.57）。**明确声明：这只是单位根代理检验，不是协整检验，不得作协整结论。**
- **β 稳定性**：选择窗内全部滚动 60 日 β 的 标准差 / |中位β|。
- **行业映射**：见第 2 节（index_member_all 快照、逐股 l1、in_date 门控、无映射剔除并计数）。

**信号与格子（V1 冻结保留）**：
- 信号：z ≤ 入场阈值（事件/信号日定义见下方统计口径）。**入场 3 格：−1.5 / −2.0 / −2.5**。
- **退出 2 格**：(a) z ≥ 0 次日开盘卖出，或第 5 个交易日收盘强制退出（取先到）；(b) z ≥ +0.5 次日开盘卖出，或第 5 个交易日收盘强制退出（取先到）。
- 格子共 3×2=6；Bonferroni，α=0.05/6，**仅覆盖格子多重性**（范围声明见下）。

**执行与成交（外部审核#5，复用既有 P2 撮合语义并写死）**：
- 主指标口径（**唯一通过标准口径**）：**可交易股票实际净收益**＝信号日收盘后挂单、次一交易日开盘价买入（遇冻结规则 no_trade）→ 按退出规则卖出，逐笔扣费。残差回归量（ε/z）只是信号输入，不是收益本身。
- 信号日收盘后挂单，次一交易日开盘价成交；严格 T+1；跳空按实际开盘价成交；无量不成交如实记 no_trade；ST/停牌掩码阻断。
- **买入可成交性（P2 方向性语义）**：买入执行会话**开盘价=涨停价** → 买入不可成交（no_trade）；**跌停不影响买入可成交性**——按开盘价可正常成交（无量除外，照 P2 无量不成交）。
- **卖出可成交性（P2 方向性语义）**：卖出（含 z 回归退出与第 5 会话强退）执行会话**开盘价=跌停价** → 不可成交，顺延至次一交易日重试；顺延期间持仓与浮亏照常计入。**第 5 会话强制退出为收盘价成交：若该日收盘价=跌停价 → 同样不可成交并顺延**（判定用收盘价，与收盘执行同时点，无前视）。
- 持有会话以入场日=1 计数（退出规则中"第 5 个交易日"即第 5 个持有会话，取先到）。
- 涨跌停受阻判定**统一仅以执行时点价格与涨停/跌停价的关系为准**（外部复审#1）：开盘成交的买卖用开盘价（买入 no_trade 判据＝开盘价=涨停价；卖出受阻判据＝开盘价=跌停价），第 5 会话收盘强制退出用收盘价（收盘价=跌停价→顺延）。**不使用当日最高/最低价**；开盘=最高=最低的"一字"情形是开盘价判据的自然特例（开盘价等于涨停/跌停价即已涵盖），无需另行判定。判定所用价格为集合竞价/收盘结果，与执行同时点、执行前可得，**无前视**。披露：该判定口径的偏差方向为保守——只会把本可成交/本可卖出的情形判为 no_trade 或顺延（低估成交与样本量），不会虚增成交（第 6 节）。开盘即跌停的主动不入场属避雷过滤器（见第 4 节），不是成交受阻。
- 未了结持仓处理（外部复审#3）：持仓退出越过阶段右端边界时（阶段B 右端=2023-12-31、阶段C 右端=2026-08-28），一律按该阶段右端最后可得收盘价 MTM 计价并计入结果（阶段B＝2023-12-29 收盘、阶段C＝2026-08-28 收盘），**不删除、不读取越界日期（2024 年起 / 2026-08-28 之后）的退出价格**；顺延持仓与浮亏照常计入（第 4 节成熟边界 B 类）。

**统计口径（外部审核#1，冻结）**：
- 事件定义与去重：同一股票 z **自上向下首次穿越阈值才记事件**（穿越＝z 由高于阈值降至 ≤阈值，穿越当日为事件日/信号日）；持仓期间不重复计。
- 显著性协议（**唯一**，外部复审#2 冻结；阶段 B 探索筛选与阶段 C 门禁均用且仅用此协议）：统计量＝**逐笔净期望**＝总净收益÷总事件数。推断＝以事件日为块单位的 **block bootstrap（块长 20 交易日）**：每次抽样**携带被抽中日期的全部事件**，按 总净收益÷总事件数 重算逐笔均值；**无事件日不进入重采样池**（estimand 为事件条件下的逐笔期望）；重采样次数 B=10,000、固定种子 20260909；**置信区间按门禁级别区分（外部复审终审点）**：阶段 B 六格筛选用 **99.1667% CI（0.4167% / 99.5833% 分位，双侧对应 Bonferroni α=0.05/6）**，其下界>0 方为探索筛选通过；阶段 C 唯一候选用 **95% CI（2.5% / 97.5% 分位）**。除分位点外协议参数完全一致，全文只存在此一套显著性口径。**禁止逐笔独立 t 检验**；V2 的"逐日期等权均值 t 检验"独立表述已删除。
- 多重性范围声明：Bonferroni α=0.05/6 **仅覆盖格子多重性，不覆盖筛选偏差**（阶段 A 资格筛选与阶段 B 同窗评估叠加引入的偏差）；筛选偏差由阶段 C（历史留出）处理。本版将格子多重性落实到 B 门禁分位点（99.1667% CI，见上条显著性协议）。

## 4. 三阶段设计

- **阶段A 资格筛选（只用 2020-01-01—2023-12-31）**：按第 3 节冻结定义逐股计算 half-life、ADF t 统计量、z≤−2.0 事件次数（按冻结事件去重口径）、**事件后 10 日回归概率**（冻结定义：**回归＝事件日后 10 个市场会话内 z 首次达到 ≥0**，与退出格(a) 对齐；该 10 会话结局越出 2023-12-31 边界的事件记 A 类"未成熟"：回归概率分子分母均不计、仅计数，见下条）、残差波动率、β 稳定性；有效会话 <200 的股票剔除并计数。冻结阈值（事前）：事件数≥8、half-life 2—15 交易日、10 日回归概率≥55%（同上冻结回归口径）、ADF 低于 10% 临界（t<−2.57）。**阈值不调优**，输出冻结候选名单并披露数量。
- **事件结局成熟边界（外部审核#4 引入；外部复审#3 拆互斥两类）**：
  - **A 类（标签未成熟，仅阶段A 资格事件）**：z≤−2 事件后 10 个市场会话的回归结局越出 2023-12-31 → 记**"未成熟"**：分子分母均不计，仅计数；
  - **B 类（阶段B 已入场交易）**：卖出退出受阻（开盘价=跌停价顺延）或第 5 会话强退日越出 2023-12-31 → 一律按选择窗最后一个交易日（2023-12-29）收盘价 MTM 计入该格结果——**不删除、不读取 2024 年的退出价格**。阶段 C 同理按其数据右端（2026-08-28）MTM（第 3 节未了结持仓处理）。
- **阶段B 探索性候选筛选（选择窗 2020—2023，同窗；外部审核#1 降级）**：在冻结 6 格上做探索性交易统计：逐笔净收益、胜率、分年、no_trade 与排除计数；事件研究表每格须含：样本数、回归概率、均值与中位收益、**MAE/MFE**（最大不利/有利偏移，量化接飞刀风险与退出档合理性）、平均持有期。**B 只产生候选；任何机制与盈利结论只能来自阶段 C 及以后。** 阶段 B 为同窗（筛选与评估同窗）评估，显著性格子只是候选证据，**不得表述为"机制存在/机制存活"**；显著性按第 3 节**唯一显著性协议**（事件日块 block bootstrap：块长 20、B=10,000、固定种子 20260909），**B 六格门禁用 99.1667% CI（0.4167% / 99.5833% 分位，Bonferroni α=0.05/6 落实到分位点），逐笔净期望 CI 下界>0 方为探索筛选通过**；Bonferroni 0.05/6 仅覆盖格子多重性、不覆盖筛选偏差（筛选偏差由阶段 C 处理，见第 3 节）。
- **衰减曲线（纯描述性补充，总计划两阶段测试法例外）**：对冻结事件给出 T+1/2/3/5/10/20 日前向收益；**无退出规则、仅描述、不得用于事后修改本轮持有期**（本轮持有期已固定 ≤5 会话强退）。
- **附加分解报告（描述性，外部审核#2）**：对被评估格子补报：持仓期行业指数收益、持仓期残差变化额、"滚动模型更新导致的 z 变化"占比——仅描述性归因，不构成通过标准。
- **成本压力测试（吸收外部报告）**：17bps 基准之外，同格复算 **27/37bps** 两档；27bps 档兼作阶段 B→C 唯一选优口径（见下），37bps 档为稳健性展示。仅在 17bps 下为正的格子标注"依赖乐观成交假设"。
- **集中度与失败归因（吸收外部报告；贡献度公式外部复审#4 冻结）**：**贡献度冻结公式**——contrib_i＝该格内股票 i 的 17bps 净盈亏合计（可正可负）；Top5 占比＝ Σ_top5 |contrib_i| / Σ_all |contrib_i|；若 Σ_all |contrib_i|＝0 → 该格直接 FAIL（零盈亏总量无法评估）。报告 **Top 标的贡献度**（收益是否被少数股票垄断，Top5 占比 >50% 则不满足阶段 C 的 PASS 集中度条件）；**失败案例清单**（偏离后未回归事件逐类归因：公告利空/行业崩溃/关系断裂/流动性）。
- **阶段B→C 唯一选优规则（外部审核#6 + 外部复审#4 追加，事前冻结）**：阶段 B 若多格通过探索筛选（按第 3 节唯一显著性协议，17bps 逐笔净期望 bootstrap **99.1667% CI（0.4167% / 99.5833% 分位）下界>0**），**唯一选优规则＝取 27bps 压力档净期望最高者；并列取样本数大者；再并列取阈值绝对值小者；再并列（最终裁决）按固定格子顺序靠前优先：（−1.5, z≥0）→（−1.5, z≥+0.5）→（−2.0, z≥0）→（−2.0, z≥+0.5）→（−2.5, z≥0）→（−2.5, z≥+0.5）**；阶段 C 只检验这 1 格。无格子通过探索筛选（含全负）→ 无候选，FAIL 封存。
- **阶段C 冻结后历史留出验证（只读 2024-01-01 起至数据右端 2026-08-28（指数数据末端，见第 2 节）；外部审核#4/#6 更名）**：名单与参数全冻结，只允许检验选出的 1 格一次；任何"再调一次"禁止；FAIL 如实封存。主指标：**17bps 逐笔净期望及 95% 置信区间**（第 3 节唯一显著性协议：事件日块 block bootstrap，块长 20 交易日，B=10,000，固定种子 20260909，CI 取 2.5/97.5 分位）。通过判定（事前冻结）：

  - 有效事件数 <30 → **INSUFFICIENT_EVIDENCE**；
  - 其余（含 Σ_all|contrib_i|=0，零盈亏总量无法评估）→ FAIL。
