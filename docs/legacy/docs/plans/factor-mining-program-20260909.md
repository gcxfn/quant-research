## 1. 方法论三条新规（外部批评裁决后写入）

1. **家族分层判定**：禁止"单因子判死整个家族"。判定表述只能是"某家族的代表构造在本成本/频率/执行口径下未通过"。因子按六维对象对待：家族×构造×池子×条件×期限×执行。
2. **两阶段测试法**：第一阶段只测毛 IC/RankIC + **衰减曲线**（T+1/3/5/10/20 日前向收益），不配置任何止盈止损；只有衰减曲线显示某期限毛收益能覆盖成本线的构造，才进第二阶段配交易结构算净收益。禁止再用"先定死障碍规则再测因子"的反向顺序。例外记录：主线 MR 轮固定 5 日强退，衰减曲线以**纯描述性补充**形式给出（冻结事件的 T+1/2/3/5/10/20 日前向收益，无退出规则、仅描述、不得用于事后修改本轮持有期）。
3. **家族代表制**：每家族预登记 5—10 个经济含义不同的代表构造（如不同期限/残差化/条件化），禁止参数微调凑格子；格子数事前冻结并做多重检验校正。
