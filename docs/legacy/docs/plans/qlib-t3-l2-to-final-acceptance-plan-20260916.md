## 3. 各阶段细则

### S0 L1 独立复核

- 输入：门槛包 `-1`、结果批 `-1`、L1 批 `-2` 完整工件。
- 动作：独立复算 116/26 集合与逐项拒绝原因；裁定“接受探索性披露”或“另登记新门槛重评”。
- 验收：集合复算零差异；若重评，新门槛登记先于重评执行。
- 失败处置：门槛缺陷只影响 L1 结论，不推翻 L0；重评用新门槛包，不覆盖旧批。

### S1 L2 订单路径提取

- 动作：在 L1 批 `-2` 的分数缓存与策略配置上重放 `OpeningCashTopkDropoutStrategy` 决策，
  逐候选落档每个调仓日的买卖股票与执行日；不重新求表达式。
- 产出：订单路径清单（候选×执行日×股票×方向）、去重后的（股票，执行日）需求集、
  逐股票日分钟需求计数。
- 验收：重放持仓序列与 L1 批 `-2` 日账户的成交日/市值一致（允许浮点容差）；
  需求集可机械复算。
- 边界：此清单是数据需求上界快照；分钟回测中限价/参与率导致的顺延会新增证券日，
  新增部分按 S8 同样触发补数，不回填本清单。

### S2 训练窗分钟接入

- 数据源优先级：本地用户 1 分钟 ZIP（2015–2024 已在 `data/raw/user_minute_1m/`，闲鱼来源、
  原商未知）→ 缺口按 T1 既有渠道补（baostock 5 分钟仅 2020 起；xiaodefa `stk_mins` 1 次/小时
  且与闲鱼同源，只作补缺不作独立验证）。
- 动作：按 S1 需求集把 1 分钟聚合为 5 分钟（沿用 T2 冻结口径：241 根→48 根，09:30 只入首根），
  写入 Qlib provider 的 minute 频率目录；逐文件记录来源、SHA、聚合参数。
- 验收：抽样对账聚合前后 OHLC/量守恒；时间网格负例（缺根、重复、错时间）fail-closed；
  与日线开收/日量差异按 `research_disclose` 登记披露，不静默放行。

### S3 Qlib 分钟回测接线

- 动作：用 Qlib 嵌套执行器（日级策略 + 分钟级 SimulatorExecutor）实现 T2 冻结执行语义：
  原限价单及有效期、逐 bar 参与率（主 0.005/压力 0.0025）、方向涨跌停、T+1、整手、
  opening_cash_only、按日历史费率。
- 冒烟：选 1–2 个已被 L1 淘汰的候选做接线验证（结果已无关晋级），对比日线 L1 与分钟 L2 的
  持仓/成交差异并归因；另做合成负例（涨跌停不可成交、参与率截断、缺 bar 顺延）。
- 验收：账本守恒（现金+持仓=净值）逐路径成立；费用独立重算一致；缺分钟 fail-closed 不补日线。

### S4 L2 门槛事前登记

- 在 S5 全量结果产生之前冻结；建议结构（数值以届时登记为准）：训练窗主净收益>0、
  压力净收益>0、主最大回撤界、分钟相对日线的执行劣化上界、无 TopK/比例/分位数。
- S3 冒烟若使用已淘汰候选，须在门槛包中披露，不构成对 S5 结果的预览。

### S10 统计披露

- 全部分母 2000（含 105 阻断与 26 L1 拒绝）如实披露；家族/模板结构、两轮事后门槛登记
  （L1 探索门槛、S4 若受描述影响）全部列入多重检验披露；不恢复 V5，不按存活数缩分母；
  结论保持探索级，统计有效性逐项给出 UNKNOWN/限定表述。

### S11 组合研究

- 时机：漏斗收口后进行——L2 分钟验证且十年主/压力路径均通过的幸存小集合（预期几个到
  几十个），不在 L1 的 116 个候选上提前组合；同模板窗口变体冗余先披露。
- 主线：等权（家族内→家族间或直接等权，按幸存者家族分布在运行前登记）；无可调参数。
- 对照：滚动自适应权重（训练期 IC 加权或岭/Lasso 强正则线性回归，逐月只用 t−1 前数据
  估权重）作为预登记对照；深度学习/树模型在本样本量不采用。
- 采纳规则事前冻结：自适应组只在预登记比较中胜过等权基准方可替换主线，且结论仍为
  探索级。
- 数据边界：自适应权重依赖 S7 十年日线扩展后重算的十年因子分数缓存；2020–2022 与
  因子筛选窗重叠，组合回测报告必须披露该重叠除外时段；2025+ 前向验证保持冻结，
  开放须另立决策。
- 验证：组合信号按 T2 执行口径跑十年分钟主/压力（复用 S8/S9 能力），不因“组合分散”免检。

## 4. 横切纪律

- 身份：每阶段新批次目录，绑定代码快照、provider/缓存摘要、候选集合摘要、门槛包 SHA；
  恢复时身份不符即拒。
- 数据：分钟只按实际订单依赖获取；缺分钟 fail-closed；不同源分钟不互为独立验证；
  日线差异披露不等于放行。
- 引擎：`qlib_research` 不导入 `quant`/`experiments`/VectorBT；自有代码仅数据接入、配置、导出。
- 资源：长跑必须检查点+心跳+续跑；内存门禁沿用 L0 经验（顺序恢复优先于加并发）。

## 5. 停止规则

- 任一阶段通过者为 0：交付该阶段全批结论并停止后续依赖阶段，不为找赢家扩预算。
- 数据缺口无法补齐：登记 BLOCKED 清单，独立候选继续，受阻路径不虚构结果。
- 任何公共算子/数据缺陷：冻结全部受影响候选，核影响范围后新身份重跑受影响部分。
