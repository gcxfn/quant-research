## 2. 冻结的变更定义（唯一变更）

- 每个交易日收盘后，对当前持仓逐只检查：**close ≤ SMA120 或 R60 ≤ 0**。有完整当日数据时等价于 `not quant.factors.trend_ok(closes, index, 120)`；等于均线必须触发。使用当日及以前数据，不把未来价格或无当日bar的旧观测当作当天信号。
- 触发→**次交易日开盘**卖出该标的全部持仓（与现有 next-open 执行口径一致），费用照旧（ETF万1无最低免印花+滑点万5）。
- 卖出所得现金不在月中买入，可用于**退出后最近一次月末信号对应的次交易日开盘调仓**，不额外空等一个月。若月末开盘退出，则当日收盘仍可按原规则形成月末目标；次日开盘按目标执行。
- 同一开盘先执行已排队每日退出，再执行前一月末目标的调仓卖出和买入；同标的退出只卖一次。排队退出标的不得在同一开盘重新买回，未完成退出保持队列，趋势暂时修复不撤销。新的月末信号可在退出后决定以后是否再次买入。月末现金预算仍复用已修复V3的开盘已知估值、不对仍入选的存量仓位精确再平衡。
- 缺bar、无有效开盘/成交量或有明确不可卖证据时不得虚构退出：记失败原因，保留原触发日，每个后续交易日开盘重试至可成交；期末未退列为未完成，不丢弃。只核验这类真实执行障碍，不引入额外择时门禁；R3基线仍须复现，若共享执行修正使基线变动须停止收益比较并交主对话审核，不能悄悄改变对照。
- “买入侧不变”指买入信号日期、排名、资格与预算规则不变；每日退出会改变实际持仓、可用现金、月末再次买入与份额，允许这些内生变化并披露，不强制复制基线订单或固定基线买入量。
- 其余全部冻结：月末信号日、R20/R60/R120等权排名、Top3、买入门禁（仍只在月末信号日评估）、上市满252日、流动性门槛、池（含D-2026-09-09-04排除规则）、费用、初始10万。不做任何参数搜索。
