## 1. 决策与目标

建议重建历史数据、短线成交回放和策略研究组织方式，保留已可复用的费用、账户、数量约束和人工操作能力。旧代码与历史实验保留为对照；不以删除重写的规模衡量进展。

产品主线为程序筛选A股股票/ETF的1—5交易日机会，排除ST/*ST，给出资金和底仓约束下的价格、数量、止损和退出条件，由人操作。做T仍由人指定标的，允许未完成差额隔夜。周内短线默认在第5交易日退出；此前用户允许的条件续持作为单独策略契约评估，必须披露超过5日的比例，不混入严格周内成绩。

盈利目标为10万元账户扣费后年化不低于10%、夏普不低于1.5，回撤研究约束约20%。这是一项待验证目标，不是重构验收时必须凑出的数字。“不考虑成本”按研发投入不设预定上限理解；真实佣金、税费和滑点继续计入，付费数据采购不由本计划自动授权。

工程完成、历史研究合格、未来验证合格分开验收。工程可以成功而策略仍无盈利优势。

## 3. 目标结构与数据契约

数据流：历史时点数据 → 当日可选池 → 信号 → 入场计划 → 资金分配 → 按时间撮合 → 账户账本 → 退出复评 → 指标与事前记录。

### 历史时点数据

- 证券信息：稳定证券标识、交易所、品种、上市/退市日；ETF类型由证券资料确定，不能仅凭代码前缀认定为符合A股范围的ETF。
- 状态事件：ST、停复牌、板块/交易制度，包含生效区间与可获知时间。未知状态单独标明，不默认正常。
- 价格：实际未复权日线/分钟线、成交量与金额单位、交易时段和数据源；复权因子与公司行为单独保存。
- 公司行为：生效日、分红、送转/拆并等对现金和股数的影响。信号可用在当时构建的连续价格序列，成交和手数必须用实际交易价格，账户记录真实公司行为，避免重复计入分红收益。
- 时点字段：市场事件发生/生效时间、公告或首次可用时间、抓取时间分别保存。现在补取的历史数据不得伪称当时已留档；缺少历史版本的字段披露限制。
- 交易规则：按证券与生效日期取得涨跌停、最小价位、申报数量、可卖约束、费用。具体历史制度由官方来源核实后录入，未知项限制相关研究，不套用今天规则回算全部历史。

原始数据保持原样；新增规范数据按运行批次保存，旧派生CSV不覆盖成为新实验输入。无需新增哈希体系；以明确文件路径、来源、截止时点和参数快照复现。

### 策略与账户契约

信号函数只接收当时可用的数据，返回候选及理由，不读取未来行情。入场计划声明生成时刻、最早可交易时刻、有效期、限价/触发方式和取消条件。退出计划声明止损、止盈、时间退出和是否允许延期。配置只引用具体已实现规则，不建设通用插件或兼容框架。

组合账本逐时处理现金、持股、可卖股数、费用、公司行为、订单余量和成交。资金不足不假造成交，不使用尚未发生的卖出释放资金。股票/ETF比较先分别用同规模账户，最后必须用一个共享10万元账户检验最终方案。

## 4. 分阶段实施

### P0：保存参照并核实数据可得性

先读当前工作树和账户路径，保留未提交工作；将本轮参照配置、行情路径、既有指标和限制写入交接记录。不重跑所有旧实验，不清理旧结果。

按覆盖需求探查现有公开/授权数据源：全历史证券名单、历史ST/停牌、公司行为、未复权日线、分钟线。探查样本须覆盖ETF、不同股票板块、退市或历史ST、停复牌和除权案例，按事件选择，不能按后来的收益选择。请求串行、带节律和断点续抓，不全市场并发抓取。

交付：`D:/AI/workspace/个人量化/docs/experiments/short-data-coverage.md`，列每类字段的来源、实际样本、日期覆盖、授权条件、缺口和可行研究范围。

通过条件：用真实样本证实可读到必要字段及其单位/时间含义。若仅有近期分钟数据，就做限定日期的执行验证；若拿不到历史退市/ST，就不得宣称全市场无幸存者偏差。采购必要时先提出具体数据产品、覆盖证据和费用，再由用户决定；不先买服务。

### P1：历史时点数据与可选池

复用取数与原始存储，增加证券历史状态和实际价格读取。按交易日构建可选池，明确证券是否上市、是否ST、是否停牌、是否满足账户板块权限与流动性条件。研究范围由已确认覆盖决定，ETF优先或股票子集只能按数据覆盖选择，不能按历史收益挑池。

交付：规范数据样本、按日可选池及排除原因；覆盖报告更新真实范围。

验收针对实际失败模式：新增未来状态不得改变过去可选池；除权前后权益可对账；原始价格与信号序列不混用于手数/费用；历史资料缺失不被当作正常状态；证券退市后不被继续推荐。缺口会改变研究范围或阻止给出推荐资格，而不是用更多异常框架掩盖。

### P2：分钟撮合与账户账本

在现有日线粗筛旁实现短线分钟回放。日线信号必须等该日结束后才可见；分钟收盘生成的信号不能在同一分钟低价成交。分钟内部仍不知道完整路径，遇到止盈止损同时触达，给出保守主结果和可识别的路径区间，不把分钟线当逐笔盘口。

显式处理订单生效/失效、部分成交、数量限制、参与成交量上限、涨跌停方向、停牌、T+1、现金与可卖股数、费用、公司行为。延迟和参与率参数在真实分钟样本检查后、收益实验前冻结，不能为提高收益倒调。只验证日线已触发的策略也需披露筛选条件，不能把这种样本当全市场分钟策略证据。

交付：分钟成交账本与日线对照回放；首批选择有明确真实行情事件的案例，而非盈利最高案例。

通过条件：用独立手算预期验证T+1、最低佣金分段、部分成交费用口径、涨跌停不可成交、跳空、触价歧义、先后现金可用性与公司行为。任何解释不清的账户权益差额先修复，不能进入盈利筛选。日线与分钟结果不同须能归因到具体成交，不要求二者收益相同。

### P3：拆开公共门槛并做机制归因

将信号、宽基门槛、排名、入场、退出和资金分配拆为具体函数及配置，保留现有候选复现入口，不自动改变默认short。先用相同数据和日线撮合复现旧规则，以区分代码移动、数据变化和撮合变化的影响。

逐层记录：可选池数量 → 信号数量 → 市场门槛拒绝 → 排名落选 → 费用/资金拒绝 → 下单 → 成交 → 退出。现金按日期纳入净值，统计资金闲置原因，禁止只对持仓日计算夏普。

第一轮归因只做单因素对照，不跑所有条件的笛卡尔积：原规则参照；去掉宽基门槛；固定信号下改变入场时机；固定入场下改变退出。具体参数和不超过8组的登记表在P1/P2覆盖确定后写死，再运行。结果为负也完整保留；这8组是试验范围限制，不是统计显著性保证。

通过条件：相同输入与旧规则能解释复现；每一组只有登记的差异；每笔计划与成交能追溯。交付拒绝原因、单笔净优势、成交率、资金占用和费用侵蚀归因，不要求此阶段达成盈利目标。

### P4：按交易逻辑重建周内候选

在P3归因后，选择有证据支持继续研究的逻辑，不预先指定哪类必赢。每类明确机会来源、入场触发、取消条件、持有期限、失效环境以及为什么预期收益能覆盖成本。

候选方向仍可包括强势股回撤企稳、突破回踩和ETF修复，但不强迫它们共用同一排名/买入/市场过滤。每种逻辑最多先登记一个完整规则及一个简单参照，先检验交易收益，再决定是否需要机器学习。

若研究模型：先与简单规则及历史频率基线比较；股票/ETF标签分开，明确成交概率与成交后净盈亏，采用训练期拟合和标签成熟隔离。新增财务、公告、行业或其他信息前，须先具备历史可用时间；不得拿今天的基本面填回过去。更复杂模型只有在增量证据充分时才进入候选。

验证按时间前推，训练和验证边界清除跨界标签，间隔按最大实际标签观察期限设定；未完成交易不编造盈亏。记录全部尝试与失败，按日期块分析不确定性，不把重叠个股样本当独立观测。已看过的历史用于探索和稳健性分析，不能重新封为未知测试集；若确有未使用的独立数据，先登记封存再选择模型。

交付：每类完整策略说明、冻结配置、全部实验记录、逐年/分环境结果、参数邻域稳定性、费用压力、集中度与样本不足说明。参数邻域只诊断，不能看确认段后挑出新的最优点。

### P5：统一资金组合与人工前向跟踪

只有候选自身有扣费后正优势且验证未明显失效，才研究共享10万元账户的组合和风险分配。按股票/ETF与同主题相关性限制集中度，先固定简单分配，不用杠杆或不断放大单笔风险凑目标。

新增短线事前记录：在计划可交易前冻结信号、数据截止、策略版本、账户假设、价格/数量、退出及延期条件。人工实际成交另行追加，未成交、取消、延迟、漏操作分别记录，不改写原计划；模拟成交和人工成交分开评价。可复用概率留档的拒绝迟到报告逻辑，不直接复用V3的20日收益结算。

首轮未来观察建议至少连续60个交易日且100笔成熟交易；任一不足继续积累，不催生交易凑数量。这只是观察覆盖门槛，不能据此证明年化10%或夏普1.5。后续观察长度由收益波动、日期相关性和区间估计决定；亏损或执行偏差扩大时可提前停止该候选。

交付：原始计划、模拟/人工成交、差异归因、完整含现金日净值。失败候选回研究，旧模型及策略不自动替换生产入口。

## 5. 验收口径与停止条件

工程验收：相关标准库单元测试、`python -X utf8 -m unittest discover -s tests`、一个旧月频端到端smoke和一个新短线撮合端到端案例。每个测试须对应具体错误及失败后的处理；文档-only变更不为凑流程运行回测。

研究目标：最终共享账户以252日、包含现金日的净值计算几何年化和夏普，主夏普rf=0并披露rf=1%敏感性；报告最大回撤、年度结果、成交数量、持仓延期、资金使用率、费用压力、标的集中度和不确定性。历史年化≥10%、夏普≥1.5、回撤≤20%仅是数值目标通过；没有独立数据/未来验证仍不可标为可执行。

独立审查在P2账本和P4/P5策略升级前分别进行，记录于`D:/AI/workspace/个人量化/docs/decisions.md`。审查者需独立读取实现和证据，不能把实现者的测试输出当独立PASS。本计划不创建审查任务或子代理；安排独立审查属于实施阶段工作，未完成时维持研究状态。

以下情况改变下一步：必要历史字段不可得则缩小范围；账本无法对账则暂停盈利研究；策略无净优势则淘汰，保留可用数据/代码；确认段失败则不事后换冠军；未来执行偏差过大则回到成交假设。任何情况都不通过删除失败证据、改变统计起点或隐藏费用来达到目标。
