先做一次固定的**共同样本内暴露调整描述**，无新回测策略：

- 只用TRAIN的35个成熟月末，复用原P1资格、原始因子方向与下一月复权收益标签定义。标签须与既有R0月度IC在相同样本上对齐；不能用裸价无公司行为的收益替代。
- 暴露固定为信号当日流通市值、20日历史波动率、换手率。后两项直接使用既有对照导出的同日分数还原；市值来自同日daily_basic。缺值用共同样本，不填零；同时列原全样本、共同样本和覆盖损失，避免把换样本误认为中性化收益。
- 每个月先将因子、未来收益、三项暴露分别做截面平均并列排名，再用同一个含截距的暴露矩阵分别拟合因子排名与收益排名，报告两者残差的相关。并列处理沿已核规则；若设计矩阵秩不足或有效样本不足，记录不可估，不修改暴露集合凑结果。
- 报告全部月、三个年度和残差相关的描述均值，同时保留未经调整的共同样本RankIC。不报p值、显著性、置信区间或“行业中性Alpha”，不在不同暴露/分桶方案间选优。历史行业归属仍缺，不引入今天行业快照。

该描述用于判断下一项研究最该查什么，不能因残差相关为正自动扩大R2。已观察训练期、预先挑代表及大量历史搜索的限制不因残差化消失。代码只处理导出的分数/同定义标签，不重写引擎求值核心。

## 判断、停止及后面的系统工作

- 若暴露调整后证据弱或高度不稳定，优先记“现有证据不足/可能共同暴露”，不为追求正结果继续加中性化层或改方向。若发现具体数据/实现错误，限定修复相关路径并留新批次，不把错误归因于因子无效。
- 三候选若进入小批，所有结果、缺值与原方向都登记；不得只存赢家或把三个机制当三张独立支持票。只有多构造有可解释的一致行为，才准备有明确上限与停止条件的R2方案；不自动2–3倍扩预算。
- 已完成小试中META_combo_02/10bps的sh.603879除权差异作为该路径DATA待办；其他结果不依赖时不横向阻断。MT276、一般进程加固、灾备不作为这里新增前置条件。
- 对拟确认的少量策略，下一阶段再冻结真实执行/容量、个人红利税、成本、持仓和资金时序，与成熟引擎或独立账本按同一订单逐笔比对。Qlib等是否适合需按实际版本/规则核查，不能仅因名称成熟就认定正确。
- 科学确认必须另行冻结经济效应、主端点、选择历史/总搜索分母、有效统计方法和真正未观察数据。旧V5仍否决，不反复校准求PASS；2023财务旧工件和已看过验证数据的污染披露保留。LOCKBOX/前向证据与生产可执行资格分别验收。

本方案没有要求所有工程待办完成后才允许研究。系统可靠性通过当前真实路径的纠错、可复算结果和诚实分类推进；允许研究失败，不为系统验收制造赚钱策略。
