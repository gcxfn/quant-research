## 冻结比较总体

1. 各自全可成熟样本：每个期限单独筛选win/loss/timeout有效标签，再按证券、entry_date顺序，以完整市场日历隔开对应5/10会话。no_trade/None不计亏损，不占有效轮次。分别报告目标记录、无标签、no_trade、无结局、有效记录和非重叠轮次数。用于回答10日总体净均值是否为正。
2. 共同可成熟日期诊断：按市场完整日历，信号日后第10会话不晚于选择截止的日期，分别列5/10有效与缺失计数。证券自身标签仍遵循原标签生成器，股票缺行不以市场日历伪造价格。不得把“共同日期”误称每只证券均有可成交结局。
3. 配对主比较：同一(date,symbol)在两个期限均有win/loss/timeout及有限入场/退出价/净额，entry_date相同。只在共同可成熟日期内取交集，然后按证券、entry_date升序，以市场日历固定10会话去重；两个期限严格用同一批轮次。差值为每对net10−net5，其总体均值是配对改善值。共同有效筛选可能受退出可得性影响，必须同时披露交集外5-only/10-only/both-invalid计数，不能将该诊断称作真实投资组合收益。
4. 全期与2020/2021/2022/2023按信号年拆分报告同一统计；先全期去重再拆年，不在年界重新启动去重。不得用某一年转正替代全期结论。
