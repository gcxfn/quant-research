## 3. 指标与比较规则（事前冻结）

指标：年化、年化波动、夏普、Calmar、最大回撤、水下总数，**加水下深度族**：最长连续水下日数（收盘净值严格低于历史收盘峰值）、平均回撤深度（水下日的平均距峰值幅度）、深度回撤持续区间（回撤 ≥20% 的起止与持续天数，逐段列出）。

主比较 = M3 vs M1（动态 vs 固定），在（最大回撤、夏普）两指标上：
- **动态无增量**：M3 两指标的相对改善幅度均 <10%（|M3−M1|/|M1|）；
- **动态有增量**：M3 至少一项相对改善 >20% 且另一项不劣于 M1（回撤更低/夏普更高）；
- 其余为**不确定**，如实报告，不追加参数搜索。

辅助披露：M3 各月 w 分布与触底月数（上轮 36/78 个月触及 0.5 下限——总仓位约束为独立后续假设入口，本轮不动下限/目标/频率）；三形态费用拆分（佣金/滑点）。
