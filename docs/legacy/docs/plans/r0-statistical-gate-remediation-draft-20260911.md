### B.0.1 已核源码事实（248 构成与首末月；冻结案直接引用本节）

1. **N=248 构成（离线复算，非猜测）**：对冻结清单 `artifacts/factor-miner/r0-20260910/hypotheses/_all_raw.jsonl`（250 行）跑 `validator.merge_duplicates` → **246 结构（拒 3）**；`director.evaluation_units` → **248 评估单元**：244 结构 1 单元 + **2 结构各 2 窗口变体**；单元方向 positive 189 / negative 59。**单元键="%s|w:%s"（结构 id × 窗口），direction 为 hypothesis 属性、不在单元键内**——每单元单方向单次检验，**不存在方向拆分重复计罚**。
2. **首末月（标签成熟语义）**：`partition.py` `TRAIN = ("2020-01-01","2022-12-31")`；`stats.forward_returns` 循环 `for k in range(len(month_ends) - 1)`、docstring"末端月无下月 → 不产出"——36 个日历月末位中**末位（2022-12）结构性无标签**；**首位 2020-01 标签成熟**（前向月 2020-02 在窗内）；标签成熟位=**35（2020-01..2022-11）**。窗前数据仅可经 `warmup_read` 且 `ensure_not_warmup` 守卫"不得用于任何统计/标签"——不引入额外成熟位。

### B.1 自然月轴与缺失政策（冻结建议）

1. **轴=自然月**：36 日历位、None 占位不压缩重编号（F-1 闭合）；"35"按 B.0.1.2 的标签成熟语义导出，非观察长度定义。
2. **缺失分型披露**：截面退化（ic=None）计该位缺失；披露位数与模式（孤立/连续/尾部聚集）；退市/停牌结构性缺失单独标注。
3. **缺失上限**：缺失 > 7/35 的单元判**证据不足**（不判过不判败、单列）；7/35 为建议值。

### B.2 短样本、依赖假设与"证据不足"出口

1. 每一候选方法附显式假设边界；假设不被满足时实际水平可能超名义，只能由 B.5 网格事前测量。
2. 适用场景"超标"或"**不分辨**"（不分辨≠受控，不得因未拒绝超标就放行）→ 方法未证实，其下全部单元只能输出证据不足；非适用场景超标仅披露。
3. 真实 TRAIN 事后诊断只披露不反馈；禁止用真实结果选方法/调参数/切换方法。

### B.3 多重检验预算：两层账与方向记账

1. **两层账**：(i) **批次错误控制**——本批门禁限定声称控制**本批**方向性 FWER；**已有多轮真实探索（财务两批、PV1、事件/MR 轮等）作为 S4 尝试账如实披露**；本草案**不宣称研究计划整体 FWER**；跨批联合错误控制若需设计属未来另行预登记事项，本草案不断言其不可能、也不在本轮设计。(ii) **结构层披露**——去重结构数与方向拆分计数（189/59）作家族披露与未来家族层预算输入，不作本轮 α 分母。
2. **方向记账（维持原公式，如实标注）**：tail=α_total/(2N) 不变；方向单元名义率=α/(2N)=2.0161×10⁻⁴；全批方向性 FWER 的 Bonferroni 界 = N×α/(2N) = α_total/2 = **0.05**（不依赖独立性）。按 B.0.1.1 已核：248 单元无方向拆分重复计罚，此界即真实记账。
3. 批内 α 分母 N=评估单元数（=248，运行时从 units 派生、禁止手填）。

### B.4 候选方法（主门禁候选仅一个；符号检验为诊断）

**主门禁候选（唯一）：t 型区间（HAC 标准误）——候选近似法**。t=mean/SE_NW；Newey–West HAC，L=⌊4(m/100)^(2/9)⌋（m=35→L=3，规则出处 NW 1994 **已核实**）；判过（正方向）：mean−t_{df,1−α_total/(2N)}·SE_NW>0 ∧ mean≥0.02；df=m−1=34 作锚。**明确声明：35 点下 t(df34) 极端尾部（~2×10⁻⁴ 分位）无可靠小样本保证、HAC SE 为渐近量——仅为候选近似法；其性质只在 B.5 生成模型场景内受测，真实适用性 UNKNOWN；任一适用场景超标或不分辨即出局，出局则路径 B 当前无可用方法，回落路径 A。**

**诊断（不入主门禁）：月度符号检验**。estimand=中位数/正号概率≠均值 IC；相依/缺失下 iid 二项对"均值 IC>0"不构成有效检验——仅作一致性诊断，不产生科学 PASS、不计门禁预算。

**共同约束**：不以加大 B 修复任何性质；旧块 bootstrap 若保留仅作描述性稳健图；方法指定先于校准运行与任何真实 TRAIN 门禁结果。

### B.5 事前固定种子有界合成校准（本轮不执行，仅设计）

1. **场景网格**：月数 35；月度 AR(1) ρ∈{0,0.2,0.4,0.6}；创新 {标准正态, t₃ 重尾}；缺失 {无, 随机 20%, 连续 3 月聚集}；批内单元相依 {独立, 共同因子 ρ_c=0.3（随机流实际共享）}。4×2×3×2=**48 格**，仅测主门禁候选一个方法。
2. **唯一主要终点=全批 248 单元整批 FWER**（每批=248 个单元各过门禁、计 ≥1 过的批占比）；**取消 v3 的逐单元率终点（K=12×R=2,500 设计撤回——极端单元率确认无意义且 K=12 不能代表 248 单元整批）**。FWER 比较界=**0.05**（B.3.2 Bonferroni 方向界，不依赖独立性）。
3. **判定=上界标准（无任何容差因子）**：每格 CP **上置信限 ≤ 0.05** → 该格"受控"；CP **下置信限 > 0.05** → "超标"；中间 → "不分辨"。受控必须是以上置信限证明的限定，**不以点估计/下置信限接受**。
4. **多格同时覆盖**：方法适用性主张要求 48 格**同时**受控；为实现全域联合覆盖，逐格 CP 采用 Bonferroni 调整水平 **1−0.05/48≈99.896%**（union bound 下全域覆盖 ≥95%）；若逐格仅用 95% 分别陈述，则不得包装为全域保证（二选一，建议前者用于适用性判定）。R=20,000 时零拒绝批的上界=1−(0.05/48/2)^(1/20000)≈**3.8×10⁻⁴**（远低于 0.05，零拒绝格信息充分）。
5. **计算量（以单元评估次数计；v3 的 1,320 万算式与 20–40 分钟测速均无依据，撤回）**：每格 R 批 × 248 单元；R=20,000 → 48 格合计 **248×20,000×48=238,080,000 次**单元评估（若另留逐单元格 +30,000×48=1,440,000 → 239,520,000，与主对话算术一致；本设计不保留）。**R 为冻结常数：先以小规模实测标定单次评估耗时，再在冻结案定 R**；不设看结果后加批；超预算回主对话重审。
6. **功效格只披露不选择**；校准工件（代码/种子/原始计数/JSON）全量留档，CP 与计数须过独立复算（13/13 先例）方可进入 B.6。
