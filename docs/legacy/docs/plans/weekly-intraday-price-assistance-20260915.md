## 3. 先定义统一输入与输出

### 输入

1. 账户：现金、总持仓、当日可卖量、实际成本、费用规则、账户版本、风险限制。
2. 成交：唯一成交编号、时间、股票、方向、数量、价格、实际费用及属于哪一轮交易。
3. 五分钟行情：股票身份、交易日、bar 起止时间、可用时间、未复权 OHLC、成交量／成交额及单位、来源和是否完整。
4. 日线和状态：历史证券目录、板块、逐日 ST／停牌／上市退市、价格限制、复权映射、必要公司行为；信号只使用决策时可得信息。

缺失、重复、过期、未收完的 bar 和错误价格口径，必须有明确处理。五分钟收盘后才能使用该根完整特征；不能使用当日尚未发生的日高、日低、收盘和成交额。

### 输出

每只股票输出：观察时间、账户版本、建议有效期、行动（等待／建仓／持有／加仓／减仓／退出／完成做 T 剩余部分）、参考价格区间、数量、资金占用、费用、目标价成交情景下净收益、预测的不确定性、失效条件、理由及下一次复评。

预测期望收益、目标价成交后的条件收益、实际已实现收益分别存储。未经校准不能显示确定胜率。到收盘的预测高低范围不能直接相减作为可赚价差，需要验证买卖顺序及实际可成交路径。

一周与做 T 使用同一真实账户投影，共享现金／持仓／风险额度；按交易轮次记录用途，防止同一底仓重复出售或多个建议重复占用现金。

## 4. 因子、组合与资金权重的选择顺序

本计划采用严格的三层顺序，后一层不能反过来改变前一层：

### 第一层：筛选可用因子

先在历史训练区间内评估已有日线因子，按经济含义分家族，至少覆盖动量、趋势、波动、流动性、相对市场强度和回撤状态。对每个因子记录覆盖率、方向稳定性、未来 5 日收益关系、分段表现、与其他因子的相关性及交易成本后的边际价值。

因子筛选只使用训练数据；验证区间在因子名单和筛选门槛冻结后才能读取。高度重复的因子只保留有明确增量信息的代表，不能因为某个窗口表现好就事后替换窗口。已有月频因子可以作为候选，但必须按本次日线和 5 个交易日目标重新评估，不能直接继承月频结论。

### 第二层：确定因子组合权重

在筛选出的因子名单冻结后，才估计因子权重。第一轮只比较两种事前固定方法：等权，以及在训练区间内估计的受约束权重。权重约束包括非负、总和为 1、单个因子上限和家族上限；不得根据验证期收益重新调权。

组合分数用于排序股票和判断信号强弱。因子权重优化与股票资金权重优化分开记录，不能把“某因子权重高”解释成“该股票应该买得多”。

### 第三层：确定股票资金权重

因子组合和排序结果冻结后，才根据账户现金、单股上限、风险预算、ATR 到风险价距离、费用和最多 5 只持仓约束，计算每只股票的资金权重。第一轮比较等风险分配与风险预算分配，资金权重不能反过来改变因子权重。

因此，完整链条是：

`候选因子 → 筛选因子 → 因子组合权重 → 股票排序 → 资金／仓位权重 → 交易执行`

每一层都保存独立配置、输入摘要和结果。若因子筛选没有通过，停止后续组合优化；若因子组合有信息但资金分配没有增益，保留因子研究结果，不把它包装成可交易策略。

## 5. 建议的研究配置，尚非用户实盘规则

| 参数 | 首版草案 |
|---|---|
| 初次单股建仓上限 | 账户净资产 20%，初始约 4 万元 |
| 单股持仓上限 | 净资产 25%，包括补仓和买入启动做 T 后的临时敞口 |
| 总持仓上限 | 净资产 80%，初始约 16 万元 |
| 单股一轮计划亏损预算 | 该轮开始时净资产 1%，初始约 2,000 元；延期／补仓不重置 |
| 账户保护触发参考 | 扣除外部出入金影响后的净值，从历史高点回撤 8% 时暂停新增建仓／补仓并复评 |

这些比例仅是上一轮讨论提出的研究起点，无已验证最优性。P0 需明确市值自然变化与新订单检查的区别、部分卖出与做 T 盈亏如何计入一轮风险、保护期未完成交易的处理，并冻结配置。风控触发是建议规则，不保证在跳空、停牌或无法成交时把实际损失限制在预算内。

补仓必须同时满足新买入条件、预计费用后空间、剩余风险和资金上限；不得仅因价格下跌或降低平均成本而补仓。保留初始建仓价、累计损益及目标变更记录。

## 6. 执行阶段与交付

| 阶段 | 具体工作 | 交付及完成标准 |
|---|---|---|
| P0 需求与实验冻结 | 核复用缺口；冻结输入输出、股票资格、目标定义、状态转换、参数、时间切分、候选预算与停止条件；登记公共文件所有者 | 可执行的配置、公式／政策说明、样例、来源清单及事前审核记录；当前仅完成本文与勘查 |
| P1 共用账户与历史重放 | 复用日内计划已验证的账户输入、精确费用、T+1、可卖量、部分成交、跨日、公司行为和重复成交框架；用合成账户和固定历史切片接通一周／做 T 状态 | 一条完整和一条未完成路径的独立精确核算；关键负例和新调用回归通过；旧参数不自动继承 |
| P2 因子筛选 | 在训练区间评估已有日线因子，按预先登记的覆盖、稳定性、增量和成本门槛筛选；验证区间保持封存 | 因子筛选表、家族去重、训练期结果和冻结因子清单 |
| P3 因子权重 | 因子名单冻结后，比较等权和受约束权重；只使用训练区间估计，完成后封存 | 因子组合配置、权重身份、训练期诊断和验证前审核 |
| P4 一周交易研究 | 用冻结因子组合自动选股，再计算股票资金权重；运行建仓、延期、分批卖出和补仓的完整政策 | 20 万共享账户主／压力结果；逐日净值、每轮损益、延期／补仓归因及全部失败 |
| P5 做 T 研究 | 独立推进用户指定标的路径；新假设针对剩余交易时段价格与可执行往返，先诊断预测，再回放交易 | 预测校准和费用后增量；先买／先卖的顺序、未完成部分、隔夜风险及主／压力账本 |
| P6 联合验证 | 在相同起始资金下比较一周单独、做 T 单独及两者共同运行，核现金竞争与仓位冲突 | 共用账户结果；增量、集中亏损、资金占用和期末未平仓资产完整披露 |
| P7 实时模拟准备与接入 | 历史阶段先交付数据契约及模拟输入重放；未来获得实时阶段授权后，接用户五分钟行情并只做模拟跟踪 | 到达时间、预测、建议、实际录入／模拟状态分别留存；缺行情和重启恢复可追溯 |

顺序：P0 → P1 → P2 → P3 → P4 → P5 → P6 → P7。P2 因子筛选通过并冻结后才能进入 P3 权重；P3 权重冻结后才能进入 P4 股票资金分配。做 T 的 P5 可复用 P1 的账户能力，但其新预测和交易规则必须独立冻结。一条研究没有增益时保留结论，另一条独立路径继续；没有合格能力时不拼成可用联合策略。

P0/P1 的工程推进不等于预测能力已经有效。P2/P3/P4 的实验登记审核通过后按冻结范围执行，阶段审核不要求用户重复确认普通可逆操作。

## 7. 第一轮实验预算与判断方法

以下为预算建议，P0 冻结后才运行：

- 一周线先做已有因子筛选，再做因子权重；最多登记 1 个新增学习构造，做 T 线最多 1 个新增学习构造；各有一个预先指定的朴素预测／固定政策对照，零超参数搜索。模型、特征、训练窗口、目标映射须在运行前写全，本文不把未选定的方法冒充已冻结模型。
- 一周管理固定登记三个对照：相同选股与初仓的既有退出基线、新续持／分批减仓但不补仓、新完整政策含补仓。分别检验新增行为的增量，不从持有／补仓路径中事后挑最好结果。
- 做 T 与相同底仓不操作及一个冻结的费用价位对照比较；相对较差对照为正但相对不操作为负，不计为增强成功。
- 每条已登记政策只运行主、压力两种成交情景。预测一次生成供两个情景共用；参数／构造尝试与纯技术修复分开计数。联合政策只固定一套，不追加权重搜索。
- 主／压力的具体延迟、滑点、参与率和样本量／统计门槛在 P0 明文冻结，不默认把旧实验数值视为已经适合新需求。
- 同时看净收益、相对对照增量、回撤、实际持有天数、资金使用、补仓贡献、单股／月份集中度、未完成交易，以及预测相对朴素基线的误差和校准。所有达标或失败路径均披露，不只汇报成交的盈利轮次。
- 合格信号不足时建议少于常态 3 只或等待，作为待冻结的防止强行凑数规则；最多 5 只是产品容量约束，不用作统计研究的候选搜索限额。
- 没有费用后增益、样本不足、数据／实现有缺口分别记录。完成既定预算后停止新增假设，提交继续／停止／不足结论；不测试到盈利为止。
