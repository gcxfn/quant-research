## 1. 目标与四门分离

- 允许所有策略失败：任何一轮全部淘汰也算按协议成功完成。
- 四个门严格分离、不得互替：**R0 工程完成 / 系统可信 / 策略有证据 / 产品可执行**。
- 数据、实现、回测三条链分别记 **VALID / INVALID / UNKNOWN**，允许多个同时阻断。
- 只有三链皆有效且选择统计协议有效，才允许科学判断。
- 未来阶段（非 R0）须预登记经济最小效应 δ（含口径）、功效与区间判定：
  1. 净增量效应 CI 上界 < δ —— 在登记域未达经济效应；
  2. CI 下界 ≥ δ 且成本、容量、风险等配套检查通过 —— 有支持；
  3. 其余 —— 证据不足。
- δ 属预登记事项，不得当下随意定数；统计不显著不等于无效；任何结果不得表述为证明持续 Alpha。
- R0 沿用其原有冻结判据（§2），不追溯套用新 δ 或新 n。
