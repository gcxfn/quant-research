## 1. 假设与依据

- R1（D-2026-09-09-01）48格全部失败的定位在**买入侧毛收益与成本覆盖层**：最好候选低波动 f4_atr14_price 毛收益仅 +0.0706%/笔，无法覆盖约 0.20 个百分点的往返成本。
- 成本结构测算：平均持有约3会话 → 每年约80次往返 × 0.20% ≈ 16%/年成本拖累；最好因子毛收益年化约 5.6%。失败是结构性的，不是运气。
- 用户实际费率为股票万1（最低5元）、ETF万1（无最低、免印花税）。R1 使用的股票万2.5 口径高于用户真实成本，存在"按虚高成本否决候选"的可能。
- **本轮假设（待检验，非结论）**：在真实万1费率下，把A股股票型ETF纳入同一横截面池后，存在通过既定 Gate A/B1/B2 的候选。依据有二：ETF 往返成本（约0.12pp）显著低于 R1 股票口径（0.20pp）；低波动类因子在ETF横截面上的毛收益是未检验的经验问题。
- **诚实预期**：股票在 3.3万名义单笔下最低5元生效（实际约万1.5/边），成本仅从 0.20pp 降到约 0.18pp，单靠费率救不活任何 R1 候选；本轮真正的赌注是"ETF十分位的毛收益是否大于 0.12pp"。若本轮仍全负，证据指向瓶颈在信号强度而非成本，届时应回到换信息族/降频/停扫的方向选择。
