## 0. 定位与纪律

- 目的：对 V3 R3 已观察历史上的回撤结构做**工程修复验证（风险整形）**，不是新 alpha 挖掘。
- 病因依据：`docs/experiments/v3-dd-attribution-20260909.md`——最大回撤 −58.85%（2021-09→2025-04）中约 66% 跌幅来自五类 10% 限幅行业主题 ETF 的 Top3 集中；月末退出规则内滞后中位 11 个交易日；同窗沪深300 −24.2%（beta 约四成）；whipsaw 仅 10 次。
- 性质声明：修复规则在看过 R3 回撤归因后设计，同窗重跑属"**已观察历史修复验证**"；PASS 仅解锁前向 shadow 验证，不直接修改生产规则。
- **45% 回撤门槛是中间标准声明**：即使全组合臂 PASS，也未达到约 20% 回撤的最终目标；进一步压缩需要更深的仓位折让或其他臂，须另行预登记，不在本轮追加。
- 禁止：任何参数扫描（全部阈值单值冻结）；"每日/加快趋势退出"方向已判死（年化 10.19%→1.99%、回撤恶化），本轮不重开。

## 2. 三个修复臂

### 臂A 相关性集中度约束
- 每月末信号时，按总分降序贪心入选；若候选与已入选者的**过去 120 个交易日日收益相关系数 ≥ 0.80**，跳过并顺延下一名（顺延者同样须过门禁与相关性约束）。
- **选不满 3 只时的分配（冻结）**：资金按 3 个槽位均分；选出 k<3 只时，每只占 w/3，剩余 (3−k)·w/3 槽位持币（不因候选不足而放大单只权重）。**适用形态（外部审核第 1 轮裁决澄清）**：本槽位规则适用于含 A 或 C 的全部形态（纯 C 亦然；纯 A 时 w=1）；纯 B 与基线沿用 R3 原行为（budget=总权益/目标数）。
- 相关系数仅用截至信号日数据（无前视）；不足 120 日按可用窗口（≥60 日）计算，<60 日不施加约束。
- 冻结值：窗口 120 日、阈值 0.80，单值，不做敏感性扫描。

### 臂B 排名衰减退出
- **每日排名池定义（冻结）**：对当期池内**全部 ETF** 按总分（R20/R60/R120 百分位等权合成）排名，**不施加趋势门禁**——趋势条件只在月末选股时生效，与"每日趋势退出已判死"的机制隔离由此成立。排名要求 120 日历史，不足者当日无排名（不可能是持仓，因入选必经门禁）。
- 持仓 ETF 当日缺行情（无 bar）→ 当日无排名 → **不触发退出**，计数披露；排名并列沿用 `_percentile_ranks` 平均名次。
- 触发规则：持仓排名 > 6 → 次日开盘卖出，资金持币至月末再平衡（不月中补仓）。
- 冻结值：缓冲 = 6（Top3+3），单值。

### 臂C 波动目标仓位（含月末再平衡，为 C 臂新增规则）
- 每月末信号时，用**新选定组合**（k 只等权）截至信号日的**前 20 个交易日**等权日收益计算年化波动 σ̂（决策时点可得，无前视）。
- 下月仓位 w = clip(0.15 / σ̂, 0.50, 1.00)；重叠交易日不足 15 个 → 不施加约束（w=1.0）；σ̂ 年化 < 0.5% 时按 0.5% 计（w 封顶 1.0）。
- **"月内不变"精确语义**：不因波动率变化主动调仓；臂B 触发的卖出照常执行，卖出资金持币至月末；留存持仓保持股数不变。
- **月末再平衡规则（C 臂新增，非基线行为）**：
  - **不含 C 的形态（A、B 单臂及 A+B）**：完全沿用 R3 原持仓规则——已持有且仍入选者保留股数不调平，只为新入选标的按目标等权预算建仓（§1 基线持仓规则）。
  - **含 C 的形态（C 单臂、ABC 全组合）**：月末将全部持仓调整到 w/3 目标槽位（卖出超额、补足不足）——波动目标按月调整敞口所必需，由此产生的额外换手与成本计入 C 臂归因，单独计量披露。
- 冻结值：目标年化波动 15%、下限 0.5、回顾 20 日，单值。

### 判定形态
- **主判定对象 = A+B+C 全组合形态**；A/B/C 单独形态（及 A+B）并列报告，仅作归因参考，不作判定对象（控制多重检验）。

## 3. 回测口径

- 窗口、成本、执行、池、数据源与 R3 完全一致，仅叠加上述规则。
- 输出指标：年化、夏普（含现金日、无风险 0）、最大回撤、**水下交易日总数**、Calmar、换仓次数与成本明细、逐回合归因。
- **水下交易日总数定义（冻结，硬判据用）**：全窗口内每日收盘组合净值 < 历史最高收盘净值的天数之和；等于历史峰值的新高日不计入；样本末未修复回撤区间自然计入。基线 R3 与所有变体用同一定义复算。

## 4. 成败标准（事前，全组合臂）

1. 年化收益 ≥ 基线 − 2.0pp；
2. 最大回撤 ≤ 45.0%（较基线改善 ≥ 13.85pp）；
3. 水下交易日总数 ≤ 基线 × 0.70（同 §3 定义复算基线）。

三条同时满足 = 修复 PASS（解锁前向 shadow）；任一不满足 = FAIL，如实封存，不追加参数搜索。

## 5. 披露
