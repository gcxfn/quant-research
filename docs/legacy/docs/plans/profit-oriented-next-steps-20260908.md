- 所有操作保持 MANUAL_ADVICE_ONLY，严格 T+1，无券商连接、自动下单或自动修改实际账户。
- 当前 P4 的五日尺度、12 个候选构造、4 档止损和 Gate A/B/C/D 保持冻结。本计划不把“五天净赚 2%”改成另一套交易规则，也不将其当收益承诺。

### 阶段六：用户决定是否人工小规模试运行

仅在前向结果未否定优势、实际执行成本可接受且独立审查认为证据足以讨论试运行后提出。届时提供具体方案，由用户确认试运行金额、可接受亏损、暂停线和操作时间；本计划不自动授权交易。

小资金不一定更容易盈利：最低佣金会升高。按拟投入资金重新计算最低手数、分散数量和扣费优势，不能照搬 10 万元结果。若该金额无法经济执行，继续观察或放弃，不用杠杆补足。

只由用户下单并录入真实成交。分别记录模型收益、人工实际净收益和执行偏差；模拟成交永不写成实盘。预先确认的亏损线或关键执行偏差触发时停止新开仓，存量按既定风险方案处理，不自动加仓摊平。

扩资前核实真实成交样本、成本、回撤和容量；不因连续几笔盈利自动放大投入。以实际净收益作为最终验收，不承诺固定时间内赚钱。

## 7. 如果这一轮没有盈利候选

交付一页结论，明确失败发生在信息强度、买入侧收益、组合稀释、交易成本、无法成交或时间外失效的哪一层。结论必须能指向下一步行动，不重复生成同义报告。

- 没有信息强度：停止扩写相同价量指标；只有存在明确经济假设和可取得的事前数据时，才提出一个新假设族。
- 有毛收益、被周转成本吃掉：下一轮可提议放宽周期/退出目标或单独评估 ETF，但先取得用户对范围变化的确认，不扩大本轮参数网格。
- 因子有效、Top3 失效：下一轮只研究组合集中度这一项，不同时改因子和退出。
- 时间外失效或前向失败：终止该候选，保留失败记录；不能继续利用同一验证窗调参，然后重新称为样本外。

下一轮最多提出一个新的、可证伪的研究假设族，先写依据、数据、预算和停止条件。没有新证据就暂停短线研发，不把 V3 尚未对本目标验收的结果当替代盈利保证。
