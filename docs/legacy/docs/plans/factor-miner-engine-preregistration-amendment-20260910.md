## §1 零方差语义(B-01,P1)

**修订**:窗口算子 STD/ZSCORE 的输入窗口、CORR 的任一侧输入窗口,若**窗口内最大值==最小值**(所有值完全相等),该日输出 **None(无信号)**。MEAN/SUM/MAX/MIN 不受影响(常数窗的均值/和有定义)。

**依据**:常数窗口的总体方差在精确算术下严格为零(Codex 以 Fraction 参考证实),z 分母无定义;旧实现因浮点残差输出伪信号(如 [1.1]*20 → None 与 [1.3]*60 → ±0.99 并存,取决于顺序求和的舍入运气)。

**边界声明**:近常数窗(值不完全相等但差在浮点残差级)维持现两遍式语义不变,本轮不改;若审计要求延伸,另行修订。

**历史影响与重算规则**:本引擎尚无已产出的正式 TRAIN 工件(R0 首跑于落盘前死亡),故无既往晋级需要作废;今后一切运行(含双路径)在新语义下计算。任何在本修订前用旧语义产生的因子值/晋级(如 dev-smoke 通道工件)不得用于晋级判定,只作历史留档。

**双路径同步**:纯路径与 numpy 路径以相同判定谓词(窗口 max==min)同步实现,逐位等价要求不变。

## §2 TRAIN 多重检验收紧落地(C-01,P1)

**修订**:TRAIN 粗筛门禁的 bootstrap 置信区间由固定 95% 改为 **α_total=0.10、按 N 校正的双侧端点**:`[α_total/(2N), 1−α_total/(2N)]`(百分位)。N=246 时端点约 [0.0203252%, 99.9796748%],与预登记 §5 "每轮粗筛 α=0.10/N" 及 D-28 扩候选决策的统计代价承诺一致。

**N 的构造定义(冻结)**:N = **本轮冻结评估单元数**(evaluation units = 公式哈希去重后的有效结构 × 其窗口变体,即 director 构建的 units 列表长度),运行时从 units 结构自动派生,**禁止手填或用文档数字充当**;N 与端点写入每单元结果与 registry 可见字段(`train_multiple_testing`),供复算。

**兼容**:LOCKBOX 既有 Bonferroni α=0.05/N_frozen 不变;描述性 95% CI 保留为报告字段(不参与晋级判定);VALIDATION 阶段口径维持预登记原文,如需校正另行修订。

**历史影响**:同 §1——引擎尚无正式 TRAIN 工件;财务粗筛两批(F1–F5、F6–F31)各自已按 α=0.10/N(N=5/N=26)实现,不受本条影响。

## §3 门禁输入校验(C-02,P1)

**修订**:`continuous_gate` 对输入与 bootstrap 输出 fail-closed——非 None 的 IC 值必须为有限数且 ∈[-1,1];CI 下界≤上界且均有限。任何 NaN/±inf/越界/顺序颠倒 → 门禁 fail,原因码 `invalid_ic_input`;不抛异常中断批次,也不静默通过。

## §4 十分位描述统计的并列分组(C-04,P2)

**修订**:`decile_top_bottom_spread` 分档前先按并列平均秩赋值,再按秩取十分位(兑现原注释承诺);结果对因子字典构造顺序不变(股序不变量入测试)。该指标为描述性,不参与晋级。

## §5 回测成交日资格、连续账本与账本约束(D-01/D-02,W1-02/W1-03/W1-04,W2-01/W2-02/W2-03/W2-04,P1)

**修订**(factor_miner/backtest.py 层;首版仅覆盖 D-01/D-02,经 Codex 复审 wave-1 判定 W1-02/W1-03/W1-04 不通过后按下列口径重写;经 Codex 复审 wave-2 判定 W2-01/W2-02/W2-03/W2-04 不通过后按第 6~9 条再扩充——**文档冻结口径先于代码与测试**):
1. **成交日资格(W1-03)**:买入与退出执行日均须股票可交易。执行状态必需字段 tradestatus/volume/isST **全部存在且合法**(tradestatus/isST 为 ∈{0,1} 的整数,volume 为有限数值且>0)才可能判可交易;任一缺失/None/非法类型/非有限值 → 稳定理由拒绝:`unknown_status`(状态表缺该日或三字段全缺失)/`partial_status`(tradestatus 或 volume 部分缺失)/`st_unknown_on_exec`(执行日 ST 状态未知——**正式输入缺少执行日 ST 状态不得默许成交**)/`invalid_status_type`(类型或取值非法,含字符串成交量,干净拒绝不抛 TypeError)/`nonfinite_volume`(volume inf/nan)/`suspended_on_exec`/`zero_volume`/`st_on_exec`;不可执行→不成交/顺延,逐笔记录原因与实际退出日;
2. **连续权益账本与资本约束(W1-02)**:逐月收益来自**跨月连续的现金+持仓权益账本**,不再将递延持仓的全期收益计入入场月——期初(入场日开盘、上期卖出后、本期买入前)现金归一为 max(0, 目标槽位−递延占用)×单笔名义(注入/撤回不计入当月收益,非复利机制假设);期初权益=现金+递延持仓按入场日开盘的市值(缺行取最近可得收盘);**未成交/受阻资金留现金(零收益)、不得向成交者重配**(目标槽位分母;替代首版"重等权仅对实际成交集"的相反表述);**递延持仓占据的目标槽位不得再分配给新选股**(新开仓上限=目标槽位−递延占用;新开仓名次高者先填槽,无空闲槽位→no_free_slot,现金本金不足→no_free_cash,同股在途→carry_still_held);期内实际退出(含递延落地)按实际退出价回笼现金并计卖出费;期末未了结仓位按第 6 条双边界估值接口重估(下一入场日开盘边界;最终期按样本末收盘边界);月收益=期末权益/期初权益−1(net 含本期全部精确税佣费用;gross=(权益变动+本期费用)/期初权益),递延持仓收益按边界估值拆分归属各月;资金守恒 equity_start(k+1)=equity_end(k)+注入(k+1),逐月 ledger 块披露现金/持仓/权益全部分项供复算;净额与基准同月配对(共同月份,报告 n_paired_months);组合 gross/net/门禁输入唯一来源=该账本,逐笔口径仅存于披露(exit_actual/exit_status)、基准(第 7 条同窗基准)与独立逐笔标签函数 position_net_return;
3. **月类型与未成熟跨月传递(W1-04,W2-04)**:逐月 month_type∈{normal, cash_no_signal, cash_blocked, immature}:无信号真现金月(cash_no_signal)与有目标全未成交现金月(cash_blocked)的 gross/net=0.0(现金零收益,真实账本月)**计入均值**;已入仓但数据窗内无退出价的未成熟月(immature)gross/net=None(不编造 0 收益)**不计均值**并披露 n_immature,持仓留在账本阻再开仓;**未成熟状态随持仓跨月传递**(W2-04):n_immature 每期从期末全部未决(incomplete_label)持仓重建,不因月份切换清零;仅当该持仓的原始退出调度重试按第 8 条明确恢复条件得到新信息(找到可执行退出开盘,或窗内出现有效收盘转为可估值持仓)才恢复正常计价——禁止无新报价/无成交时仅因月份循环切换就恢复为有效零收益;允许的陈旧价估值必须随第 6 条估值时点/陈旧度字段披露;
4. **精确税佣净额**:逐笔采用 `max(佣金率×金额, 最低佣金)`(默认万2.5/5元,卖出加印花税 5bps)——口径名为**精确税佣净额(不含滑点)**,不得表述为"完整成本权威净收益";最低佣金临界金额=5元÷万2.5=**2万元**;17/27/37bps 阶梯降为**标注 proxy 的描述性字段**;
5. **产品成本模型**:Top15 组合的仓位数量/规模规则(如 20万÷5万=4 仓等权 vs 收益自适应定仓)为独立产品决策,需单独预登记,**不在本修订范围**;在彼之前本模块不得为 Top15 产品签执行资格。
6. **估值接口双边界:实际退出≠估值(W2-01,W2-02)**:账本边界估值显式区分两种边界,**开盘边界**(期内/期末以下一入场日为界)只能取该日开盘价,缺失时回溯**严格早于该日**的最近有效收盘——该日收盘在该时点尚不可知,禁止使用;**样本末边界**(最终期)取截止日收盘,缺失时回溯严格更早收盘(兑现"最终期按最后可得收盘")。每次估值记录**估值时点(mark_date)与陈旧度(mark 与边界日相差的会话数)**并随持仓披露。**确认成交才发生退出事件**:只有退出调度解析为可执行开盘(executed)才设置卖出日、计卖出精确税佣、按卖出价回笼现金并删除持仓;顺延超限的"最后可得收盘 MTM"(mtm_deferred_exit)**只是估值与披露,不是卖出**——该类持仓保留数量(shares)、市值与资金占用,继续占据槽位,逐月 ``open_positions`` 披露(数量/入场/估值/估值日/陈旧度/状态),期末未平仓非零须可见。顺延超限后本轮**不自动重试卖出**(重试窗口语义未冻结,保守不假流动);若后续被再次选中按 carry_still_held 阻新开仓;
7. **基准同窗规则(W2-03)**:基准=**全池(P1 掩码在各期入场日合格名)等权、逐名独立槽位生命周期组合**,与组合槽位采用**完全相同的**执行日资格、入场检查(缺行/缺开盘/缺停板参考价/一字涨停不追)、退出调度(跌停/停牌顺延、超限 MTM 保持未平仓不假卖出)、第 6 条双边界日历估值与递延拆分;同股已持有不重复开仓(carry_still_held 同规则);基准为 gross 口径(无费用),无资金/槽位约束(每名独立名义);月 bench_gross=当期活跃槽位(本期实际退出者按卖出价、其余按边界估值)价值变动/期初价值的**等权均值**,未决(未成熟)槽位剔除,全无活跃槽位→None;基准不得把完整未来交易标签充当当月收益(逐股标签的全期收益必须按同一日历边界拆分归属);单资产、相同初始持仓、相同交易规则下组合毛收益=基准毛收益(验证测试);多资产下两者差异只允许来自池宽度(全池 vs Top-q)与组合资金/槽位约束等**交易规则差异**,不得来自时间归属错误;
8. **未决调度重试与恢复条件(W2-04 配套)**:未决(incomplete_label)持仓的退出调度每期以**原始退出目标**重试解析(组合与基准同规则):重试找到可执行退出开盘→转 executed 按实际卖出处理;窗内出现有效收盘(无可执行开盘)→转 mtm_deferred_exit 可估值持仓(按第 6 条不假卖出);两者皆无→维持未决并计入 n_immature。递延超限(mtm_deferred_exit)持仓不重试(第 6 条);恢复只由新增行情数据触发,不由月份切换触发;
9. **披露键(本轮新增)**:逐月 ``open_positions``(未平仓明细:symbol/shares/notional/entry_px/entry_date/mv/mark_date/mark_stale_sessions/status)与 ``n_open_positions``;逐月 ``bench_gross`` 改按第 7 条同窗口径计算(旧逐股标签口径作废,依赖旧数值的工件不得复用)。

**④⑤家族门禁判据口径补释**(按 Codex 复审 2026-09-11 裁决第3条同步):VALIDATION 家族门禁 ④(17bps)/⑤(27bps)晋级判据维持冻结的 17/27bps proxy 口径(读 `net_edge_proxy` = gross−turnover×bps,该阶梯已整体降级为 proxy 标注);精确税佣净额 `net_edge`(不含滑点)不随档位变化,作为补充证据字段并列报告、不参与晋级。正式路径**不回退**:`bt` 为空、缺 `net_edge_proxy` 键或其值为 None → 一律按不可判定处理(`net_edge_<N>bps_undecidable` 判拒绝),不隐式换指标;仅显式 opt-in 的历史测试档(`allow_legacy_net_edge=True`)允许旧形状 dict 回退 `net_edge`,正式主管线不触及。
