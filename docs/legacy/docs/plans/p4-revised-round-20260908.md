## 设计型随机对照

独立于收益，在每个交易日的共同有限 h=5 标签样本上，按证券代码排序后用 Python `random.Random(seed).shuffle` 生成均匀随机排名。对排名和真实标签平均秩计算 Spearman IC。两种固定日集合：全部交易日、market_state=True交易日（覆盖 F6 的条件样本）。各20次，种子2026090800至2026090819；每个种子依日期顺序推进，两个集合使用同一逐日随机结果。

使用原 Gate A 的 mean IC、ICIR、四年符号一致性判据，保存全部20次结果，不择优、不改种子。随机列不计算策略收益、不进入候选。

整体异常规则提前冻结：每个集合记 Gate A 通过次数 K。给定每天共同样本数 n，随机排列 IC 的条件方差为 1/(n-1)，不同日期独立，均值方差 V=sum(1/(n-1))/T²。由 Chebyshev 得单次过 Gate A 的保守概率上界 p=min(1,V/0.02²)，因为 Gate A 必须满足绝对均值至少0.02。取最小整数 k>=2，使 Binomial(20,p) 的 P(K>=k)<=0.025；两集合用 Bonferroni 合计上界0.05。K>=k 暂停；若不存在阈值或无有效日期，则诊断不充分、暂停。此界只用于检出随机对照异常，不是候选显著性或盈利证据。至少两次才会触发，单次偶然过线不会停轮。
