## 任务2：引擎修复收口及研究入口接线验收

### 2.1 先确定实际要运行的版本

1. 对照当前主仓、隔离性能实现、拟运行快照和最新T1数据/账户修复，生成路径级差异与SHA256映射，明确哪些修改已合入、哪些只存在于隔离目录。
2. 在独立新目录完成必要整合，不能整仓覆盖主仓或用旧性能快照替换较新的T1修复。登记实际入口、cwd、Python与依赖版本、PYTHONPATH、后端、L0-only开关、缓存位置和资源配置。
3. 默认验收拟采用的CPU优化路径，GPU继续不采用。若采用已验收旧CPU路径回退，须说明原因、速度限制，并在新批次核当前清单接线；不能将“旧版通过”直接挪给新版本。pure回退使用实际支持的显式参数，先核CLI帮助，不靠清环境变量猜测。

### 2.2 收口已知问题，已修项只复核

| 检查面 | 必须满足的行为与证据 |
|---|---|
| 跨进程缓存 | 相同源码、输入和配置在至少两个新进程生成相同键，第二次真实命中；改变预处理实现或实际输入必须失效。不得用含内存地址的对象表示生成身份 |
| 缓存依赖完整性 | 实际资格、上市年龄、ST未知处理、复权、时间轴/窗口等配置及依赖源码入身份；逐项核实际读取链，至少证明资格参数改变后失效、cached与fresh资格掩码一致 |
| 损坏缓存恢复 | 缺数组、缺shape/错误类型、同shape内容篡改均拒绝旧条目；保留坏件证据，可重建并再次命中，不永久卡在已存在目录，也不悄悄消费坏值 |
| 运行身份 | 代码、清单及分片、配置、实际消费数据在装载/恢复/汇总及收尾按契约校验；必要身份不符时非零退出，不能产有效成功裁决；仅核历史工件的快路径须明确未重新核实数据 |
| 交付冻结 | 核新final-manifest所有引用、生成器和新修复证据；重复验证不改被绑定文件。校验结果反向绑定manifest，不造成自指；命令实际写入新输出目录而非旧包 |
| GPU证据隔离 | 如最终包包含GPU证据，收尾身份失败必须失败退出且不得成为有效采纳依据；不要求重测GPU性能，不以GPU修复作为CPU筛选必须采用GPU的条件 |
| L0入口 | 正式CLI确实进入L0-only，使用冻结公式、方向、参数、股票池和标签；不误走成本阶梯默认分支。L1/L2消费契约单列，未做的不写已接通 |
| 公共能力兼容 | 与最新T1读取边界、字段、资格和身份规则共存；如合并触及账户/分钟模块，跑对应回归，确认未撤销最新源接受边界、公司行为及费用修复 |

新证据必须绑定本次实际运行版本。旧反例已关闭且身份未变时可复用可核实证据，无具体反例不重复增加审核层。

## 任务3：最终清单上的真实小批试跑

### 3.1 依赖及事前冻结

任务2通过、最终清单及门槛登记审核通过、真实试跑授权有效后执行。本次“写任务书”不单独授予运行权限；若已有后续明确授权则直接依其执行，不重复请示。

- 清单目标/上限2000个去重构造；未达2000须有真实去重、合法性或数据限制说明，不能将1430分母改写为2000。
- 从最终清单中事前固定最多20项，按家族、字段、算子、缺失处理和方向覆盖选取；写出选择规则与ID，禁止按已知收益选样。测试夹具与真实研究结果分开。
- 试跑使用正式训练窗口、真实历史股票池和数据规模；2025+禁止读取，标签成熟不得越界。缩小到40股等夹具只能补充验证，不能冒充正式规模试跑。
- 冻结候选、代码、配置、数据身份、种子、数值比较规则和命令。登记并发、线程、内存停止线、超时、磁盘预算及中断处置；不照搬旧19秒缓存命中或2000项2.2–3.1小时估算。
- 这最多20项属于最终L0预算，后续技术重跑单列，不重复算新构造。不得因试跑收益修改剩余清单或门槛。

### 3.2 真跑与核验

1. 在新输出根用最终CLI执行，记录装载、求值、汇总耗时、峰值内存、缓存命中/重建、完整退出码。候选失败、数据不足和程序故障分开记录；通过候选可以为0，试跑不以盈利为验收条件。
2. 逐候选核对公式、实际方向、参数、窗口、来源身份和结果键；预期与实得集合精确相等，重复、漏项、未登记结果或失败目录不能被汇总为完成。
3. 核月末轴、标签成熟、有效月份、缺失/非有限IC处理，以及ic_gate_pass、coverage_ok、data_ok、eligible_L1的分离；独立重算至少一个真实样例的月RankIC与有效月计数，另保留关键负例。
4. 在这同一组最多20项内验证中断/恢复和至少一次分片边界：可拆成两片每片不超过10项；正常执行与恢复的结果身份、数值和总分母一致。恢复不得漏算、重复计数或接受错误身份。中断/恢复是技术运行，不增加构造预算。
5. 验证试跑结果后续可按身份复用；若正式调度不支持部分分片复用，明确为技术重跑并保留旧结果，不能仅凭已有目录跳过整片。
6. 仅在资源预算内完成必要冷/热装载核验；正常路径、已知缺陷回归、关键负例和独立核算足够后停止，不扩展新公式或额外长基准。
