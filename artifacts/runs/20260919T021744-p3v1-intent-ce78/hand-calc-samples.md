# P3 引擎 v1.1 意图层 · 手算样例

全部为合成数据手算，与 `tests/test_band_intents.py` 中的断言一一对应（可复跑）。
世界价格：见测试文件 DAILY_B/HALF_B（样例 1）与 DAILY_A/HALF_A（样例 2）、DAILY_C/HALF_C（样例 3）。
费用：佣金 = max(万1×名义, 5元)；2024 年卖出印花 0.05%；初始资金 200,000。

## 样例 1 · 成交即停（test_i1_fill_stop，世界 B）

意图：买入 target_notional = 10,000 元，首次决策点 = (2024-01-02, 11:30)，source = 2024-01-02。

| 时点 | 引擎行为 | 数字 |
|---|---|---|
| 01-02 11:30 | 锚 = am.close = 10.00；数量 = floor(10000/10.00/100)×100 = **1,000 股**；挂 live S_pm(01-02) | 决策点权益快照 200,000；上限校验 10,000 ≤ 25%×200,000 ✓ |
| 01-02 S_pm | low 9.50 < 10.00（严格穿透）→ 按限价 10.00 成交 1,000 股 | 名义 10,000；佣金 5.00；现金 = 200,000 − 10,005 = **189,995** |
| 01-02 15:00 | **成交即停**：意图 deactivated（事件 `intent_lifecycle: filled`） | 之后 01-03..01-09 零重发、零成交 |
| 期末 | 无其他活动 | 现金 189,995；持仓 1,000 股 |

断言（test_i1）：fills 恰 1 笔；`stopped_filled == 1`；D1 之后该标的事件数为 0；期末现金 189,995。

## 样例 2 · 到期终止（test_i3_expiry，世界 A）

意图：买入 target_notional = 10,000 元，首次决策点 = (01-02, 11:30)，expiry = 2024-01-04。

| 时点 | 引擎行为 | 数字 |
|---|---|---|
| 01-02 11:30 | 锚 10.00 → 1,000 股 live S_pm(01-02) | S_pm low 10.05 ≥ 10.00 → 未穿透（第 1 次重发失败） |
| 01-02 15:00 | 锚 = 官方收盘 10.20 → live S_am(01-03) | 当日涨跌停 [10.35, 12.65]：10.20 < limit_down → `void_limit_out_of_range` 作废（跳空日锚越界，作废披露） |
| 01-03 11:30 | 锚 = am.close 11.20 → live S_pm(01-03) | low 11.30 ≥ 11.20 → 未穿透 |
| 01-03 15:00 | 下一 live session = 01-04 == expiry → **意图终止（expired）**，零挂单 | 事件 `intent_lifecycle: expired at 2024-01-04` |

断言（test_i3）：该标的事件序列恰 = [not_penetrated, void_limit_out_of_range, not_penetrated]；fills = 0；`terminated_expired == 1`。

## 样例 3 · rescale-down 逐决策点重算股数（test_i5_rescale_weight，世界 C）

意图 1：买入 10,000 元（01-02 11:30 决策）→ 01-02 S_pm 成交 1,000 股 @10.00，现金 189,995。
意图 2：卖出 intent=risk、target_weight = 0.05（减至 5% 权重），首次决策点 = (01-03, 11:30)，source = 2024-01-03。

| 时点 | 快照（引擎内） | 目标股数 | 重算卖量 | 结果 |
|---|---|---|---|---|
| 01-03 11:30 | 189,995 + 1,000×9.60（前收）= 199,595 | floor(0.05×199,595/12.00/100)×100 = floor(8.316)×100 = **800** | 1,000−800 = 200 股，live S_pm(01-03) | high 11.90 ≤ 12.00 → 未穿透（streak 1） |
| 01-03 15:00 | 189,995 + 1,000×11.00（官方收盘）= 200,995 | floor(10,049.75/11.00/100)×100 = floor(9.136)×100 = **900** | 1,000−900 = 100 股，live S_am(01-04) | high 11.20 > 11.00 → **成交 100 股 @11.00**，意图停止 |
| 01-04 之后 | — | — | 零重发 | 持仓 900 股 = 目标 |

两次重算的卖量不同（200 → 100）证明数量按"目标名义 × 决策点权益快照 ÷ 当期锚"逐决策点重算（§9 修订 3）；成交即停后无第三次重发（§9 修订 2）。
断言（test_i5）：not_penetrated 恰 1 次（limit 12.00）；卖出成交恰 1 笔 100 股 @11.00；`stopped_filled == 2`（买入意图 + 风减意图各一）；期末持仓 900。

## 附：K streak 与覆盖（test_i2/test_i4）要点

- test_i2：风减意图未成交重发序列锚价 9.30（am.close）→ 9.10（官方收盘）→ 8.75（am.close）逐决策点变化，detail 中 streak = 1,2,3 连续（重锚不重置），第 3 个 session 武装，次一 session（01-05 am）开盘 8.50 市价兜底 1,000 股。
- test_i4：同标的后一个意图（source 2024-01-03）在 (01-03, 11:30) 激活时取消前一个意图（source 2024-01-02），streak 归零重计——兜底时点从"若无重置"晚两个 session，实证 M1 键控重置。
