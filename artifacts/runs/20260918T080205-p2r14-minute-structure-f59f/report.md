## 3. U4 附带裁决（无论门过与否，预登记要求必写）

- F09-T2 正读数**未在本池本标签复现**：R14 池 + T2（次开→次收）下 F09（上午触板分钟占比）T2 IC = **−0.0058**（t=−3.41）；
  R10 的 +0.045 描述读数来自不同样本（含创业板、|T1|≤0.21 过滤）与不同 T2 口径（次开→当 11:30），两者不可互换。
- 状态分解（dev，池内均值 T2）：未触 0.19% / 炸板 0.66% / 封板 0.05% —— **不存在封板溢价**；炸板组次日反而是延续最强。
- 裁决结论：**「F09-T2 正读数 = 封板溢价掩盖炸板拖累」的混合假象假设不成立**（方向整体相反）；F09 的 T2 读数应视为样本/标签依赖的描述值，不登记为信号。
