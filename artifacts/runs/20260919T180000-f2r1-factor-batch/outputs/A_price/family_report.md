## 一、口径

- 仅 `tradestatus==1` 行序；`day_ret = close/preclose − 1`（参考价链复权，公司行动内含，
  面板诊断 0 null/0 inf/0 非正 preclose）；窗口收益 = `cump(t)/cump(t−k) − 1`，
  cump = ∏(1+day_ret) 按 symbol 累乘。
- std ddof=1；corr 用矩形式；Amihud ×1e9（amount 单位元）；A21 分母为 0 时 value=null。
- 月末网格 = dev 窗全市场并集日历每月最后交易日（72 期；评估 68 期见上）；
  因子帧不做剔除（池过滤留给 harness，与预登记 §1 一致）。
- 评估配置逐字 `FactorEvalConfig(horizon_days=20, n_groups=10, eval_freq="M",
  min_history_rows=60)`；池月度中位 3186 符号。
