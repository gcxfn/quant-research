## 一、字段映射表（本族最重要披露；预登记 §3-C 公式为语义定义）

| 因子 ID | 语义 | 实际数据源×列×变换 |
|---|---|---|
| C01/C02/C18 | 竞价溢价/分歧/动量 | xiaodefa `stk_auction_c`：`auct_prem = auction.open / 面板 preclose − 1`（**竞价时点 open，非面板 open**） |
| C03 | 竞价参与度 | `auction.vol / 面板 volume`（竞价量/当日量） |
| C04–C06 | 主力资金 | xiaodefa `moneyflow`：主力 = `(buy_lg+buy_elg) − (sell_lg+sell_elg)`（大+特大单，派发定义），分母=面板 amount |
| C07/C08 | 主动买/卖占比 | moneyflow 四档买方/卖方金额合计 ÷ 面板 amount |
| C09/C10 | 大单买/卖 | moneyflow `(buy_lg+buy_elg)` / `(sell_lg+sell_elg)` ÷ 面板 amount |
| C11–C14 | 涨跌停 | xiaodefa `stk_limit` 的 `up_limit/down_limit`；C11=mean(close/up_limit,20)−1、C13=count(close==up_limit,20) |
| C15/C16 | 九转 | xiaodefa `stk_nineturn`：**td = nine_up_turn − nine_down_turn（净 TD 计数，映射选择）**；C15=月末原值、C16=20 日和 |
| C17 | 资金偏斜 | moneyflow 主力净流入比的 20 日总体偏度 g1（与 F06 口径一致） |
| C19/C20 | 收盘强度 | 面板 `(close−low)/(high−low)` 20/60 日均值 |

**源核验**（派发要求）：
- auction 口径核验（3 票×3 日）：`auction.open ≠ 面板 open`（如 000001.SZ 2017-06-05：
  9.04 vs 9.13），`auction.vol ≈ 面板 volume 的 11%`——确认是**竞价时点聚合**而非全天行情。
- stk_limit 口径核验：`up_limit = round(preclose×1.1, 2)`（000001.SZ 2017-06-05：
  9.17×1.1=10.087→10.09 ✓；600519 同验 ✓）——名义价与面板未复权价一致，**可用**。
- moneyflow 缺失日比率填 0（无资金数据视为无主力净流入）参与滚动；auction/limit 缺失行
  比率为 null（不参与窗口，min_samples 不足则该月末无值）。
- nineturn 数据质量披露：trade_date 跨 chunk 日期格式不一（`20150602` 与
  `2015-06-02 00:00:00` 两种），已做双格式解析；nine_* 列跨 chunk 类型不一已统一 Float64。

## 三、族内解读与披露（探索性）

- **资金流全族不显著**（C04–C10 t 值 −1.8~+0.7）：dev 窗内 moneyflow 单/大单口径的
  横截面排序信息弱；与 E13（解禁前瞻，事件类）对照，"聪明钱"维度在本数据源上无信号。
  如实留档。
- **C13/C14 涨停频次是全 120 因子目前最强 t（−6.77）但分组非单调**（ic 负、mono 正）
  被 crit2 淘汰——"经常涨停的票未来差"集中在极端组、非单调递减，判据按冻结标准执行，
  不调参救活。
- C11/C12 高度共线（涨跌停距离互为镜像：close/up_limit 与 close/down_limit 单调相关），
  F3 去重时二选一。
- **C01 vs F08 同语义不同源对照**：C01（auction 竞价 open，t=−3.65，2015 同号存活）
  vs F08 overnight20（面板 open，t=+2.44，2015 反号淘汰）——竞价时点价与面板开盘价
  的微差改变了横截面排序与 2015 表现，源选择敏感，两行对照留档；F3 用 C01 版本。
- C19 收盘强度与 A14（振幅，被 crit2 淘汰）同属"日内结构"簇。

## 四、多重性披露

- 本族 20 检验属 N=120 宽口筛选；存活 4 为 F3 候选资格。C17（t 差 0.04）、
