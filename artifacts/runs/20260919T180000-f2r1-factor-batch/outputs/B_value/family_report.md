## 一、口径

- 数据：daily_basic 两批 concat（20260913-r2=2015-01-05..2018-12-28 共 975 块、
  20260909-r1=2019-01-02..2020-12-31 共 487 块，接缝已审计干净），全量 4,605,868 行、
  4,298 符号，(symbol, date) 去重后无重复。
- 快照类（B01–B08/B13/B14）= 月末行直接取值；窗口类（B09–B12/B15）在日频帧按
  symbol 交易日行序滚动后切月末。**月末 = 面板全市场并集日历**（该股无行→该月末无值）。
- B09–B11 用 daily_basic.turnover_rate（%）；B12 按冻结公式用面板 turn 列（比值，单位消去）。
- 负 pe/pe_ttm/ps_ttm 保留符号（负盈利/销售收益率语义）；pe=0 或 null → null。
- B13 = rank(ep_ttm)+rank(bp)、B14 = rank(−ln_tmv)+rank(bp)，rank 为**月末截面内** average rank。
- B15 市值动量含增发/回购等股本变动噪声（预登记已声明，如实施披）。
- 评估：信号 ≤2020-11-30（68 期统一口径），`FactorEvalConfig(horizon_days=20,
  n_groups=10, eval_freq="M", min_history_rows=60)`，池月度中位 3186。

## 三、族内解读与披露（探索性）

- **规模因子不显著**（B01 t=−1.60）：与 B14（rank 复合后 t=+3.33、mono +0.94）对照，
  说明规模的信息在**与其他价值维度的截面组合**中而非单独排序——B14 是本族最强。
- **B07 dv_yield 与 E16 div_yld120 同语义不同源**：E16（dividend 事件流自算，
  修复版 t=+3.08 mono +0.80 存活）vs B07（tushare dv_ratio 直读，t=+3.85 但 mono **反号**
  −0.40 被淘汰）——两源同 IC 方向但分组结构不同（dv_ratio 含 null 填充与口径差异），
  F3 若用股息率维度应优先 E16 的事件流实现。两行对照留档。
- B15 mv_ret20 本质是价格动量（20 日市值变化≈价格变化+股本噪声），与 A01/A09 反转簇
  高度相关（ic −0.0712 vs A01 −0.0702），F3 去重重点。
- 换手簇 B09–B12 与 A 族 A17/A18（流动性）语义相邻但源不同（换手率 vs 成交额），
  corr 留待 F3 汇总时统一计算。
