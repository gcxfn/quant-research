## 一、PIT 口径（披露三件套 + tie-break 披露）

1. **对齐**：四数据集（fina_indicator/income/balancesheet/cashflow）各经与
   `eval.pit_financial` 逐字同语义的值保留版对齐（修正稿胜出=同 (ts_code,end_date)
   取最新 ann_date 版本；signal_date = f_ann_date>ann_date>end+90d 兜底；
   符号风格转换）。**键集与 pit_financial 输出逐组校验一致**。
2. **tie-break 披露（重要）**：同 (symbol, signal_date) 多报告期公告时（如年报修正+季报
   同日），`pit_financial` 的 `.first()` 隐式取旧报告期（语义未定义）；本实现取**最新
   报告期**（金融上正确：投资者同日看到两份，最新报告代表当前基本面）。差异行数：
   fina 18,243 / income 22,479 / bal 16,532 / cf 20,345（占 8-9%，为同日多公告组的
   取舍差异，非数值差异）。
3. **PIT 覆盖率**（月末 as-of 行 roe 非空占比）：2015=96.3%、2016=95.5%、2017=96.3%、
   2018=96.6%、2019=96.4%、2020=96.7%——预登记 §5-3 担心的 2015 上半年覆盖偏低
   未成事实（fina_indicator 的 ann_date 覆盖良好，2015-01 起即有 2014Q3 可见）。
4. **90 天兜底使用比例 = 0**（fina 四数据集 f_ann_date/ann_date 全有值）。
5. 合并宽表的行级 signal_date = 四表可见时点的 **max**（全部表可见才用，保守滞后）。

## 二、字段映射与派生口径

- fina_indicator 直读：D01 roe、D02 roa、D03 grossprofit_margin、D04 netprofit_margin、
  D05 debt_to_assets、D06 current_ratio（列名实为 current_ratio 非 currentratio）、
  D09 eps、D10 bps、D11 tr_yoy（营收同比）、D12 netprofit_yoy、D18 assets_turn、
  D19 ocf_yoy、D20 q_sales_yoy（单季营收同比直读）、D30 ocfps（每股 OCF）。
- 三表派生：D07 = cf.n_cashflow_act / income.revenue；D08 = OCF/total_assets；
  D15 = (n_income_attr_p − OCF)/total_assets；D26 = total_assets/权益；
  D27 = (资产−intan_assets−goodwill)/权益；D28 = (sell_exp+admin_exp)/revenue；
  D29 = (n_income_attr_p − fina.profit_dedt)/|n_income_attr_p|。
- 同比差分（D13/D14/D25）：值 − 去年同月报告期值（(symbol, year−1, month) join）。
- 单季（D21）：累计净利差分（Q1 原值、Q2-4 = 累计−上季），同比 = 单季/去年同季|.|−1
  （亏损基数取绝对值，口径披露）；D24 = eps − 上季 eps。
- TTM：D22 = q_roe（fina 单季 ROE）4 期滚动和；**D23 近似口径披露：以最新报告期
  grossprofit_margin 充当 TTM 毛利率**（单季毛利率未直读，未做营收加权）——D23 因此
  与 D03 数值接近，F3 去重时二者视为同簇。
- 复合（D16/D17）：月末截面 average rank；D16 的 ep 来自 B 族 B04 同源（daily_basic
  月末 1/pe_ttm）。
- 单位：fina 比率类为 %，eps/bps/ocfps 为元，三表金额为元——全部只做秩相关，不换算。
