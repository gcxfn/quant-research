## 不一致清单（severity）

2. **MINOR（5 个表格单元格双重舍入）**：§3 表 5 格按"先 2dp 再 1dp"舍入，与精确值差 ~0.05pp：C01 净 13.6（精确 13.546→13.5）；C03 毛超额 +3.2（3.149→3.1）；C07 回撤 −25.6（−25.548→−25.5）；C09 回撤 −25.6（−25.548→−25.5）；C12 回撤 −25.9（−25.846→−25.8）。其余 167 格全部吻合。
3. **LOW（冻结配置文本歧义）**：VOLT `vol_input` 的 "adj_close/adj_close_**prev_own_row** − 1" 存在两种读法。实现取 eligible 子集内的前一行；若按"该 ETF 全部自身行情行的前一行"字面读法，64/108 个信号日敞口不同（最大绝对差 0.15，如 2018-01-31：0.9318 vs 1.0000），6/9 年的档位占比分布会变。留档路径与文档与实现语义逐位一致（本复核 9/9 年复现），且三机制对策略、B1(m)、B3′ 施加同一敞口路径，判定不受影响。若未来重开该方向，建议补一行语义说明。
4. **LOW（不可复现子句）**：§6"涨跌停阻断买入…（集中于 2024-09/10）"——阻断事件在 exec_stats 中只有计数、无逐事件留档（trades 仅含 filled 成交），该时间分布子句无法从产物复现。非判据、非决策性。
5. **INFO（口径并陈易混淆）**：`metrics.load_stats.rows_whitelisted=813,201 / 943 码` 是 U2 注册表过滤后的行数，而文档 §1 的"1,168 白名单 × 1,016,201 行"是白名单过滤后、U2 过滤前的行数。两者各自正确（本复核独立重建同时复现 1,016,201/1,168 与 943 码及逐年池规模），但并陈时易误读。
6. **INFO（作废 run 的 gate 差异）**：作废 run `93d0523e` 的 gate-3 布尔与正式 run 在 7 个配置上不同（C01/C03/C06/C09/C12 False→True，C05/C11 True→False），因其消费了塌陷的 B1(m) 逐年超额。该 run 已在判据消费前作废、结果文档表用的是正式 run 的 gate——处置正确，无需行动；此处留档说明差异来源。
