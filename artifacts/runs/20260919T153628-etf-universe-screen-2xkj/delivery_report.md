## 1. 方法与口径

### 时间纪律
- 全程仅使用 2015-01-01..2024-12-31 数据；脚本内断言 `2025+ 行数 = 0`、`2015 前行数 = 0`、日期上界 ≤ 2024-12-31、键 (symbol, date) 无重复，全部通过。
- 研究窗: dev = 2015–2020（并集日历 1,462 个交易日）、val = 2021–2024（969 个交易日）。并集日历 = 全部 1,169 只 ETF 交易日期的并集（2,431 天，与 SSE 2015–2024 开市日 2,431 一致）。

### 覆盖（覆盖合格 = 双窗均 ≥95%，取严）
- 每标的分窗统计出现日期数 / 该窗并集日历天数；`min_cov = min(dev_cov, val_cov)`；双窗均 ≥0.95 记覆盖合格。
- 注意这是刻意从严的设计：2020 年后上市的全部标的 dev 覆盖必然 <95%，直接落选。覆盖合格 78 只，未合格 1,091 只——未合格主因是"上市晚/生命周期不全"，不是数据缺陷。

### 流动性
- 每标的全历史（≤2024-12-31）日成交额中位数与 P25；跨 1,169 只标的对中位数排百分位。
- 全体中位数的 P25 = 222.53 万元；`liquidity_pass = 中位数 ≥ 222.53 万元`（未合格 292 只）。
- 中位数 <2,000 万元单独标记 `liquidity_low_flag`（794 只；**通过池内也有 20 只带此标记**，因它们仍高于全体 P25——按任务定义这只是标记，不参与 screen_pass；扩展宇宙使用时应知晓）。

### 公司行动 / 跳变画像
逐行计算三个量：
- `close/preclose − 1`（交易所参照口径）
- `close(t)/close(t−1) − 1`（持有人口径，headline）
- `preclose/prev_close − 1`（参照价跳变，缺口的另一签名）

因子来自 fund_adj 原始文件，按 (symbol, date) 左连，`factor_ratio = f(t)/f(t−1)`。事件表收录 |close/prev_close−1|>6% **或** |close/preclose−1|>6% 的全部事件，分类优先级：
1. **拆分合并型**: 因子有跳变且 |factor_ratio−1| > 0.15（含份额拆分/合并，引擎可由因子建模）
2. **分红型**: 因子有跳变且偏离 ≤0.15
3. **无因子缺口缺陷**: preclose/prev_close 参照差 >2% 且因子无跳变（因子缺失行保守计入）
4. **停牌复牌型**: 无因子跳变、preclose 连续、但相对并集日历有停牌缺口
5. **普通大幅波动**: 无上述任何异常签名（真实行情波动，如 2020-02-03、2024-09/10 行情）

另: 单标的存在 |close/prev_close−1| > 50% 的事件记 `split_class_flag`（任务规则）；为不漏掉 1:2 拆分（≈−49.2%），另设 `has_split_merge_event`（存在拆分合并型因子事件）。两者并列报告。

### 因子质量
- 日线行左连 fund_adj，统计缺失行数。全缺: `sz.159842`（920 行，原始批次即空结果，已登记）；部分缺: `sh.502056`（1,200 行）。合计 2,120 行，与数据集 quality.json 一致。

`coverage_pass`（双窗 ≥95%）且 `无未建模缺陷日`（无因子缺口缺陷日 = 0）且 `liquidity_pass`（中位数 ≥ 全体 P25）。

## 3. 诚实披露与限制

- 单一上游（tushare pro）提供价格与因子，非独立双源验证；本筛查只描述该数据集的内部一致性。
- "无因子缺口缺陷"判据是保守签名（参照价跳变 >2% 且因子无变化），不能区分"份额折算漏记"与"上游 preclose 抄写错误"——数据层面无法进一步区分，均按缺陷处理。
- 事件分类中的"分红型/拆分合并型"以 factor_ratio 阈值 0.15 划分，属启发式；明细表中附 factor_ratio 原值供复核。
- 覆盖率用并集日历口径；生命周期不全（上市晚/已退市 116 只）自然落选，这反映的是"双窗全程在市"这一筛选设计，不是数据质量问题。
- 通过池 51 只中 20 只中位成交额低于 2,000 万元（但高于全体 P25），扩展宇宙探索时需自行决定是否加严流动性线。
- 本报告不含任何收益率、回撤、绩效或策略结论；未产生任何"可实盘"表述；未做 git 操作。
- 唯一写入位置为本 run 目录；`data/` 与其他 run 目录零写入。
